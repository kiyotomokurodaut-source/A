# 東大英語の要約は「訳して縮める」と失敗する｜70〜80字に収める5つの手順と自作演習

## 無料部分

東大英語の第1問(A)は、英文を読んで、その内容を**日本語で**要約する問題です。字数は年度によって違い、70〜80字前後の指定が多く、書き出しが指定される年もあります。

この問題について、受験生からよく聞く悩みは次の3つです。

- 英文は読めているはずなのに、答案が「ぼんやりした内容」になる
- 字数が大きくはみ出し、削っていくうちに何が言いたいのか分からなくなる
- 自己採点のしかたが分からず、過去問を解いても伸びた実感がない

私は東京大学文科二類に現役合格し、教育学部を卒業しました。今はプロ家庭教師として、東大を含む大学受験生の英語を指導しています。要約の答案を添削していると、点が伸びない原因は英語力不足よりも、**手順の問題**であることがよくあります。

いちばん多いのは、**一文ずつ和訳して、それをつないで短くする**という書き方です。この方法では、本文で目立っていた具体例が残りやすく、筆者が最も言いたいこと（多くは「しかし」「つまり」の後にあります）が字数の最後に押し出されて消えてしまいます。

要約は「短い和訳」ではありません。**本文の論理関係を、日本語で組み立て直す作業**です。

この記事の有料部分では、次の内容を扱います。

1. 答案を書く前に行う5つの手順（設問確認、文の役割分け、主張の一文化、具体例の扱い、字数調整）
2. 自作の英文（約170語）を使った演習：手順どおりのメモ、よくある失敗答案3つとその修正、答案例
3. 字数が多すぎる・少なすぎるときの調整のしかた
4. 自己採点のためのチェック表（7項目）
5. 過去問を使った4週間の練習計画

例題はこの記事のために作った自作の英文です。実際の入試問題や予想問題ではありません。また、東大は採点基準を公表していないため、この記事で示す「減点されやすい点」は、答案を読む側から見て内容が伝わらない箇所という意味です。得点を保証するものではありません。

過去問を何年分か解いたのに要約の点数が安定しない人、これから東大英語の対策を始める人に向けて書きました。

## 1. 書く前の5つの手順

### 手順1：設問の条件を先に確認する

本文を読む前に、設問を読みます。確認するのは次の3つです。

- 字数（例：70〜80字）。句読点を1字に数えるか
- 書き出しの指定があるか（ある場合、その書き出しに続けて自然な文になるように書く）
- 「要旨」なのか「〜について筆者の考えをまとめよ」なのか（範囲が限定されているか）

書き出しが指定されている場合、その分も字数に含まれるかどうかは、問題の指示に従ってください。**指示を最優先にする**のが鉄則です。ここで読み違えると、内容がよくても大きく失点する可能性があります。

### 手順2：各文（各段落）に「役割」のラベルを付ける

本文を読みながら、各文の横に短いラベルを付けます。和訳はしません。

| ラベル | 意味 |
|---|---|
| 背景 | 話題の導入、以前の状況 |
| 一般 | 世間一般の見方、よくある考え |
| 対比 | 前の内容と反対の状況 |
| 利点／問題 | よい面、悪い面 |
| 例 | 具体例、データ、エピソード |
| 主張 | 筆者が最も言いたいこと |

特に注意するのは、**But / Yet / However / In fact / The point is / Rather** など、流れが変わる語の後です。主張はここに来ることが多いです。反対に、For example / Imagine / Consider などの後は「例」になることが多いです。

### 手順3：主張を「AではなくB」「AだがB」の形で一文にする

筆者の主張は、多くの場合、何かと比べることで成り立っています。そこで、主張を次のような型で、日本語で一文にします。

- 「Aだと思われているが、実はB」
- 「AにはXという利点があるが、Yという問題もある」
- 「問題はAではなく、Bである」

この一文が、答案の骨組みになります。**ここで字数を気にしてはいけません。**まず内容が正しいかを確認します。

### 手順4：具体例は「言い換え」て残すか、捨てる

例を捨てるのが基本ですが、機械的に捨ててはいけません。判断の基準は次のとおりです。

- 例が主張を説明するだけのもの → 捨てる
- 例がなければ主張の中身が分からない（その例が論点そのもの） → **抽象的な言葉に言い換えて**残す

たとえば「スマートフォンの地図アプリ」が本文の話題そのものであれば、「デジタル地図」などの言葉で残す必要があります。

### 手順5：骨組みに肉付けし、最後に字数を合わせる

骨組み（手順3）に、必要な要素を重要度の高い順に足していきます。字数を数えるのは**最後**です。最初から字数を気にすると、内容の選択を誤りやすくなります。

## 2. 自作演習

### 例題

次の英文の要旨を、70〜80字の日本語でまとめなさい。句読点も1字に数えます。

> For most of history, a city's map was drawn by people who walked its streets. Surveyors measured distances step by step, and the result reflected what they could observe on foot. Today, by contrast, the maps on our phones are built largely from data generated by millions of users moving through the city. This shift has obvious advantages: such maps update quickly, showing new roads or traffic jams within minutes. Yet it also changes what a map is for. A traditional map invited its reader to understand the shape of a place and to choose a route for herself. A navigation app, on the other hand, asks only for a destination and then tells the user where to turn. Some researchers worry that people who rely on such instructions form weaker mental pictures of the places they live in. The point is not that digital maps are harmful, but that convenience in reaching a destination may come at the cost of knowing where we are.

### 手順2のメモ（役割ラベル）

1. For most of history … → **背景**（昔の地図は歩いて作られた）
2. Surveyors measured … → **例**（1の具体化）
3. Today, by contrast … → **対比**（今はユーザーのデータで作られる）
4. This shift has obvious advantages … → **利点**（更新が速い）
5. Yet it also changes what a map is for. → **転換**（地図の役割が変わる）← Yet に注目
6. A traditional map invited … → **対比の前半**（場所の形を理解し、自分で道を選ぶ）
7. A navigation app … → **対比の後半**（目的地を入れると曲がる場所を指示する）
8. Some researchers worry … → **問題**（頭の中の地図が弱くなる）
9. The point is not … but … → **主張**

### 手順3：主張の一文

「デジタル地図が有害なのではなく、目的地に着く便利さと引き換えに、自分のいる場所を理解することが失われるかもしれない。」

### 手順4：残す要素と捨てる要素

- 残す：デジタル地図（話題そのもの）、利点（更新が速い）、指示に従うだけになるという変化、場所を理解する力が弱まるおそれ
- 捨てる：測量士が歩いて測った（2）、交通渋滞などの例（4の一部）、some researchers という出どころ

### 失敗答案と修正

**失敗答案A（和訳をつないだもの）**
「昔の地図は人が街を歩いて作ったが、今はスマートフォンの地図が多くの利用者のデータから作られ、新しい道路や渋滞を数分で表示できるようになった。」

→ 問題点：前半（文1〜4）しか扱っておらず、Yet 以降の主張がまったく入っていません。これだけで70字を使っており、主張を入れる余地が残っていません。**冒頭から順に訳すと起きる典型的な失敗**です。

**失敗答案B（主張だけで中身がない）**
「デジタル地図は便利だが、それによって失われるものもあるので、使い方に注意が必要である。」

→ 問題点：「失われるもの」が何か書かれていません。また「使い方に注意が必要」は本文に書かれていない内容（答案を書いた人の結論）です。**本文にない提言を足さない**ことが大切です。

**失敗答案C（例を残しすぎ）**
「ナビアプリは目的地を入力すると曲がる場所を教えるため、伝統的な地図のように自分で道を選ばなくなり、住んでいる場所の頭の中の地図が弱くなると研究者は心配している。」

→ 問題点：文6〜8の言い換えとしては正確ですが、筆者の主張（The point is not … but …）の「有害というわけではないが、便利さと引き換え」という対比が入っていません。「研究者は心配している」という出どころも、要旨には不要です。

### 答案例（79字）

「地図が利用者のデータで作られ更新が速くなった一方、道順を指示されるだけになると、目的地に着く便利さと引き換えに、自分のいる場所を理解する力が損なわれかねない。」

※字数は句読点を含めて数えています。自分で数え直して確かめてください。

確認ポイント
- 利点（更新が速い）と問題（理解する力が損なわれる）の両方が入っている
- 「指示されるだけ」で、伝統的な地図との対比を一語にまとめている
- 「〜と引き換えに」で、主張の中心（便利さと代償）が表れている
- 「有害ではない」の部分は、「損なわれかねない」という控えめな言い方に含めて、字数を節約している（字数の上限が大きい設問なら、「デジタル地図が悪いのではなく」を入れてもよい）

## 3. 字数の調整

### 多すぎるとき（削る順番）

1. 同じ意味の繰り返し（「速く、すぐに」→「速く」）
2. 修飾語の重なり（「とても大きな」→「大きな」）
3. 名詞化してまとめる（「〜するということ」→「〜すること」）
4. それでも多ければ、**重要度の低い要素**（今回なら「利用者のデータで作られ」）を短くする

**主張の中心と論理関係を表す語（一方・ではなく・引き換えに）は最後まで残します。**

### 少なすぎるとき（戻す順番）

1. 骨組みで省いた「対比の前半」（今回なら「自分で道を選べた従来の地図と違い」）
2. 利点や前提の部分

「〜ということである」のような、内容のない語句で字数を埋めるのはやめてください。採点する人には、内容が増えていないことが分かります。

## 4. 自己採点チェック表

過去問の答案を書いたら、次の7項目を○／×で確認します。

| # | チェック項目 |
|---|---|
| 1 | 字数・書き出しの指定を守っている |
| 2 | 筆者の主張（But / Yet / The point is の後）が入っている |
| 3 | 主張と対になる要素（何と比べているか）が入っている |
| 4 | 具体例をそのまま書いていない（必要なものは抽象語に言い換えている） |
| 5 | 本文にない意見・提言を足していない |
| 6 | 主語と述語が対応し、一文として意味が通る |
| 7 | 論理関係を表す語（しかし、一方、ではなく、ため）が本文の関係と合っている |

×がついた項目を、答案の横に書いておきます。**同じ番号の×が3回続いたら、それが今の課題**です。次の練習ではその項目だけを意識してください。

模範解答と見比べるときは、「表現が同じか」ではなく、**「要素の数と論理関係が同じか」**を確認します。市販の解答例どうしでも、表現は大きく異なります。

## 5. 4週間の練習計画

| 週 | やること | 1回の目安 |
|---|---|---|
| 1週目 | 過去問2題。時間を計らず、手順1〜5のメモを必ず書く | 25分 |
| 2週目 | 過去問2題。メモを短くし、役割ラベルだけで骨組みを作る | 20分 |
| 3週目 | 過去問3題。目標時間を決めて解く（例：15分）。チェック表で自己採点 | 15分＋採点10分 |
| 4週目 | 大問1から順に通しで解く演習の中で要約を解き、全体の時間配分の中で何分使えるかを確認 | 通し演習 |

- 目標時間は人によって違います。東大英語全体の時間配分の中で、自分が要約に使える時間を決めてください。
- 1週目にメモを丁寧に書くことが、後の速さにつながります。最初から速く解こうとしないでください。
- 過去問が足りなくなったら、英字新聞のコラムや大学の講義紹介文など、主張がはっきりした300語前後の英文で同じ練習ができます。

## おわりに

要約は、才能や「センス」の問題ではありません。**主張を見つけ、対比を残し、例を言い換える**という手順を、毎回同じように実行できるかどうかで決まります。

この記事の例題とチェック表を使って、まず1題、手順どおりに解いてみてください。過去問の答案で×が続く項目があれば、それがあなたの次の課題です。
