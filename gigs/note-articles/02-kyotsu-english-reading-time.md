# 共通テスト英語リーディングの時間配分は「人の表」をまねても決まらない｜3回の演習で自分の80分を作る方法

## 無料部分

共通テストの英語リーディングは、試験時間80分、100点満点の試験です。2025年度からの新しい形式では大問が8つに分かれています（細かい構成は年度によって変わる可能性があるため、大学入試センターの最新資料と前年度の問題で必ず確認してください）。

この試験の相談で最も多いのは、「最後の大問まで終わらない」というものです。

そこで、インターネットや参考書に載っている「第1問は◯分、第2問は◯分」という時間配分表をまねる人がたくさんいます。しかし、私が指導している中で見ていると、**配分表をそのまま使ってうまくいく人は多くありません。**理由は単純で、時間がかかる場所が人によって違うからです。

- 単語の意味を思い出すのに止まる人
- 一文の構造が取れず、同じ文を何度も読み直す人
- 設問が求める情報を本文から探すのに時間がかかる人
- 選択肢を2つに絞ったあと、決められずに迷い続ける人

この4人は、同じ「時間が足りない」という悩みを持っていても、直すべきところがまったく違います。誰かの配分表を使っても、自分が止まっている作業は速くなりません。

私は東京大学教育学部を卒業し、今はプロ家庭教師として大学受験生の英語を指導しています。共通テスト対策では、生徒に**自分の時間を記録してもらい、その記録から配分を作る**方法をとっています。

有料部分では、その方法を一人で実践できる形にまとめました。

1. 1回目の演習：大問ごとの「通過時刻」を記録する方法（記録用シートつき）
2. 時間を失った原因を4種類に分ける方法と、それぞれの練習
3. 2回目の演習：自分用の時間配分表を作る（記入用テンプレート、予備時間の取り方）
4. 迷ったときのルール：「仮の答えを付けて先に進む」の具体的な基準
5. 3回目の演習と、試験直前4週間の過ごし方
6. 本番当日の時計の見方とマークのしかた

この記事では、得点が何点上がるといった約束はしません。紹介するのは、**自分の80分を記録し、毎回の演習を次の改善につなげる手順**です。共通テストまで時間が限られている人ほど、演習を「解いて採点して終わり」にしないために役立ててください。

## 1. 1回目の演習：通過時刻を記録する

最初の演習では、**時間配分を気にせず**、いつもどおりに解きます。そのかわり、次の記録を取ります。

### 用意するもの
- 共通テストの過去問、または新形式に対応した問題集の1回分
- 時計（スマートフォンのストップウォッチは、通知で集中が切れるので避けます）
- 下の記録シート

### 記録のしかた
大問を1つ解き終えるたびに、問題用紙の余白に**その時点の経過時間**を書きます。「何分かかったか」ではなく、**開始から何分たったか**を書くのがポイントです。引き算は後でできますが、解きながら計算すると集中が切れます。

さらに、次の2つの印をつけます。

- **△**：迷った設問（2つまで絞って決められなかったもの）
- **↩**：本文を3回以上読み直した箇所

### 記録シート

| 大問 | 通過時刻（経過分） | かかった時間 | △の数 | ↩の数 | 正答数／設問数 |
|---|---|---|---|---|---|
| 第1問 | | | | | |
| 第2問 | | | | | |
| 第3問 | | | | | |
| 第4問 | | | | | |
| 第5問 | | | | | |
| 第6問 | | | | | |
| 第7問 | | | | | |
| 第8問 | | | | | |
| 見直し | | | | | |

80分で終わらなかった場合は、80分の時点で解答を記録したうえで（ここまでが本番の得点です）、**最後まで解き続けて**、終わった時刻も記録してください。「時間があれば解けたのか」「時間があっても解けなかったのか」を分けることが、次の練習を決めるためにとても重要です。

## 2. 時間を失った原因を4種類に分ける

採点が終わったら、かかった時間が長かった大問と、△や↩が多かった大問を見ます。そして、時間を失った原因を次の4つに分けます。

### 原因A：語彙で止まる
**症状**：知らない単語や、見たことはあるが意味が出てこない単語のところで止まる。↩が単語の周辺に集まっている。
**練習**：間違えた単語だけを集めた「自分の単語リスト」を作り、毎日5分、英語→日本語を瞬時に言えるか確認します。新しい単語帳を始めるより、演習で止まった語を確実にするほうが、直前期には効果的です。

### 原因B：一文の構造が取れない
**症状**：単語は分かるのに、誰が何をしたのかが取れない。長い文や、関係詞・分詞が入った文で↩がついている。
**練習**：↩がついた文を書き出し、主語・動詞・修飾のかかり方に線を引いてから和訳します。1日3文で十分です。時間を計る練習より先に、こちらを優先してください。構造が取れないまま速く読もうとすると、読み直しが増えて、かえって遅くなります。

### 原因C：情報を探すのに時間がかかる
**症状**：本文の内容は理解できているのに、設問に答えるために本文を行ったり来たりしている。日付・金額・条件の変更などを含む問題で時間がかかっている。
**練習**：本文を読む前に、設問で問われていることを確認し、「何を探すか」を決めてから読みます。演習では、設問の答えの根拠になった本文の行に、設問番号を書き込んでください。根拠の位置を探すのが速くなると、読み直しの回数が減ります。

### 原因D：選択肢で迷う
**症状**：△が多い。2つに絞ったあと、長い時間迷っている。
**練習**：間違えた設問について、**選んだ選択肢のどこが本文と違うのか**を一語単位で特定します。「本文に書かれていない内容が加わっている」「範囲が広すぎる（always、all など）」「時間や条件がずれている」など、誤りのパターンを自分のノートにためていきます。

原因は1つとは限りません。**最も時間を失った原因から**直してください。いくつも同時に直そうとすると、どれも中途半端になります。

## 3. 2回目の演習：自分用の時間配分表を作る

1回目の記録をもとに、自分の配分表を作ります。

### 手順1：予備時間を先に確保する
80分のうち、**最初に5分を予備時間として取り分け**ます。この5分は、迷った設問の見直しや、マークの確認に使います。使う大問を決めておかないことがポイントです。

### 手順2：残り75分を、1回目の記録の比率で配る
1回目の演習で各大問にかかった時間の比率を参考に、75分を配分します。ただし、次の調整をします。

- 原因Aや原因Bで時間を失った大問：**時間を増やさない**。時間を増やしても、語彙や構文の問題は解決しないからです。そのかわり、2章の練習を優先します。
- 原因Cや原因Dで時間を失った大問：設問の先読みや、迷ったときのルール（次の章）で時間を短くできる可能性が高いので、目標時間を少し短めに設定します。

### 手順3：「経過時間」の表にする
配分は「◯分ずつ」ではなく、**「経過◯分までに第◯問を終える」**という形にします。本番では、引き算をするより、時計を見て予定と比べるほうがずっと簡単です。

### 記入用テンプレート

| 区切り | 目標の通過時刻（経過分） | 1回目の実績 | 2回目の実績 |
|---|---|---|---|
| 第1問 終了 | | | |
| 第2問 終了 | | | |
| 第3問 終了 | | | |
| 第4問 終了 | | | |
| 第5問 終了 | | | |
| 第6問 終了 | | | |
| 第7問 終了 | | | |
| 第8問 終了 | 75 | | |
| 予備時間・マークの確認 | 80 | | |

（参考）前半の大問は文章が短く、後半ほど長い文章や論説文が出る傾向があります。そのため、多くの人は**前半を予定より早く終え、その分を後半に回す**形になります。ただし、各大問の分量は年度によって違うので、ここに具体的な分数は書きません。必ず自分の記録から決めてください。

2回目の演習では、この表を問題用紙の表紙に書き写してから解きます。大問を終えるたびに、目標と実績の差を確認します。

## 4. 迷ったときのルール

時間が足りなくなる大きな原因のひとつは、**1つの設問で迷い続けること**です。そこで、次のルールを事前に決めておきます。

> **2つに絞って30秒たっても決められなければ、根拠が多いほうに仮の答えをマークし、問題用紙の設問番号に△をつけて先に進む。**

ポイントは3つあります。

1. **必ずマークしてから進む**：空欄のまま進むと、時間切れのときに得点にならず、マークのずれの原因にもなります。
2. **「根拠が多いほう」を基準にする**：本文の根拠の行を指でさせるほうを選びます。なんとなくの印象で選ばないでください。
3. **△の見直しは予備時間で行う**：すべての大問を解き終えてから戻ります。後の大問を読んだあとで戻ると、冷静に判断できることがよくあります。

30秒という数字は目安です。演習で△の数が多すぎる（たとえば1回の演習で10個以上）場合は、ルールの問題ではなく、原因Dの練習が必要なサインです。

### 解く順番を変えるべきか
大問を最初から順に解くか、順番を変えるかは、1回目の記録で決めます。

- 前半の大問で時間を使いすぎて、後半の長い文章に手をつけられない人 → 順番どおりのまま、前半の目標時刻を厳しく守る練習をする
- 後半の論説文が得意で、得点源にしたい人 → 後半から解く方法を、**演習で2回以上試してから**採用する

本番で初めて順番を変えるのは危険です。マークのずれも起きやすくなるので、試すなら必ず演習の段階で行ってください。

## 5. 3回目の演習と、試験直前4週間の過ごし方

### 3回目の演習
2回目の配分表を、実績に合わせて修正してから解きます。この時点で**目標と実績の差が各区切りで2分以内**になっていれば、配分は使える状態です。差が大きい大問は、2章の原因の分類に戻ります。

### 直前4週間の例

| 時期 | 演習 | 演習以外 |
|---|---|---|
| 4週間前 | 本番形式で1回（記録シートを使う） | 原因の分類と、原因A〜Dの練習 |
| 3週間前 | 本番形式で2回（配分表を作り、試す） | 自分の単語リスト、構文の書き出し |
| 2週間前 | 本番形式で2回（配分表を修正） | △の設問の誤りパターンをノートにまとめる |
| 1週間前 | 本番形式で1〜2回（本番と同じ時間帯に解く） | 新しい教材には手を出さず、ノートの見直し |

- 演習の回数を増やすことより、**1回ごとの記録と復習**を優先してください。記録をとらずに10回解くより、記録をとって4回解くほうが、直すべき点がはっきりします。
- リスニングや他の科目との兼ね合いで、全体の計画は調整してください。

## 6. 本番当日の時計の見方とマーク

1. **試験開始の時刻を問題用紙に書く**：経過時間で管理するため、開始時刻を書いておくと、時計を見たときにすぐ計算できます。可能であれば、自分の配分表を「時刻」に書き換えておきます（例：開始が◯時◯分なら、第3問の終了は◯時◯分）。
2. **マークは大問ごとにまとめて行う**：1問ずつマークすると時間がかかり、最後にまとめてマークすると時間切れのリスクがあります。大問を解き終えるたびに、その大問のマークを済ませるのがバランスのよい方法です。
3. **予定より遅れたときは、取り戻そうとしない**：遅れを一度に取り戻そうとして読み方を雑にすると、失点が増えます。遅れが3分を超えたら、残りの大問の「迷ったときのルール」を少し厳しく（30秒→20秒）するだけにします。
4. **最後の5分はマークの確認に使う**：特に、問題を飛ばした箇所の前後で、マークがずれていないかを確認します。

試験会場では、腕時計の持ち込みや機能に関する決まりがあります。受験案内で事前に確認してください。

---

## おわりに

時間配分は、「正しい表」を探すものではなく、**自分の記録から作り、演習ごとに修正するもの**です。

1回目は記録、2回目は配分表の作成と実行、3回目は修正。この3回の演習を行うだけで、「なぜ終わらないのか」がはっきりし、次にやるべき練習が決まります。

まずは、次の演習1回分で、記録シートを使ってみてください。
