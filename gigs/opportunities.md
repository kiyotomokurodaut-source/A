# 執筆・スキル副業の機会調査（目標：手取り合計10万円/月）

調査日：2026-11-23。金額は検索で確認できた公開案件・公式ヘルプ・解説記事の数字で、**相場の目安**です。案件ごとの条件は応募前に必ず確認してください。atsoho.com など第三者ブログの数字は「二次情報」と明記しています。手数料は改定されることがあるため、登録時に各社の公式ヘルプを確認してください。

## 0. 前提：黒田さんの「売れる経歴」と使い方

サイト（public/about/）で公開している事実だけを使います。

- 東京大学文科二類に現役合格、教育学部卒業
- プロ家庭教師として個別授業・受験コーチング・学習計画と進捗管理を直接担当（黒田塾）
- 対応範囲：算数・数学（中学受験〜大学二次の文系・理系数学）、英語（基礎〜大学受験、海外大学出願のエッセイ指導）、国語（記述添削）、社会（二次論述）、小論文・面接（総合型・学校推薦型）
- 指導経験の例：東大文科一類の生徒への日本史・数学指導、医学部受験生への数学・英語指導、不登校から外国語大学合格までの学習再建（いずれも匿名事例。**合格実績数・指導人数・指導年数はサイトに記載がないので書かない**）
- 学習ガイド・解説サンプルを公開中（これがポートフォリオになる）
- 外部プロフィール：X @kurodaschool、Shiok!、スマートレーダー、LinkedIn

**一般ライター（文字単価0.5〜1.5円）と競争しないことが最重要です。**「東大卒・現役指導者・実名顔出し可」は、監修者・専門家ライターとしての価値です。監修料は一般的な専門家で1記事5,000円〜3万円、2,000字の記事のファクトチェック・監修で1〜3万円が目安とされています（[クラウドワークス公式メディア](https://crowdworks.jp/times/know-how/13264/)、[同 別記事](https://crowdworks.jp/times/know-how/12526/)）。1本あたりの作業は30〜90分なので、時給換算では執筆より有利です。

**編集プロダクション・教育メディアへの直接営業（最も高単価）**：取材記事や編集プロダクション経由の文字単価は5〜20円が目安とされています（二次情報、上記）。受験・教育メディア（塾比較サイト、教育系出版社のWebメディア、総合型選抜専門メディアなど）の「ライター募集」「監修者募集」ページや問い合わせフォームに、`proposals.md` の監修テンプレートと公開中の学習ガイドURLを送ります。クラウドワークスで受けた案件の実績が2〜3本あると、話が進みやすくなります。

### (c) note 有料記事・メンバーシップ

- **手数料（公式）**：事務手数料（クレジットカード5%、キャリア決済15%など）を引いた額に、プラットフォーム利用料10%がかかります（定期購読マガジンは20%）。1,000円の記事をカード決済で売ると、手数料は145円です。振込手数料は1回270円です（[note公式ヘルプ](https://www.help-note.com/hc/ja/articles/360011358873)）。メンバーシップの開設・運用は無料です。
- **価格と量**：1,000円の記事なら、1本あたりの手取りは約855円です。手取り10万円には月117本の販売が必要で、**集客がない状態では現実的ではありません**。月10〜30本（手取り1〜2.5万円）を、ほかの経路の補助と考えてください。
- **作業**：1本あたり執筆と確認に4〜6時間。一度書けば受験シーズンごとに売れ続けるストック型です。
- **集客**：X（@kurodaschool）と黒田塾の学習ガイドからリンクします。無料部分にも価値がある内容にすることが、購入されるための条件です。
- **AI関連**：noteは2025年8月から、有料部分を含む投稿テキストをAI事業者の学習データに提供する仕組みを導入しています（オプトアウト可）。有料記事を学習させたくない場合は、設定で拒否してください（[note公式ヘルプ](https://www.help-note.com/hc/ja/articles/47621851095449)、[Impress](https://www.watch.impress.co.jp/docs/news/2157450.html)）。AI利用の表示義務を定めた専用ルールは、今回の検索では確認できませんでした。
- **リスク**：無名のうちは売れません。誇大なタイトル（「〇日で偏差値〇上がる」など）は書かないでください。

## 2. AI生成コンテンツに関するプラットフォームのルール

| プラットフォーム | 確認できた内容 |
|---|---|
| クラウドワークス | AI活用ポリシーを公開。AIの利用自体は禁止せず、**利用の可否はクライアントとワーカーの合意で決める**。ワーカー向けの行動規範あり（[CodeZine](https://codezine.jp/news/detail/19965)、[みんかぶ](https://minkabu.jp/news/4190132)、[利用規約](https://crowdworks.jp/pages/agreement.html)） |
| ランサーズ | クライアント向けFAQに「生成AIの使用を許可する時の注意点」がある（[FAQ](https://www.lancers.jp/faq/C1002)）。本文は未確認 |
| ココナラ | 生成AIを支援ツールと位置づけ。一部カテゴリでは**AI生成イラストそのものを納品物とするサービスを禁止**。文章へのAI利用の表示義務は確認できず（[news/1354](https://coconala.com/news/1354)、[news/917](https://coconala.com/news/917)） |
| note | AI学習へのデータ提供（オプトアウト可）。AI利用表示の専用ルールは確認できず（上記） |

**運用ルール（推奨）**
1. 応募前に募集要項の「AI使用」の項目を確認する。禁止の案件には、AIを使った下書きで応募しない。
2. 指定がない案件では、提案文で「構成案・下書きにAIを補助的に使い、事実確認・最終稿は本人が行う」と開示し、クライアントの了承を得る。黒田塾サイトの編集方針（AIを補助的に使用）と一貫させる。
3. 監修・添削の判断と最終的な文章は、必ず黒田さん本人が確認する。添削コメントは本人の名前で出るため、AIが書いた文をそのまま送らない。
4. 規約は頻繁に変わるため、**登録時と応募時に最新の規約を本人が確認する**。

- 作業時間の目安：監修4〜6h＋執筆8h＋ココナラ約12h＋note（新作1本）5h＋解説4h ≈ **月35時間（週8〜9時間）**
- **1か月目の現実的な見込み**：手取り2〜4万円（ココナラは評価ゼロ、監修は実績待ち）。2か月目に5〜7万円、受験期（12〜2月）に10万円以上を目指してください。
- 受験期が終わる3〜4月はココナラの需要が落ちます。その時期は監修・執筆の継続案件と、年間を通して売れるnote記事で補ってください。

## 5. 最初の2週間の行動リスト

1. クラウドワークス・ランサーズ・ココナラ・noteに本人名義で登録し、本人確認を済ませる（ココナラは本名で出品できるが、表示名は任意）。
2. `profiles.md` を貼り付ける。プロフィール写真は黒田塾サイトと同じものを使う。
3. ポートフォリオとして黒田塾の学習ガイド（東大英語要約、共通テスト時間配分など）のURLを3本登録する。
4. CW・ランサーズで「監修」「教育」「受験」「塾」「総合型選抜」「家庭教師」で検索し、`proposals.md` を使って週5件応募する。
5. `coconala-listings.md` の4サービスを出品する（最初は価格を2〜3割下げ、5件程度の評価がついたら定価に戻す）。
6. `note-articles/` の2本を、12月上旬（共通テスト前）に公開する。
7. 入金・経費は事業所得または雑所得として記録する（黒田塾の会計との関係は税理士に確認）。
