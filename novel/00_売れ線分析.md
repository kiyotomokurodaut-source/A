# ライトノベル売れ線分析（1995〜2026）と本作への反映

## 1. 30年の流れ（年代別ヒットと「売れた理由」）

| 時期 | 代表的なヒット | 売れた構造 |
|---|---|---|
| 1990年代 | スレイヤーズ（累計2000万部）、魔術士オーフェン、ブギーポップは笑わない（1998）、フルメタル・パニック！ | ファンタジー冒険＋**一人称の軽妙な語り**（スレイヤーズ）。ブギーポップで「学園×群像×切なさ」という“現代ラノベ”の原型が成立。 |
| 2000年代前半 | 涼宮ハルヒ（このラノ2005年1位）、戯言シリーズ（2006）、狼と香辛料（2007） | **ツッコミ型の一人称男子＋強烈なヒロイン**。ハルヒは「平凡な僕×規格外の彼女」の決定版。狼と香辛料は**知識（経済）を会話劇で読ませる**手法を確立。 |
| 2000年代後半 | “文学少女”（2009）、バカとテストと召喚獣（2010）、とある魔術の禁書目録（2011） | 文学少女は**実在の作品知識×ヒロイン×切なさ**。教養ネタを毎巻の軸に据える構成。 |
| 2010年代前半 | ソードアート・オンライン（2012・2013）、やはり俺の青春ラブコメはまちがっている。（2014〜2016の3連覇） | 俺ガイルが**ひねくれた一人称ツッコミの学園青春もの**を王道に押し上げた。部室・顧問（平塚先生）・奉仕部という「部活の箱」。 |
| 2010年代後半 | りゅうおうのおしごと！（2017・2018）、青春ブタ野郎シリーズ、錆喰いビスコ（2019） | りゅうおうは**専門分野（将棋）×熱さ×泣き**。青ブタは「**軽い掛け合い＋年上ダウナー毒舌ヒロイン＋思春期の痛みに一冊で答えを出す**」形が強い。 |
| 2020〜2022 | 千歳くんはラムネ瓶のなか（2021・2022）、七つの魔剣が支配する（2020） | 千歳くんは**群像ヒロインの恋心と痛み**、リア充主人公。複数ヒロインのあいだの温度差が読みどころ。 |
| 2023〜2024 | ようこそ実力至上主義の教室へ（2023）、お隣の天使様にいつの間にか駄目人間にされていた件（2024年は5冠） | **Web発の甘々ラブコメ**が定着。お隣の天使様は「距離が縮まる過程」を丁寧に積み重ね、**呼び名の変化**などの小さな前進を山場にしている。 |
| 2025 | 負けヒロインが多すぎる！（1位）、時々ボソッとロシア語でデレる隣のアーリャさん | マケインは**負けヒロインに寄り添う**構図と、くすっと笑える一人称の語りで売れた。アニメ化の月に売上が前月の約25倍。ロシデレは**ヒロインの“秘密のデレ”というギミック**が一行で伝わる。 |
| 2026 | あそびのかんけい（新作・文庫・総合の3冠）、お隣の天使様（2位）、マケイン（3位）、ロシデレ（4位）、転生程度で胸の穴は埋まらない（5位）、**デルタとガンマの理学部ノート（6位）**、**ミドルノートにさよなら（7位）** | 上位は依然**学園／日常ラブコメ**が独占。あそびのかんけいは**趣味の専門性（ボードゲーム）×片想いの嘘から始まる関係**。一方で理系部活の青春（デルタとガンマ）や、重い設定の純愛（ミドルノート）も上位に入っている。 |

累計部数の上位は転スラ、薬屋、とある、SAO、魔法科、スレイヤーズ、ハルヒ、ダンまち、無職転生など、異世界・ファンタジーが中心。ただし「文庫新人のデビュー作」に絞ると、近年のこのラノ上位は学園ラブコメが圧倒的に強い。

## 2. 売れ線の共通項（抽出した10の法則）

1. **一行で伝わるヒロインのギミック**：「ロシア語でデレる」「お隣の天使様」「負けヒロイン」。帯とタイトルだけでどんな関係かがわかる。
2. **文章型の長いタイトル**が今も主流。ただしガガガ・電撃では「千歳くんはラムネ瓶のなか」「デルタとガンマの理学部ノート」のような**短い詩的なタイトル＋副題**も強い。
3. **一人称男子のツッコミの語り**（スレイヤーズ→ハルヒ→俺ガイル→マケイン）。地の文の笑いがページをめくらせる。
4. **ダウナー／毒舌／年上系ヒロインと、あとで見せる甘えのギャップ**（青ブタの麻衣先輩、お隣の天使様の真昼）。
5. **専門知識を会話劇で読ませる**（狼と香辛料の経済、りゅうおうの将棋、あそびのかんけいのボドゲ、デルタとガンマの科学）。知識はヒロインとの距離を縮める道具になっている。
6. **部活という箱と、ゆるい顧問**（奉仕部と平塚先生、古典部など）。
7. **複数ヒロインと負けヒロイン**。2020年代は、選ばれなかった側の恋にも尊厳を与える描き方が好まれる（千歳くん、マケイン）。
8. **距離が縮まる“小さな前進”を山場にする**：呼び名が変わる、手が触れる、肩に寄りかかる、LINEの既読。
9. **笑い7：泣き3**。泣かせは後半に集中させ、前半は掛け合いで読者をキャラに惚れさせる（青ブタ、千歳くん）。
10. **1巻で物語を閉じつつ、続刊の余白を残す**（新人賞は完結が条件、ただし編集部はシリーズ化できる余地を見る）。

## 3. 競合作との差別化

| 競合 | 被りうる点 | 本作の差別化 |
|---|---|---|
| デルタとガンマの理学部ノート（電撃） | 理系部活×初恋×科学の解説 | 本作の軸は**嗅覚（匂いがわからない少年と、嗅覚が鋭すぎる少女）という“感覚の非対称”**で、謎解きはしない。科学は感情を翻訳する道具。 |
| ミドルノートにさよなら（ガガガ） | タイトルが香水用語、重い設定の純愛 | 本作は**病気を「治ったあと」のサバイバー視点**で描く。読後感は明るい。 |
| 余命もの（君の膵臓、今夜世界からこの恋が消えても） | 病気×恋愛×泣き | **ヒロインは死なない**。死んだのは親友で、残された側の罪悪感と、もう一度好きになる怖さを描く。 |

## 4. 改稿方針（初稿から何を変えたか）

| 項目 | 初稿 | 改稿 |
|---|---|---|
| タイトル | 『きみの匂いを、化学式で覚えている』 | 『**匂いのわからない僕を、年上の同級生が毎日嗅いでくる。**』（副題：きみの匂いを、化学式で覚えている）。法則1・2 |
| ヒロインのギミック | 嗅覚が鋭い、マスク | **湊の匂いを毎日嗅いで言語化してくる**（「嗅覚トレーニングの教材」という口実）。距離感ゼロの嗅ぎ癖が一行で伝わるギミック。法則1・4 |
| ヒロインの属性 | ダウナー毒舌の留年生 | **二つ年上の同級生**。湊がわざと「先輩」と呼ぶと怒る、というお約束を入れ、後半で呼び名を「凪」に変える山場を作った。法則4・8 |
| 語り | 抒情寄りの静かな一人称 | **自虐ツッコミの一人称**に寄せて、化学の雑学をボケとして使う。抒情は泣かせ所だけに絞った。法則3・9 |
| 脇役 | 男友達・颯太 | **幼なじみの日下部小春（負けヒロイン）**に変更。カレーの章で関係が動き、病院へ行けと湊の背中を押す役も担う。法則7 |
| 甘さのイベント | 少なめ | 相合傘、白衣の貸し借り、肩に寄りかかって眠る、間接キス、呼び名の変化などを各章に配置した。法則8 |
| プロローグ | 匂いと記憶についての随筆 | **第七章の病室を先に見せる予告**（冒頭で最大の引きを提示）に変更し、随筆部分は短くした。 |
| 構成 | 全七章＋凪の幕間 | **全八章＋幕間二本**。日常ラブコメの章（第四章「バニリン」：三人の勉強会、パン屋、暗い閉架書庫）と、**小春視点の幕間**（夏祭りの夜の負けヒロインの独白）を追加。笑いの比率を上げ、選ばれなかった側の恋を描いた。法則7・9 |
| 続刊の余白 | 二冊目のにおいノート | それに加えて、**小春の恋の行方**と新入部員の伏線を残した。法則10 |
