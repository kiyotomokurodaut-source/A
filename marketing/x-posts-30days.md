## Day 1｜12/1（火）｜共通テスト直前：新しい教材

```
共通テスト直前期に、新しい参考書へ手を出すのは避けたいところです。定着しないまま本番を迎える可能性が高いからです。

例外は共通テスト形式の演習（過去問・予想問題）。新しい知識ではなく、形式と制限時間に慣れる作業です。
https://kurodaschool.jp/study-guides/kyotsu-test-final-stage/
```

## Day 2｜12/2（水）｜共通テスト直前：時間の型

```
大問ごとの制限時間は、解きながら決めるのではなく、解く前に決めておくもの。

「この大問は○分まで」「分からなければ印を付けて次へ」を科目ごとに書き出し、演習のたびに微調整を。1問へのこだわりが全体の得点を崩します。
https://kurodaschool.jp/study-guides/kyotsu-test-final-stage/
```

## Day 3｜12/3（木）｜模試の復習：答案を残す

```
模試の復習は、解説を開く前に自分の答案を残すことから。

正解した設問でも「偶然当たった」「根拠を説明できない」「時間を大きく使った」ものには印を付けます。復習のゴールは、きれいなノートではなく次の行動です。
https://kurodaschool.jp/study-guides/mock-exam-review/
```

https://kurodaschool.jp/contact/

## Day 5｜12/5（土）｜東大英語：120分の配分

```
東大英語の時間配分は、リスニングと見直しの枠を先に引いてから考えます。

120分から聞き取り30分と見直し5分を引くと、残りは85分。この85分に筆記と聞き取りの準備を収めます。英作文が長引いても、聞き取りの開始は待ってくれません。
https://kurodaschool.jp/study-guides/todai-english-time-allocation/
```

## Day 6｜12/6（日）｜中学受験：宿題が終わらない

```
中学受験の宿題が終わらないとき、「もっと速く」の前に原因を4つに分けます。

量が多い／考え方で止まる／計算・作業で時間がかかる／取りかかれない。

必須課題を自己判断で削らず、塾の先生と優先順位を確認してください。
https://kurodaschool.jp/study-guides/homework-priorities/
```

## Day 7｜12/7（月）｜過去問：時間内の答案

```
過去問は時間を計って解き、時間切れの後に書いた分は色を変えて区別します。

「解けるはずだった」と「時間内に解けた」は別の情報です。分割して解いた点数は、時間配分の失点が消えた点数なので、本番の目安になりません。
https://kurodaschool.jp/study-guides/kakomon-start-timing/
```

## Day 9｜12/9（水）｜東大数学：白紙再現

```
東大数学の復習は「解説を読んで分かった」で終えない。

当日：間違えた判断を1行で書く
翌日：問題だけ見て、条件整理と方針を再現
3〜7日後：数字や条件の違う類題で、同じ判断が使えるか確認

日程は残り日数に合わせて調整を。
https://kurodaschool.jp/study-guides/todai-math-review/
```

## Day 13｜12/13（日）｜共通テスト英語：時間不足

```
共通テスト英語で時間が足りないとき、読む速さの前に「止まる作業」を分けます。

単語・表現／一文の理解／情報の探索／選択肢の判断／時間配分。

原因は一つとは限りません。今回いちばん時間を使った作業から直します。
https://kurodaschool.jp/study-guides/kyotsu-english-time/
```

## Day 14｜12/14（月）｜過去問：失点の5分類

```
過去問の失点は5種類に分けると、次にすることが決まります。

知識不足→範囲を絞って想起・再テスト
読み落とし→根拠箇所を明示
方針選択→なぜその方針かを一文で
実行ミス→手順を固定し少量反復
検算不足→単位・符号・範囲を確認
https://kurodaschool.jp/study-guides/todai-kakomon-review/
```

## Day 17｜12/17（木）｜東大英語：英作文の見直し

```
英作文の見直しは順番が大事です。

①設問：質問に答え、立場・語数を満たすか
②論理：主張と理由が対応しているか
③英文：主語と動詞、時制、単複、冠詞

終了直前に、書けていた文を不慣れな難しい構文へ全面変更しないこと。
https://kurodaschool.jp/study-guides/todai-english-writing/
```

## Day 18｜12/18（金）｜中学受験：算数の比

```
赤と青の玉が50個で、比は3：2。両方に10個ずつ加えると比は？

赤40個・青30個で4：3。「同じ数を足したから3：2のまま」にはなりません。比が変わらないのは、同じ倍率で増減するとき。

答えだけでなく、式の理由を本人が説明できるかを確かめます。
https://kurodaschool.jp/junior-high-exam/
```

## Day 19｜12/19（土）｜保護者：模試の結果の日

模試の結果が返ってきた日、保護者ができることは、点数への感想を口にしないこと。

確認するのは結果ではなく予定で十分です。「次の模試はいつ」「見直しは終わったか」。食事や睡眠といった生活面の支えは、点数に関係なく淡々と続けてください。

## Day 21｜12/21（月）｜東大英語：リスニング

```
東大リスニングの誤答は、4種類に分けて復習します。

音：スクリプトを見れば知っている語なのに聞き取れない
意味：音は拾えたが処理が追いつかない
保持：後半で前の情報を失う
選択肢：設問・選択肢の比較で誤る

記録は一語で十分です。
https://kurodaschool.jp/study-guides/todai-listening/
```

## Day 22｜12/22（火）｜数学：解説は分かるのに解けない

```
数学の解説は分かるのに解けないときは、止まった場所を4つに分けます。

①条件の読み取り ②方針の選択 ③式の処理 ④条件と答えの照合

「発想力がない」とまとめず、自力で書けた最後の行と、書けなかった次の行を残してください。そこが質問の出発点です。
https://kurodaschool.jp/study-guides/math-self-solve/
```

## Day 25｜12/25（金）｜東大英語：失点原因から
