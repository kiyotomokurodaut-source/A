# LINE返信テンプレート

公式LINE（@670gzfpd）で使う返信の下書きです。【　】の部分を書き換えてから送ってください。

## 共通の方針（サイトの記載に合わせています）

- **急がせない**：「残りわずか」「今だけ」「本日中に」などの期限・残り枠の表現は使いません。サイトにも「即時返信や特定の曜日の空きを約束するページではありません」と書いてあります。
- **入塾は任意**：無料診断は「相談だけで終了しても構いません」。契約を前提にした書き方をしません。
- **実績の書き方**：「指導経験」と「合格実績」を混ぜません。指導事例ページ（/cases/）は、合格が確認できている事例と、難関分野の指導経験を分けて載せています（例：東大文科一類の生徒への指導は「指導経験の紹介」で、黒田塾からの合格実績ではありません）。返信で「東大に合格させた」などとは書かないでください。
- **成果を約束しない**：「成績が上がります」「合格できます」は書きません。サイトの記載どおり「回数を増やすだけで成績が上がるわけではありません」の立場です。
- **個人情報**：最初から成績表全体や氏名入りの答案は不要です。必要な部分だけ、個人情報を隠して送ってもらいます。
- **料金はサイトの表示どおり**：継続受講はすべて「月額・税込・月4セット分」。サイトにない割引や「無料」「無制限」の条件を作らないでください。振替・解約・支払い方法は「契約前に個別に確認」です。
- **返信の回数**：返事がない場合のこちらからの連絡は、3日後と7日後の2回までにします。7日後の連絡の後は、相手から連絡があるまで送りません。

## 2. 無料診断の後：プランの提案

診断の内容に合わせて、該当するパターンを1つだけ選んで送ります。複数のプランを並べて迷わせるより、理由を添えて1つ提案し、ほかの選択肢は一言だけ添える形です。

```
【お名前】様

本日はお時間をいただき、ありがとうございました。黒田です。
面談で整理した内容を、まとめてお送りします。

■ 現在地
【例：英語は時間内に最後の大問まで届かず、時間を追加すれば根拠を示して解ける問題が多い】

■ 一番のボトルネック
【例：時間配分（大問ごとの見切りの基準がない）】

■ 最初の7日間に取り組むこと
1. 【例：共通テスト形式を1回、大問ごとの制限時間を先に決めて解く】
2. 【例：時間切れ後に書いた答案を色で分け、時間をかければ解けた問題から解き直す】
3. 【例：解き直しで止まった箇所を、模試の復習シートに記録する】

【希望された場合】90日学習ロードマップ設計キット（8ページのPDF）もお送りします。
```

### 2-C 授業と自習の進め方の両方を見たい場合 → 面談＋授業（週1回）

```
■ ご提案
【科目】の授業と、授業後の演習・復習計画の両方を確認するのがよいと考えています。その場合は「面談＋授業（週1回）」のプランです。

・面談＋授業（週1回）：月額54,990円（税込・月4セット分）
・1セット＝面談30分＋授業90分。月4セット
・授業で扱った内容に加えて、次回までの演習・復習計画も整理します
・LINEでの質問対応、オーダーメイド教材の作成費、答案添削（月4通まで）を含みます

まずは面談のみ（月額24,000円）で計画から整える、という選び方もあります。ご検討のうえ、ご質問があればお知らせください。
```

### 2-D 複数科目の授業や、答案確認の頻度が必要な場合 → 面談＋授業（週2回／週3回）

```
■ ご提案
【例：数学と英語の記述】の両方で答案を確認する必要があるため、授業を週2回に分ける形を考えています。

・面談＋授業（週2回）：月額79,990円（税込・月4セット分）
　面談30分＋授業90分×2回を1セットとして月4セット。答案添削は回数無制限、保護者面談が月1回含まれます。
・面談＋授業（週3回）：月額104,990円（税込・月4セット分）
　授業回数を多く確保したい場合のプランです。上記に加えて、優先のLINE質問対応と受講外科目の学習計画管理を含みます。

ただ、回数を増やすだけで成績が上がるわけではありません。復習に使える時間が残るかを一緒に確認したうえで決めたいと思います。週1回から始める選択肢もあります。
```
