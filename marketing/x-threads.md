## スレッド1：共通テスト直前期、やること・やらないこと（7投稿）

**1/7**
```
共通テスト直前期の役割は、範囲を広げることではありません。積み上げてきた力を、本番の得点に変える仕上げの時期です。

やることを絞るために、まず「やらないこと」から確認します。（スレッドにまとめます）
```

**2/7**
```
やらないこと①：新しい参考書に手を出さない。

新しい教材は、解き方を覚え、類題で確かめ、自分のものになるまで時間がかかります。

例外は共通テスト形式の演習（過去問・予想問題）。形式と制限時間に慣れる作業なので、直前期でも必要です。
```

**3/7**
```
やらないこと②：勉強法を変えない。

SNSで見かけた他人の勉強法を、この時期に取り入れるのも避けたいところです。合うかどうかを試す時間は、直前期にはありません。

今のやり方の「精度を上げる」ことに時間を使ってください。
```

**4/7**
```
やること①：週1回、時間を測って本番形式で解く。

目的は点数ではなく、時間配分と解く順番の確認です。「この大問は○分まで」「分からなければ印を付けて次へ」を、解く前に決めておきます。

解き直しまで終えて、初めて1回分の演習です。
```

**5/7**
```
やること②：解き直しは「時間をかければ解けた問題」から。

順番や見切りの基準を変えれば取り戻せる得点だからです。

今の段階で手も足も出ない問題は無理に追わず、取れる問題を確実に取る練習へ時間を回すと、合計点は安定します。
```

**6/7**
```
やること③：本番後の自己採点に備える。

自己採点がずれる一番の原因は、自分の解答を問題冊子に残していないこと。選んだ選択肢や途中式を書き残す習慣を、今の演習から。

得点調整は当てにせず、素点で積み上げてください。
```

**7/7**
```
やること④：起床時刻を固定し、生活リズムを本番の時刻に寄せる。

不安が増えるのは、この時期では普通のことです。「今日やることはこれ1つ」と決めて終える、の繰り返しで。

全文はこちら。自分の場合の優先順位は、無料の30分診断でも整理できます。
https://kurodaschool.jp/study-guides/kyotsu-test-final-stage/
```

## スレッド2：模試・過去問の復習を「次の得点」に変える（7投稿）

**1/7**
```
模試や過去問を解いた後、解説を読んで終わっていませんか。

復習では「何点だったか」に加えて、「どの設問で、何が足りず、次に何をするか」を決めます。復習のゴールは、きれいなノートではなく次の行動です。（スレッド）
```

**2/7**
```
①解説を開く前に、自分の答案を残す。

時間内に書いた答案と、時間切れの後に書いた分は色を変えて区別します。

正解した設問でも「偶然当たった」「根拠を説明できない」「時間を大きく使った」ものには印を付けます。
```

**3/7**
```
②失点を「ケアレスミス」の一言で終わらせない。

・知識を取り出せない
・方針を選べない
・計算・処理で崩れる
・読み取り・記述を外す
・時間配分で未完になる

一つに決められないときは、最初に確認する原因を選び、ほかの候補をメモします。
```

**4/7**
```
③「数学を復習する」を、実行できる課題に変える。

×「解説を読み直す」
○「定義域を変えた2問で、頂点と両端を調べる理由まで説明する」

何を何問やるかだけでなく、「何ができれば今回の復習を終えるか」まで書きます。
```

**5/7**
```
④失点の大きさだけで、復習の順番を決めない。

8点落とした未習の発展問題と、2点落とした既習の基本問題。8点の方を必ず先に復習するとは限りません。

「基本を確認すれば進める」「繰り返しつまずく」「今は質問が必要」に分けます。
```

**6/7**
```
⑤解説を読んだ直後ではなく、数日おいてから自力で解き直す。

直後に解けても、解答を覚えていただけかもしれません。数値や条件を変えた類題で、同じ考え方が使えるかを確かめます。

過去問の価値は、年度数より再発防止の精度で決まります。
```

**7/7**
```
失点を記録・集計できる無料シートは、こちらのページで使えます（入力内容は外部に送信されません）。

自分の答案で原因を切り分けにくいときは、30分の無料受験戦略診断で一緒に整理します。
https://kurodaschool.jp/study-guides/mock-exam-review/
```

## スレッド3：東大英語120分、配分と復習（7投稿）

**1/7**
```
東大英語は「長文をたくさん読む」「過去問を何年分も解く」だけでは、改善点が散らばります。

まず失点を、読解・要約・英作文・リスニング・時間配分に分け、次の一題で直すことを決めます。（スレッドで整理します）
```

**2/7**
```
時間配分：リスニングの時間帯は自分で動かせません。

だから配分は、聞き取り30分と見直し5分を先に確保してから。120分から引くと残りは85分です。

※実際の時間帯は、受験年度の実施要領と当日の案内を優先してください。
```

**3/7**
```
要約：いきなり和訳を短くしない。

①字数・書き出しの指定を確認
②各段落の働きを書く
③本文の主張を一文に
④具体例を整理
⑤日本語で書く
⑥最後に字数を数える

本文にない結論を足さないこと。要約は賛否を述べる英作文ではありません。
```

**4/7**
```
英作文：英語を書く前に、設問への答えを一文にする。

見直しは、①設問（立場・語数）②論理（主張と理由の対応）③英文（主語と動詞、時制、単複、冠詞）の順で。

難語の数で答案の良さを判断しないでください。
```

**5/7**
```
リスニング：「聞こえない」を4種類に分ける。

音／意味／保持／選択肢

問題番号の横に一語だけ書き、3回分たまったら、最も多い原因を次週の練習テーマにします。全体を何十回も流すより、失点位置を短く切って聞き直します。
```

**6/7**
```
過去問1回を、次の1週間に変える手順。

①答案を保存（根拠が曖昧な正解にも印）
②失点の主因を一つに仮分類
③48時間以内に同種の短い課題を1つ
④1週間後に再テスト

過去問を丸ごともう一度解く必要はありません。
```

**7/7**
```
全部弱いときは、課題を5つ同時に始めず、得点に近い一箇所から直します。

各論（要約・英作文・リスニング・時間配分）へのリンクはこちらにまとめています。答案を見ながらの整理は、無料の30分診断でも。
https://kurodaschool.jp/study-guides/todai-english-strategy/
```

## スレッド4：東大数学、解説を読んで終わらない復習（6投稿）

**1/6**
```
数学の解説を読むと納得できるのに、答案用紙を前にすると最初の式が出てこない。

大切なのは、翌日、問題だけを見て最初の一手を説明できるかです。東大数学の誤答を5段階に分けて復習する方法をまとめます。（スレッド）
```

**2/6**
```
誤答の5段階：

1. 条件整理で止まった
2. 方針を選べなかった
3. 方針は合っていたが計算で崩れた
4. 論証が不足した
5. 時間配分で解き切れなかった

時間不足をすべて「計算速度」の問題にしないことが重要です。
```

**3/6**
```
「方針を選べなかった」とき。

解答を覚えるのではなく、「この条件があるから、この道具を候補にした」と説明します。

例：二次関数の最大・最小なら、頂点と定義域の位置関係を調べたいから平方完成を選ぶ。「できる」から「選べる」へ。
```

**4/6**
```
「論証が不足した」とき。

必要条件だけ示して十分性を確認していない、場合分けを閉じていない、範囲を言葉で結論していない。

上限を出すだけでは「範囲の証明」は終わりません。その値を実際にとる組を作れるかまで確かめます。
```

**5/6**
```
白紙再現の一例：

当日：間違えた判断を1行で書く
翌日：問題だけ見て、条件整理と方針を再現
3〜7日後：条件の違う類題で同じ判断が使えるか
2〜3週間後：過去問・模試の別問題で再確認

日程は残り日数に合わせて調整してください。
```

**6/6**
```
自作例題と、東大理系数学2026第3問の図解はこちら。

自分の答案のどこで止まっているかを一緒に確かめたい方は、30分の無料受験戦略診断へ（公式LINEで「面談希望」）。
https://kurodaschool.jp/study-guides/todai-math-review/
```

## スレッド5：保護者向け、模試の判定と併願校（6投稿）

**1/6**
```
模試の結果が返ってくるたびに、家庭の空気が点数に左右される。受験生のいるご家庭では、よくあることです。

判定や偏差値は、仕組みを知っていれば落ち着いて読めます。直前期の保護者向けにまとめます。（スレッド）
```

**2/6**
```
判定は「合格の約束」でも「不合格の宣告」でもありません。その模試を受けた時点の得点と、合格ボーダーの目安との差から出した目安です。

E判定の意味は「今回の得点のままでは、ボーダーに届いていない」。それ以上でも以下でもありません。
```

**3/6**
```
結果が返ってきた日、保護者ができること。

点数への感想を口にしない。確認するのは予定で十分です。「次の模試はいつ」「見直しは終わったか」。

食事や睡眠といった生活面の支えは、点数に関係なく淡々と続けてください。
```

**4/6**
```
志望校を変えるかどうかは、感情ではなく材料で話します。

①判定の推移（1回ではなく複数回）
②残り期間
③科目ごとの失点の中身
④本人の意思

1回の判定で志望校を変える判断はしないでください。
```

**5/6**
```
併願校は、遅くとも12月中に確定を。

決める順番は、日程（入学金の納入期限を含む）→受験料と入学金の総額→レベルの配分。

日程と費用は保護者、進学の意思は本人、と役割を分けて話し合ってください。
```

**6/6**
```
詳しくはこちら。

判定の読み方や併願校の考え方を整理したい場合、無料受験戦略診断（30分・オンライン）は保護者の方だけでも参加できます。公式LINEで「面談希望」と送ってください。
https://kurodaschool.jp/study-guides/parents-mock-exam-hantei/
```
