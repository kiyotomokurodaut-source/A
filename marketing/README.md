# SNS投稿キット（受験直前期：2026年12月〜2027年1月）

X（@kurodaschool）から、公式LINEの無料受験戦略診断（https://kurodaschool.jp/contact/）へ来てもらうための投稿セットです。オーナー（黒田）が自分で投稿する前提で、コピーしてそのまま使えるようにしてあります。

## ファイル

| ファイル | 中身 | 使い方 |
| --- | --- | --- |
| `x-posts-30days.md` | 12/1〜12/30の毎日の投稿30本 | 毎日1本、コードブロックの中身をコピーして投稿 |
| `x-threads.md` | 5〜7投稿のスレッド5本 | 週1本。1本目を投稿し、残りを返信でつなげる |
| `line-followup-templates.md` | LINEの返信テンプレート | 「面談希望」への返信、診断後の提案、3日後・7日後の再連絡、教材購入のフォロー |
| `REVENUE-PLAN.md` | 収益計画（既存） | 必要な件数の目安。下の記録表の目標値に使う |

## 作るときに守ったこと（投稿を書き足すときも同じ）

- **サイトに書いてあることだけを使う。** すべての投稿のリンク先に、その内容の根拠があります。
- **「指導経験」と「合格実績」を混ぜない。** 指導事例ページは、合格が確認できている事例と、難関分野の指導経験を分けて載せています。たとえば東大文科一類の生徒への指導は「指導経験の紹介」で、黒田塾からの東大合格実績ではありません。「東大合格者を輩出」「合格率○%」のような書き方はしないでください。
- **書いていないもの**：合格実績の数字、生徒の声・体験談、生徒数、割引・キャンペーン、期限、残り枠。教材の「友だち割」はサイトに載っている条件ですが、Xでは使っていません。
- **成果を約束しない。** 「これで上がる」「受かる」は書きません。
- 料金を書くときは、サイトと同じ「月額・税込・月4セット分」を必ず添えます（この30日分の投稿では料金に触れていません。料金は LINE の提案文で伝えます）。

## 文字数について

X は全角1字を2、半角1字を1として数え、上限は280（＝全角140字）です。URLは長さに関係なく23（＝全角11.5字）として数えます。
すべての投稿とスレッドの各投稿は、この数え方で上限以内に収まることを確認済みです（いちばん長いもので 266/280）。本文はURLを除いて全角126字以内です。
書き換えるときは、X の入力欄の残り文字数の表示で確認してください。

## 投稿前の準備（1回だけ）

1. **プロフィール文**（例。160字以内）
   ```
   東京大学教育学部卒・黒田清友のオンライン個別指導「黒田塾」。英語・数学・学習計画の「なぜ」を毎日投稿します。30分の無料受験戦略診断は公式LINEで「面談希望」と送ってください。入塾は任意です。
   ```
2. **プロフィールのリンク**：`https://kurodaschool.jp/contact/`（診断の案内ページ。LINEの友だち追加ボタンがあります）
3. **固定ポスト**：スレッド1（共通テスト直前期）の1本目を固定。1月の共通テスト後は、スレッド3（東大英語）かスレッド4（東大数学）に替える。
4. LINE公式アカウントの「あいさつメッセージ」に、`line-followup-templates.md` の 1-A を短くしたものを入れておくと、返信までの間に何を書けばよいかが伝わります。

- **時間帯**：最初の2週間は、朝（7時台）と夜（21〜22時台）を交互に試し、プロフィールへのアクセスが多かった方に寄せてください。受験生と保護者で見る時間帯が違う可能性があるため、保護者向け（Day 8, 19 とスレッド5）は夜を推します。どちらも仮説なので、下の表で確かめてください。
- **CTA の頻度**：4日に1回（Day 4, 8, 12, 16, 20, 24, 28）。これ以上増やすと宣伝の印象が強くなるので、増やす場合も3日に1回までにしてください。
- **返信・引用**：投稿への質問には、投稿と同じ内容の範囲で答え、詳しくは診断へ、と案内するだけで十分です。個別の成績や答案はXで受け取らず、LINEで受け取ってください。

## LINEに届いたら

1. 「面談希望」→ `line-followup-templates.md` の 1-A〜1-C で返信し、1-D で日程を確定
2. 面談後 → 2-0 ＋ 2-A〜2-F から1つ ＋ 2-G
3. 返事がない → 3日後に 3-A / 3-C、7日後に 3-B / 3-D。**それ以上は送らない**
4. 教材の相談 → 4-A〜4-D

最初の返信で「何で黒田塾を知りましたか（任意）」と聞いておくと、Xからの相談かどうかを数えられます（/contact/ の相談文作成ツールにも「X（Twitter）」の選択肢があります）。

### 見る割合（月末に計算）

| 段階 | 計算 | 目安（REVENUE-PLAN.md の仮定） |
| --- | --- | --- |
| 投稿 → プロフィール | プロフィールへのアクセス ÷ インプレッション | まず数字を取る |
| プロフィール → LINE追加 | うちXから ÷ プロフィールへのアクセス | まず数字を取る |
| LINE追加 → 面談 | 面談 ÷ LINE友だち追加 | 30% |
| 面談 → 契約 | 契約 ÷ 面談 | 30% |

REVENUE-PLAN.md の目標は「月に友だち追加 約25件 → 面談 7件 → 契約 2件」です。どの段階で止まっているかで、次に直すものが変わります。

- インプレッションが少ない → 投稿の時間帯を変える、反応のよいテーマ（下の表で上位のもの）を増やす
- プロフィールへのアクセスはあるのに LINE追加が少ない → プロフィール文と固定ポストを見直す
- LINE追加はあるのに面談が少ない → 最初の返信（1-A）を短くする、日程の候補をこちらから出す
- 面談はあるのに契約が少ない → 提案（2-A〜2-F）が相手の課題に合っているかを見直す。無理に勧めない

## 投稿前に確認すること

- リンク先のページが公開されていること（kurodaschool.jp が本番で表示されること。REVENUE-PLAN.md の「いまの最大の障害」を参照）。
- 共通テストの日程・試験時間・東大英語のリスニングの時間帯などは、受験年度の公式の案内を優先します。投稿は「目安」「練習条件」として書いています。
- /contact/ の特典の書き方（「教材7種＋5大特典は保護者同席が条件」と「90日学習ロードマップ設計キットは面談後の希望者に送付」）がそろっているかを確認してください。投稿（Day 28）とLINEテンプレートでは、90日キットだけに触れています。
