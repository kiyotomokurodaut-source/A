# 理解する古文単語帳 500（図解版）

大学入試の古文単語500語を、**漢字・語源・由来・コアイメージ**から理解して覚えるための単語帳。
Web版（赤シート・暗記カード・4択クイズつき）と、A4の印刷用PDFを同じデータから作る。

- `dist/kobun-tango-500.html` … Web版（1ファイル。ブラウザで開くだけで使える）
- `dist/kobun-tango-500.pdf` … 印刷版（A4・約210ページ）

## 構成

### 1語のカード

見出し語（歴史的仮名遣い）／漢字表記／現代仮名遣いの読み（自動変換）／品詞／重要度★／意味（①が最重要・赤字）／
語構成の分解図（赤＝意味の核、灰＝形を作る要素）／由来／コアイメージ／類義語・対義語・関連語（本書内はリンク）／
例文（古典本文は出典つき、それ以外は「作例」と明記）と現代語訳（赤字）／入試ポイント／古今異義の注意／3回チェック欄。

### 演習

- 各DAYの最後に**確認テスト**（意味の4択10問・例文の傍線部訳5問・漢字と語源5問）
- 5DAYごとに**総合演習**（100語から20問）
- Web版：赤シートモード、暗記カード（覚えた／あやしい／まだ を記録し、弱点から出題）、4択クイズ、検索、
  目次に DAY ごとの「覚えた」割合を表示。記録はそのブラウザの localStorage に保存。

## ビルド

```sh
python3 build.py --check      # dist/kobun-tango-500.html を作り、500語・各DAY20語・図の語の存在などを検査
node tools/make_pdf.cjs       # dist/kobun-tango-500.pdf（Playwright の Chromium を使う）
```

`build.py` は標準ライブラリだけで動く。PDF 作成時の Google Fonts は `curl` で取得して `.fontcache/` に保存する。

## データの書き方

単語は `data/*.txt`（ファイル名順に読む）。書式はファイル先頭のコメントを参照。

```
@ あさまし | 浅まし | 形シク | 3          見出し | 漢字 | 品詞 | 重要度
= 驚きあきれるほどだ・意外だ／情けない      意味（／区切り）
b *あさむ|驚きあきれる + し|形容詞化        語構成（* が核）
c 予想外のことに目を丸くする                コアイメージ
o …                                          由来
r めざまし      a …      d あさむ（動）      類義・対義・関連
e 本文〔あさましき〕…|現代語訳|出典          例文（出典なしは作例）
m いやしい・さもしい                         現代語の意味（古今異義語になる）
p …                                          入試ポイント
y …                                          読み（自動変換が合わない語だけ）
```

語源ファミリー図・マップ類の内容は `sections.py`、見た目は `src/style.css`、Web版の機能は `src/app.js`。
