# AIの頭の中（3D教材デモ）

大規模言語モデルが文章を作る流れを、3Dで見せる教材デモです。
`index.html` 1枚で動きます（three.js とフォントは CDN から読み込み）。

| 章 | 見せるもの |
| --- | --- |
| 01 言葉の宇宙 | 単語が「意味の座標」として星雲を作る（埋め込み空間） |
| 02 座標に変える | 入力文がトークンに分かれ、それぞれの座標を引き出す |
| 03 注意でつなぐ | 6枚の層でアテンションの光の束が張られていく（後ろの語は見えない） |
| 04 次の一語 | 最後のトークンが宇宙の一点を指し、確率の高い語が選ばれて文に加わる |

## 使い方

- ブラウザで `index.html` を開くと、自動で最初から再生します。
- ドラッグで回転、ホイール／ピンチで拡大。
- **講義モード**（`H` キー）：操作パネルを消し、大きな字幕だけにします。セミナーでの投影向け。
- `Space` 一時停止、`←` `→` 章の移動、「速度 2×」で早送り。
- 「文を変えて試す」：台本付きの4文のほか、自由入力（簡易モデル・3語まで）。

## 編集するところ

`index.html` の `CONFIG`（スクリプト冒頭）で、最後に出る案内ボタンの
リンク先・文言・講師名を変えられます。台本付きの文は `PRESETS` にあります。

## 表示内容について

座標・確率・注意の強さは、説明のためにこの画面の中で計算した模擬値です。
実際のAIモデルの内部値ではありません（画面にも明記しています）。
販売ページや広告に使うときも、この区別を崩さないでください。
