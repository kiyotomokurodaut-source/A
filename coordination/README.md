## 運用ルール

1. 作業したら、自分の担当する状況ファイルに **日時つきで追記** する。
2. 書くのは **実測値のみ**。スコア・順位・件数・順位変動は、公式結果や実画面で確認した値だけを書く。推測や水増しは禁止。未確認のものは「未確認」と明記する。
3. **他者の担当領域を上書きしない。** 既存の行を書き換えず、訂正が必要な場合は新しい行で訂正内容を追記する（競合したら新しい行で訂正する）。
4. 締切が近いものを優先する。優先順位の変更は、変更した人が理由とともに追記する。
5. このボードには **個人情報（住所・電話番号・生年月日・メールアドレス・認証情報）を書かない**。書いてよいのは作業状況・数値・締切・担当分担レベルの情報だけ。
6. 本人（黒田さん）でなければできない手続き（ログイン・本人確認・口座登録など）が発生したら、作業を止めてその旨をボードに記録する。
