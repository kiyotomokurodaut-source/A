条件が変わると解けない

計算・場合分け・答案で失点する

最初に崩れた行、見落とした条件、答案で不足した理由を分けて確認します。

登録不要のオリジナル例題

答えより先に、方針を選ぶ理由を

y = (x − 2)² + 1

x ≥ 0 のときの最小値は何ですか。では x ≥ 3 のときはどうなりますか。頂点が範囲に入るかを、理由に使ってください。

解答と、確認するポイントを開く

頂点は x = 2、y = 1。x ≥ 0 では頂点が範囲に入るため最小値は1。x ≥ 3 では頂点が範囲外で、x = 3 が頂点に最も近いので最小値は2です。

同じ式でも、変わった条件が方針にどう影響するかを説明します。正解の数値だけでなく、頂点と定義域を確認する理由が言えるか確かめてください。

条件・最初の一手・解き直しの詳しい見本を読む

黒田清友が直接担当します

東京大学教育学部卒。個別授業、答案の確認、学習計画を担当します。講師紹介と実際の指導事例を確認できます。

30分の無料相談で、まず整理する3つのこと

01 現在地

どこで止まっているか

今の教材や答案をもとに、知識・考え方・復習・課題量のどこを先に確認するか整理します。資料がそろっていなくても相談できます。

02 次の一週間

何を、どこまで行うか

教材・範囲・終わりの条件を具体的にします。すべての問題を30分で解説する相談ではありません。まず取り組む課題を決めます。

03 必要な支援

授業か、学習管理か

必要な支援と料金を確認します。5つの公開プランから検討できます。入塾は任意で、無理な勧誘は一切ありません。

LINEで「面談希望」を送る → 既存の事前フォームと候補日時の提出 → 黒田から確定日時をご連絡。候補提出だけでは予約確定になりません。

約30分・オンライン。保護者からの相談、再相談も歓迎です。教材7種＋5大特典は保護者同席の面談参加後にご案内します。追加・フォーム回答だけでは届きません。以前の条件で申込済みの方には当時の案内に沿って対応します。

必要な支援と料金を、先に確認できます

すべて税込・月4セット分。面談は30分、授業は90分。授業のみプランに定期面談は含みません。添削、質問対応、教材費などの条件は料金ページの内訳をご確認ください。
