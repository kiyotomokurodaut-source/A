東大文系数学の方針選択を、自作例題と答案で練習する

解説制作：黒田塾（AI補助）｜指導担当：黒田清友｜更新：2026年9月26日

東大文系数学の演習では、答えを再現するだけでなく、なぜその変数・場合分け・式変形を選んだのかを説明できるか確かめます。このページは出題予想ではなく、方針選択を練習するための自作例題と答案点検の手順です。実際の入試問題や大学の公式採点基準ではありません。

このページで分かること
  1. 最初に「条件・目標・つなぐ操作」を書く
  2. 自作例題：パラメータと定義域を分ける
  3. 誤答を、原因まで戻して直す
  4. 条件変更：解答を覚えたか、判断を使えるか
  5. 難しい過去問に戻すときの点検表

最初に「条件・目標・つなぐ操作」を書く

問題を見てすぐ計算を始めると、定義域の制限やパラメータの役割を見落としやすくなります。次の三つを区別してください。

解答を始める前の三つの確認
項目書き出す内容この後の例題の場合
条件変数の範囲と、使える等式・不等式−1 ≤ x ≤ 2、a は実数
目標何を求めるか。何についての場合分けかx についての最小値を a で表す
つなぐ操作条件と目標の関係が見える形にする平方完成し、頂点の位置を区間と比較する

「最大・最小だから微分」と決めつける必要はありません。式が二次式で、平方完成から頂点と定義域の関係が読めるなら、それが短い道筋になります。微分を使う場合でも、最後に定義域と端点を確認する点は同じです。

自作例題：パラメータと定義域を分ける

問題　a を実数とする。−1 ≤ x ≤ 2 において、f(x) = x² − 2ax の最小値 m(a) と、その最小値をとる x を求めよ。

この問題は方針選択を確認する基礎例です。東大入試全体の難度を代表する問題ではありません。

まず自分で考える

ここで動かすのは x です。a はひとまず固定し、その値によって答えがどう変わるかを考えます。「x と a を同時に自由に動かして最小にする問題」と読み替えてはいけません。

発想・場合分け・答案を順に確認する

1．平方完成すると、何が分かるか

f(x) = (x − a)² − a²

a を固定したとき、−a² は定数です。したがって f(x) を最小にするには、区間 [−1, 2] の中で (x − a)² を最小にします。これは「区間内で a に最も近い x を選ぶ」という意味です。

2．場合分けの境界はどこから出るか

頂点の x 座標は a です。頂点が区間の左、区間内、区間の右にある三つの場合で、a に最も近い区間内の点が変わります。境界の −1 と 2 は定義域の端点であり、思いつきで決める値ではありません。

最小値をとる点と最小値
a の範囲最小となる xm(a)
a < −1−11 + 2a
−1 ≤ a ≤ 2a−a²
a > 224 − 4a

3．そのまま答案にする

f(x) = (x − a)² − a² である。−1 ≤ x ≤ 2 における f(x) の最小値は、この区間内で a に最も近い点で得られる。a < −1 のとき x = −1 で m(a) = 1 + 2a。−1 ≤ a ≤ 2 のとき x = a で m(a) = −a²。a > 2 のとき x = 2 で m(a) = 4 − 4a。以上が求める最小値と、そのときの x である。

4．境界で確かめる

a = −1 では 1 + 2a = −1 と −a² = −1 が一致します。a = 2 では −a² = −4 と 4 − 4a = −4 が一致します。境界で式が一致することは点検になりますが、それだけで場合分け全体が証明できるわけではありません。

誤答を、原因まで戻して直す

誤答1：いつでも最小値は −a² とする

平方完成そのものは正しくても、等号を満たす x = a が定義域に入るとは限りません。たとえば a = 3 のとき、x = 3 は区間外です。正しい最小値は x = 2 で −8 であり、−9 ではありません。式だけでなく「その x を実際に選べるか」を答案に戻します。

誤答2：端点だけを比較する

端点の比較だけで最小値が決まるのは、区間内にさらに小さい値がないと確認できる場合です。a = 0 なら f(0) = 0 で、端点の f(−1) = 1、f(2) = 4 より小さくなります。頂点を候補から落とさないでください。

誤答3：最小値だけ書き、達成する点を書かない

この例題は「最小値をとる x」も要求しています。何を求める設問だったかを最後に読み直し、m(a) と x の両方を答えます。途中式が正しくても、要求の一部が抜けていれば答案は未完成です。

条件変更：解答を覚えたか、判断を使えるか

類題　a を実数とし、0 ≤ x ≤ 3 における g(x) = x² − 2ax + 2 の最小値を求めてください。

類題の解答と、共通する判断を見る

g(x) = (x − a)² + 2 − a² と平方完成します。a < 0 では x = 0 で最小値 2。0 ≤ a ≤ 3 では x = a で最小値 2 − a²。a > 3 では x = 3 で最小値 11 − 6a です。

変わったのは区間の端点と定数項です。「区間内で頂点に最も近い点を選ぶ」という判断は変わりません。境界 a = 0 で 2、a = 3 で −7 となることも確認できます。

翌日の確認では解答を隠し、場合分けの境界がなぜ 0 と 3 なのかを一文で説明してください。答案の丸暗記ではなく、区間と頂点の位置関係を再現できるかを見ます。

難しい過去問に戻すときの点検表

この例題で使った点検は、より複雑な問題でも「使った条件」「実現可能性」「場合分けの漏れ」「設問への答え」を見直す入口になります。ただし、一つの基本例が解けたことだけで東大数学への対応が完成したとは判断しません。

答案に残すのは、条件から根拠をもって導いた内容です。部分点の配点は大学がこのページ向けに公表したものではなく、「この式で何点」と保証することはできません。無関係な式を大量に並べるより、到達した結論と未証明の箇所を区別してください。

必要条件と十分条件を点検する東大数学の復習法へ進み、実際の過去問の見直しには過去問復習の記録シートを使えます。授業で方針の立て方を確認したい場合は東大対策の個別指導案内を確認してください。
