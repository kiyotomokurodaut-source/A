# 出版企画書

## 1. 書名
**答えがタダになる時代の勉強法**

## 2. サブタイトル
**主導権を握ったまま、AIと並走する学び方**

## 3. 企画概要
生成AIによって、答えと解説はいつでも、ほぼ無料で手に入るようになった。それなのに「AIで勉強すると学力が落ちる」という研究も出ている。トルコの高校約1,000人を対象にした実験（PNAS、2025年）では、汎用AIで演習した生徒は練習中の正答が48％増えたが、AIを外した試験では17％下がり、しかも本人は下がったことに気づいていなかった。一方、答えを出さずにヒントを出すよう設計されたAIでは、成績は下がらなかった。

本書は、この逆説を出発点に、**「学習のどの苦労をAIに渡し、どの苦労を自分に残すか」を判断する原理**と、**主導権を握ったままAIと並走する具体的な方法**を示す一般向けの学習法の本である。その方法とは、自分の考えをまず何も見ずにノートへ書き殴り、それをAIに整理させ（内容は足させず、誤りと抜けは別に指摘させる）、最後に見比べ・確かめ・閉じて再現して自分の頭に取り戻す「並走ノート」である。認知心理学・学習科学の研究（検索練習、間隔効果、交互練習、認知負荷、転移、メタ認知）を、受験指導の現場の具体例と組み合わせ、高校生・受験生・社会人学習者・保護者・教員が、翌日から学び方を変えられる形にまとめた。

## 4. この本を書く理由
著者は東京大学教育学部で教育を学び、塾講師として5年間、中学受験から大学受験まで、授業と学習管理を一人で直接担当してきた。関西の有名中学への合格まで並走した中学受験生、医学部を目指す受験生、英語がほぼゼロの状態から関西の外国語大学に合格した生徒など、出発点も目標もまったく異なる生徒を指導するなかで、同じ原理——「学力は、本人の頭が働いた分しか残らない」——が繰り返し現れることを見てきた。生成AIの普及で、生徒の学び方は目に見えて変わった。宿題は短時間で「終わる」ようになったが、それが学力の伸びにつながっているとは限らない。保護者は「AIに頼るな」と言うが、その理由を説明できない。教員は、宿題やレポートが評価として機能しなくなったことに戸惑っている。

こうした悩みに対して、「AIを使え」というハウツー本も、「AIは危険だ」という警告の本も、答えにはなっていない。必要なのは、**なぜ、どこでAIを使ってはいけないのか**を学習の原理から説明し、そのうえで**主導権を渡さずにAIの力を借りる方法**を示せる本である。研究の知見と現場の実感の両方を扱える立場から、この本を書く。

## 5. 本書の特徴
1. **実践の型は一つ——「並走ノート」**：書き殴る（AIを使わない）→AIに整理させる（内容は足させない）→取り戻す（比べる・検証する・閉じて再現する）。問いと材料と最終判断を自分が握り、AIが最も得意な「組み立て」だけを手伝わせる。受験生から社会人まで、どの教科でも同じ型で使える。
2. **判断基準も一つ**：「引き算テスト——その苦労をAIに任せて消したとき、身につけたい力も一緒に消えるか」。この問い一つで、AIを使ってよい場面と、いけない場面を見分けられる。
3. **学習を見るための独自の枠組み**
   - 学力の三つの距離（分かる→思い出せる→使える）
   - 作業台と引き出しと倉庫（なぜ検索できる知識を覚えるのか）
   - 思考の五つの動詞（見抜く・選ぶ・組み立てる・確かめる・問う）
   - 誤答の四分類（知識の欠落／想起の失敗／方針の誤り／実行のミス）
   - AI利用の六つの型（答えを得る／説明させる／問題を作らせる／添削させる／問い返させる／書かせる）
   これらが章をまたいで接続し、一つの体系になっている。
4. **反対説から逃げない**：「暗記はもう要らない」「AIで効率よく学べる」「まず自分で考えよ、は本当か」などの反論を正面から検討する。
5. **エビデンスに誠実**：研究の条件と限界、再現されなかった研究（グーグル効果）、査読前の研究（MITの脳波研究）であることまで明記。話題性だけの主張に頼らない。
6. **著者自身の指導経験**：中学受験の解き直しの設計（第5章）、医学部受験生との「方針を先に言葉にする」授業（第2章）、英語をゼロから立て直した生徒の指導（第3章）を、学習科学の知見と結びつけて紹介する。
7. **全教科・全読者に具体例**：数学・英語・国語・社会・理科、資格試験、大学のレポートまで。巻末にAIへの頼み方の実例集、誤答ノート、一週間の学習設計シート。

# 書籍紹介文

数学の宿題で手が止まったら、問題を撮影してAIに送る。数秒後には、答えと丁寧な解説が返ってくる。答えと説明は、ほとんどタダになった。

では、学力は上がったのだろうか。

2025年、米国科学アカデミー紀要（PNAS）に、ある実験の結果が掲載された。トルコの高校生約1,000人のうち、汎用の対話AIを使って数学の演習をした生徒は、練習中の正答がAIなしの生徒より48％多かった。ところが、AIを外した試験では、成績が17％低かった。しかも生徒たちは、自分の成績が下がったことに気づいていなかった。一方、答えを教えず、ヒントだけを出すように設計されたAIを使った生徒は、成績を落とさなかった。同じ年、ハーバード大学では、学習科学に基づいて設計されたAIチューターが、最良とされる能動的な授業を上回る学習効果を示している。

AIは学力を上げもするし、下げもする。分かれ目は、AIの性能ではない。考える工程を、学習者が自分で担ったか、AIが肩代わりしたかである。

本書は、東京大学教育学部で教育を学び、5年間にわたって中学受験から大学受験までの生徒を直接指導してきた塾講師が、認知心理学と学習科学の研究と、自身の指導経験をもとに、「AIに任せていいこと」と「自分の頭でしかできないこと」を見分け、主導権を握ったままAIと並走する方法をまとめた、著者初の一冊である。関西の有名中学に合格した中学受験生との解き直しの工夫、医学部を目指す受験生との「方針を先に言葉にする」授業、英語がほぼゼロの状態から外国語大学合格までの立て直し——現場の具体例が、研究の知見に血を通わせる。

なぜ、勉強しているのに伸びないのか。その原因の多くは、怠けでも能力不足でもなく、「読めた」を「覚えた」と、「解けた」を「解ける」と、「作った」を「身についた」と取り違える、三つの錯覚にある。なぜ、解説を読めば分かるのに、初めての問題は解けないのか。学力には「分かる」「思い出せる」「使える」という三つの状態があり、その間の距離は、別々の練習でしか埋まらない。なぜ、検索できる知識をわざわざ覚えるのか。考えることは頭の中の小さな「作業台」の上で起き、そこに素早く載せられるのは、自分の頭の「引き出し」に入っている知識だけだからだ。

そして本書は、AIを使うかどうかを判断する基準を、たった一つの問いにまとめる。
「その苦労をAIに任せて消したとき、身につけたい力も一緒に消えるか」。
消えるなら、その苦労は自分で担う。消えないなら、AIに任せてかまわない。

この基準から生まれた実践が「並走ノート」だ。まず、何も見ずに、自分の考えをノートにひたすら書き殴る。次に、それをAIに整理させる——ただし内容は足させず、誤りと抜けは別に指摘させる。最後に、整理を自分の書き殴りと見比べ、確かめ、閉じて再現し、自分の頭に取り戻す。問いと材料と最終判断は自分が握り、AIには整理役と鏡を務めてもらう。走るのは自分、AIは隣で並走する。

さらに、AIに答えを聞くのではなく、問題を出させ、問い返させ、検証させる使い方を、数学・英語・国語・社会・理科、資格試験、大学のレポートまで、具体例と頼み方の例文で示していく。

「暗記はもう要らない」「AIで効率よく学べる」「まず自分で考えよ、は本当か」。本書は、こうした反論からも逃げない。研究の条件と限界、再現されなかった研究まで明示しながら、どこまでが正しく、どこからが誤りなのかを切り分ける。

受験生には、明日からの勉強を変える方法を。保護者には、子どものAI利用を禁止でも放任でもなく「約束」で導くための言葉を。教師には、説明の価値が下がった時代に、教える人が担うべき仕事を。

答えがタダになった時代に、それでも自分の頭で学ぶことの意味を、具体的に示す一冊。
