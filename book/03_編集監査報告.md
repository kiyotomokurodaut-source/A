# 編集チェック・最終監査報告（STEP 9／STEP 21）

## 1. 作業の経過と、途中で変えた判断

| 当初案（指示書の例） | 変更後 | 理由 |
|---|---|---|
| 第3章「人間が本当に身につけるべき思考力」→第4章「学習の設計」 | 第3章に「検索できる知識を、なぜ覚えるのか」を独立させた | 「暗記は不要か」は読者の疑問として最も強く、ここを論証しないと思考力の章（知識を材料に考える）が宙に浮くため |
| 第7章「AI時代に学ぶということ」 | 第7章を「教える人・学校・試験」に、思想的なまとめは「おわりに」へ | 教師・評価・格差の論点を一章にまとめたほうが教員・保護者に説明しやすく、7章構成を保てる |
| 思考力＝四つの動詞 | 四つの動詞＋「問う」＋メタ認知 | 「問いを立てる力」を独立させないと、AIへの質問の質（第6章）と接続できない |
| 学習法の五原則のみ | 第5章に「先に考えるか、先に教わるか」の節を追加 | 本書の「まず自分で考えよ」は、カーシュナーらの有力な反論と衝突する。専門家の読者に対する耐性のため正面から扱った |
| 第6章をAIの危険中心に | 「AIが学習を効率化する五つの仕組み」を追加 | 指示書12の「効率化するケース」と「学習が成立しなくなるケース」の両面分析を満たすため |
| 第1章は錯覚のみ | 「例外——錯覚だけが原因ではない」を追加 | 前提知識の欠落・量の不足・生活条件という別の原因を認めないと、読者の一部を誤診させる |
