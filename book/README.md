## 出版社へのアプローチ（`06_出版社アプローチ/`）

- `出版社リストとメール下書き.md`：公式サイトで受付方法を確認した12社の一覧（優先度・方法・宛先・返事の方針・確認元）、各社向けのメール本文／フォーム記入文、送付管理表
- `下書き/`：1社1ファイルのコピー用テキスト（宛先・件名・添付・本文）

入稿・持ち込みの前に、必ず `03_編集監査報告.md` の「4. 著者が入稿前に確認すること」を確認してください。
