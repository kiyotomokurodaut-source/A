# 答えがタダになる時代の勉強法

## AIに任せていいこと、自分の頭でしかできないこと

黒田清友

---

# はじめに　答えがタダになった日

## 三秒で届く解説

数学の宿題で手が止まったとき、いまの高校生にはいくつもの選択肢がある。教科書を読み返す。友人に聞く。翌日、先生に質問する。そしてもう一つ、問題をスマートフォンで撮影して生成AIに送る、という方法だ。

最後の方法を選ぶと、数秒で答えが返ってくる。答えだけではない。「まず条件を整理しましょう」「ここで判別式を使います」と、丁寧な解説までついてくる。途中で分からなければ「もっと簡単に説明して」と頼めばいい。相手は不機嫌にならないし、夜中の二時でも応じてくれる。

十年前なら、これは多くの受験生が夢見た環境だったはずだ。いつでも質問できる家庭教師が、ほとんど無料で手に入る。答えと説明にかかる費用が、限りなくゼロに近づいたのである。本書ではこの変化を「答えがタダになった」と呼ぶ。

では、答えがタダになった世界で、学力は上がるのだろうか。

直感的には上がりそうに思える。分からないところをすぐに解消できるのだから、つまずいて止まる時間が減る。時間が減れば、そのぶん多くの問題に触れられる。ところが、この直感を裏切る結果が出ている。

## ある実験が示した逆説

二〇二五年、米国科学アカデミー紀要（PNAS）に一本の論文が掲載された。ペンシルベニア大学のハムサ・バスタニらの研究チームが、トルコの高校でおよそ千人の生徒を対象に行った実地実験である。

生徒たちは三つのグループに分けられた。一つ目は、従来どおり教科書とノートで数学の演習をするグループ。二つ目は、ChatGPTと同じような汎用の対話AI（GPT-4）を使いながら演習するグループ。三つ目は、同じAIに「答えを直接教えず、教師が用意したヒントを出す」という制約をかけたAIチューターを使うグループである。

演習の時間、AIを使った生徒たちの成績は大きく伸びた。汎用AIのグループは、AIなしのグループに比べて正答が四八％多く、ヒント型AIのグループに至っては一二七％多かった。ここまでは予想どおりだろう。

問題はその後だ。AIを取り上げて、何も見ずに受ける試験を行ったところ、汎用AIで演習したグループの成績は、AIを一度も使わなかったグループより一七％低かった。練習では上回っていたのに、本番では下回ったのである。ヒント型AIのグループは、AIなしのグループとほぼ同じ水準だった。

さらに見逃せない点がある。汎用AIで演習した生徒たちは、自分の成績が下がったとも、学びが少なかったとも感じていなかった。研究チームが分析したところ、多くの生徒がAIを「松葉杖」のように使い、答えを写していたことが分かった。

練習中の成績は上がる。本人は学べたと感じている。しかし、AIを外すと実力は落ちている。この三つが同時に起きる。本書が出発点にするのは、この逆説である。

## 反対側の証拠もある

ただし、ここで「やはりAIは学力を下げる」と結論するのは早い。

同じ二〇二五年、ハーバード大学の物理学の講義で行われたランダム化比較試験では、学習科学の知見に基づいて設計されたAIチューターで学んだ学生が、教室で行う能動的な授業——講義を聞くだけでなく、グループで問題を議論する、物理教育では最良とされてきた形式——で学んだ場合を上回る学習効果を示した（Kestinら、Scientific Reports）。学生はより短い時間で、事前テストからの伸びが能動的授業の二倍を超えるほど学んだと報告されている。世界銀行がナイジェリアの公立中等学校で行った実験でも、六週間の放課後プログラムでGPT-4を英語の学習に使った生徒たちに、明確な成績の向上が確認されている。

AIは学力を下げもするし、上げもする。では、何がその分かれ目なのか。

バスタニらの実験で、汎用AIのグループとヒント型AIのグループを分けたのは、AIの性能ではない。同じAIである。違ったのは、問題を解く過程で「考える」工程を、生徒が自分で担ったか、AIが肩代わりしたかだった。ハーバードの実験でも、AIチューターは答えを先に教えないように、学生に一歩ずつ考えさせるように設計されていた。

本書の答えを先取りして言えば、分かれ目はここにある。**学力は、学習者の頭が実際に働いた分しか残らない。**AIはその「働き」を代わりに引き受けることもできれば、働きを引き出すこともできる。どちらになるかは、使い方で決まる。

## 二千四百年前の同じ心配

実は、新しい道具が人間の学びを損なうのではないかという心配は、今に始まったものではない。

プラトンの対話篇『パイドロス』で、ソクラテスは文字の発明にまつわるエジプトの伝説を語っている。文字を発明した神テウトは、これで人々はもっと賢くなり、物覚えもよくなると王に売り込む。ところが王は反論する。文字を学んだ者は、書かれたものに頼って自分で思い出そうとしなくなり、かえって物忘れがひどくなるだろう。彼らは多くのことを「聞き知る」ようになるが、実際には何も知らないまま、知者のように見えるだけになるだろう、と。

ソクラテスの心配は半分外れ、半分当たった。文字がなければ、私たちは複雑な数学も法律も科学も手にできなかった。文字は人類の思考を途方もなく拡張した。しかし、「読んだことがある」を「分かっている」と取り違える人間の性質は、二千四百年たった今もまったく変わっていない。本書の第1章で見るように、教科書を読み返しただけで「覚えた」と感じてしまう錯覚は、現代の心理学実験で繰り返し確認されている。

生成AIは、文字や印刷や検索エンジンと同じく、知識の外部化の歴史に連なる道具である。そして、それらのどれよりも強力だ。文字は情報を保存したが、説明はしなかった。検索エンジンは情報を探したが、問いに合わせて答えを組み立てはしなかった。生成AIは、答えを組み立て、説明し、書き上げる。人間の思考の工程そのものを、かなりの部分まで代行できる。

だからこそ、ソクラテスが見抜いた「知者に見えるだけの状態」は、かつてないほど簡単に作り出せるようになった。同時に、その罠を避けさえすれば、これほど強力な学習の味方もない。

## 本書が答える問い

本書は、次の問いを中心に据えている。

**AIが知識を瞬時に出してくれる時代に、人間は何を、なぜ、どのように学ぶべきなのか。**

これは大きな問いなので、もう少し手元の疑問に分解しておこう。勉強しているのに成績が伸びないのはなぜか。解説を読めば分かるのに、初めて見る問題になると解けないのはなぜか。検索できる知識を覚える必要はあるのか。「思考力」とは具体的に何なのか。復習はどう設計すればよいのか。AIを使うと学力は上がるのか、それとも思考力が落ちるのか。教師や塾の役割はどう変わるのか。受験勉強にはこれからも意味があるのか。

これらはばらばらの問いに見えるが、実は一本の線でつながっている。その線とは、「学力とは、何も見ずに、初めての状況で、自分の知識を選び、組み立て、確かめられること」という考え方である。この本は、この一本の線に沿って、学習の原理からAIの使い方、そして教育のあり方までを順に論じていく。

本書の主張の方向を、最初に示しておく。AIによって知識の価値がなくなるのではない。知識を使って考え、問い、判断し、他者と協働し、自分の理解を更新する能力の価値が、かえって高まる。ただし私はこの結論を、最初から正しいものとして押しつけるつもりはない。「暗記はもう要らない」「AIを使えば効率よく学べる」「学校の勉強は無駄が多い」といった反対の意見にも、正しい部分がある。本書ではそれらを正面から検討し、どこまでが正しく、どこからが誤りなのかを、研究と論理によって切り分けていく。

## 著者の立場と、本書の読み方

私は東京大学の教育学部で教育を学び、塾講師として五年間、中学受験から大学受験までの生徒を直接指導してきた。関西の中学受験に挑む小学生の受験に合格まで並走したこともあれば、医学部を目指す受験生と数学・英語に取り組んだこともある。不登校の時期を経て、英語がほとんどゼロの状態から外国語大学を目指した生徒もいた。授業では、答えそのものよりも「なぜその解法を選んだのか」「間違えたとき何を直すのか」「次の自習で何を確かめるのか」を扱うことを重視してきた。生成AIが一気に普及したここ数年、教える現場で目の前の生徒の学び方が変わっていくのを見ながら、私は同じ問いを考え続けてきた。AIがあるのに、この子はなぜ、何を、どう学ぶべきなのか。

ただし、「私は多くの生徒を見てきたから、これが正しい」という論法は本書では使わない。現場で見えることは、問題を見つけるきっかけにはなるが、それだけで一般化するには危うい。一人の講師が見られる生徒の数には限りがあり、記憶は印象的な例に偏る。だから本書では、現場の観察は問いや具体例として使い、主張の根拠は、認知心理学や学習科学の研究、そして論理に求める。研究を紹介する際には、その結果がどんな条件で得られたのか、どこに限界があるのかも、できるだけ書き添えた。「研究で証明された」という言葉は便利だが、多くの研究結果には条件があり、その条件を外すと成り立たないこともあるからだ。

本書の構成は次のとおりである。

第1章では、AIが登場する前から存在していた「努力が学力に変わらない」現象を、三つの錯覚として整理する。第2章では、「分かる」「思い出せる」「使える」という学力の三つの状態を区別し、自分の学力を診断する方法を示す。第3章では、「検索できる知識を、なぜ覚えるのか」という問いに、人間の記憶と思考の仕組みから答える。第4章では、曖昧に語られがちな「思考力」を、「見抜く・選ぶ・組み立てる・確かめる」という四つの頭の動きと、それに先立つ「問う」働きに分解する。第5章では、それらを踏まえた学習の設計図を描く。第6章でいよいよAIを正面から扱い、AIに任せてよい苦労と、任せてはいけない苦労を見分ける方法を示す。第7章では視点を広げ、教師・学校・試験・家庭、そして教育格差がどう変わるかを考える。巻末には、本文の方法をそのまま使えるように、AIへの頼み方の実例と一週間の学習設計シートを付けた。

AIの章だけを先に読みたい読者もいるだろう。しかし、できれば第1章から順に読んでほしい。第6章で示すAIの使い方の基準は、第1章から第5章で論じる学習の原理の上に立っているからだ。原理を知らずに使い方だけを覚えると、AIの性能が変わったとき、その使い方も古くなる。原理を知っていれば、道具が変わっても自分で判断できる。

答えがタダになった時代に、それでも自分の頭で学ぶことには、どんな意味があるのか。その問いに、できるだけ具体的に答えていきたい。

# 第1章　なぜ「勉強しているのに伸びない」のか——努力を裏切る三つの錯覚

## 1　努力の量と成績は比例しない

### 「こんなにやったのに」の中身

模試の結果が返ってきた日、「こんなにやったのに」と口にする生徒は少なくない。本人の言葉に嘘はない。毎日机に向かい、教科書を読み返し、ノートを整え、問題集を最後まで解いた。努力はしている。それなのに結果が出ない。

こういうとき、周囲の大人はたいてい二つのどちらかを言う。「まだ量が足りない」か、「やり方が悪い」かである。前者は気合いの話になり、後者は具体性に欠ける。どちらを言われても、本人は次に何を変えればよいのか分からない。

本章で考えたいのは、この「やったのに伸びない」という現象の仕組みである。先に結論を言えば、原因の多くは怠けでも能力不足でもない。**学習している最中に感じる「手ごたえ」と、学習が終わった後に残る「実力」が、別物であること**に気づいていない点にある。

このズレは、人間の脳の性質から生まれる。だから真面目な人ほど陥りやすい。そして、生成AIはこのズレを、これまでになく大きくしうる道具でもある。本章では、学習者が陥りやすい錯覚を三つに分けて見ていく。

### 学力は「閉じた後」にしか測れない

錯覚の話に入る前に、一つだけ基準を決めておきたい。学力とは何か、という基準である。

受験でも資格試験でも、本番では教科書もノートも見られない。AIに質問することもできない。自分の頭の中にあるものだけで、初めて見る問題に答えなければならない。仕事の場面でも、会議で意見を求められたときや、顧客の前で判断を迫られたとき、その場で頼れるのは自分の頭の中身である。

だから本書では、学力を次のように定める。**教材を閉じ、道具から離れた状態で、何ができるか。**勉強中にできたことではなく、勉強が終わった後に、何も見ずにできることだけが学力である。

これは当たり前に聞こえるが、この基準を本気で採用すると、多くの勉強法の評価ががらりと変わる。以下で見る三つの錯覚は、どれも「勉強中にできたこと」を「学力」と取り違えることから生まれている。

## 2　錯覚その一　「読めた」を「覚えた」と取り違える

### いちばん人気の勉強法

試験前の図書館や自習室を見渡すと、最もよく見かける勉強法は、教科書やノートを読み返すことと、マーカーで線を引くことだろう。手軽で、進んでいる実感があり、疲れにくい。

ところが、この二つは学習科学の研究では評価が低い。米国の心理学者ジョン・ダンロスキーらは二〇一三年、学習者がよく使う十の学習法について、それまでの研究を網羅的に検討し、効果の実用的な高さを評価した。その結果、再読（読み返し）とハイライト（線引き）は、要約や語呂合わせと並んで「有用性が低い」と判定された。逆に「有用性が高い」とされたのは、自分をテストすること（練習テスト）と、学習の間隔をあけること（分散学習）の二つだけだった。

もちろん、読み返しに全く効果がないわけではない。一度も読まないよりは、読んだほうが覚える。問題は、同じ時間を別の方法に使った場合に比べて、得られるものが少ないことだ。そして、もっと厄介なのは、読み返しは「効果が高い」と感じられてしまうことである。

### 自信があるほうが負ける実験

米国セントルイス・ワシントン大学のヘンリー・ローディガーとジェフリー・カーピキーは、二〇〇六年に発表した実験で、この問題を鮮やかに示した。

大学生に科学に関する短い文章を読ませた後、もう一度読み返す場合と、文章を見ずに思い出せることを書き出す場合とを比べる。つまり、「読み返す」か「思い出す練習をする」かの違いである。そのうえで、五分後、二日後、一週間後に、どれだけ内容を覚えているかをテストした。

五分後のテストでは、読み返したほうが成績がよかった。直前に読んだばかりなのだから当然だろう。ところが、二日後と一週間後のテストでは、結果が逆転した。思い出す練習をしたほうが、明らかに多くの内容を覚えていたのである。

同じ論文の二つ目の実験は、この差をさらにはっきりさせた。四回読む学生、三回読んで一回思い出す学生、一回読んで三回思い出す学生を比べたところ、五分後のテストでは四回読んだ学生の成績が最もよかった（覚えていた割合は八割あまり）。ところが一週間後には、四回読んだ学生が約四割まで落ちたのに対し、一回読んで三回思い出した学生は約六割を保っていた。しかも、実験の最後に「一週間後にどれくらい覚えていると思うか」を尋ねると、最も自信を示したのは四回読んだ学生だった。いちばん自信があった学生が、いちばん忘れていたのである。

### なぜ脳はだまされるのか

読み返すと「覚えた」と感じるのはなぜだろうか。

心理学では、この現象を「流暢性の錯覚」と呼ぶ。二回目に読む文章は、一回目よりもすらすら読める。見覚えのある言葉が並び、意味がすっと頭に入る。この「すらすら感」、つまり処理の流暢さを、脳は「自分はこれを知っている」というサインとして受け取ってしまう。

しかし、「見たら分かる」ことと「見なくても思い出せる」ことは、まったく別の能力である。読み返しで鍛えられるのは前者だ。そして試験で問われるのは後者である。すらすら読めた感覚は、本番で思い出せることを何も保証しない。

たとえば英単語帳を眺めて、「apparent（明らかな）、うん、知ってる」「inevitable（避けられない）、これも知ってる」とページをめくっていくとき、私たちは英単語を見てから日本語訳を「確認」しているにすぎない。英単語を見た瞬間に訳語がちらりと目に入り、「知ってた」と感じる。だが訳語を手で隠して、英単語だけを見て意味を言おうとすると、思ったより出てこないことに驚くはずだ。

## 3　錯覚その二　「解けた」を「解ける」と取り違える

### 章末問題はなぜ解けるのか

読み返しの錯覚を避けて、問題演習をしている人も安心はできない。問題を解いていても、別の種類の錯覚が起きるからだ。

数学の問題集を思い浮かべてほしい。多くの問題集は、単元ごとに章が分かれている。「二次関数」の章には二次関数の問題が、「三角関数」の章には三角関数の問題が並ぶ。この形式で演習すると、驚くほどよく解ける。直前に学んだ解法を、そのまま次々と当てはめればよいからだ。

ここには見落とされがちな事実がある。章ごとに並んだ問題を解くとき、学習者は「この問題にはどの解法を使うべきか」という判断を、一度もしていない。その判断は、問題集の章立てがすでに済ませてくれている。「三角関数の章の問題だから、三角関数の公式を使う」。この手がかりが、実はいちばん難しい部分を肩代わりしているのである。

ところが模試や入試では、問題は単元別に並んでいない。一つの問題を見て、それが何の問題なのか、どの道具を使うべきなのかを、自分で判断しなければならない。問題集では解けていたのに模試で手が出ない、という現象の少なくとも一部は、ここから説明できる。

### 混ぜると伸びる、しかし手ごたえは下がる

この点を確かめた研究がある。米国サウスフロリダ大学のダグ・ローラーとケリー・テイラーは二〇〇七年、大学生に、回転楕円体や球錐といった、あまりなじみのない数種類の立体の体積を求める問題を学ばせた。あるグループは種類ごとにまとめて練習し（ブロック練習）、別のグループは種類を混ぜて練習した（交互練習）。

練習中の成績は、まとめて練習したグループのほうがよかった。同じ種類が続くので、解法を当てはめやすいからだ。ところが一週間後のテストでは、混ぜて練習したグループの正答率が、まとめて練習したグループを大きく上回った。混ぜて練習した学生は、問題ごとに「これはどの種類か」を判断する練習を積んでいたのである。

さらに注目すべきは、学習者自身の感覚だ。ネイト・コーネルとロバート・ビョークが二〇〇八年に行った、画家の作風を見分ける学習の実験では、複数の画家の作品を混ぜて見たほうが、画家ごとにまとめて見るよりも、新しい作品の作者をよく当てられるようになった。にもかかわらず、実験後に尋ねると、参加者の大半は「まとめて見たほうがよく学べた」と答えた。

混ぜて練習すると、練習中は間違いが増え、もどかしく感じる。その「もどかしさ」を、学習者は「うまく学べていない」サインだと受け取る。実際にはその逆で、もどかしさの中で判断の練習が起きているのだが。

### 答えを見て「あ、そうか」の罠

問題演習にはもう一つ、よくある落とし穴がある。問題を少し考えて分からないとき、解答を見て「あ、そうか」と納得する場面だ。

この「あ、そうか」は、第2章で詳しく扱う「再認」という働きである。再認とは、目の前に示されたものを「知っている」「正しい」と判断することだ。解答を読んで納得できるのは、解答が示す道筋を、一歩ずつ確認できるからである。しかし、その道筋を白紙の状態から自分で作り出せるかどうかは、まったく別の問題だ。

解答を読んで納得した問題に丸をつけ、「この問題は済んだ」とする学習者は多い。だが、その問題は「解けた」のではなく、「解説を理解できた」にすぎない。次に同じ問題を白紙から解こうとしたとき、最初の一行目で止まってしまうことは珍しくない。

## 4　錯覚その三　「作った」を「身についた」と取り違える

### きれいなノートの誘惑

三つ目の錯覚は、目に見える成果物にまつわるものだ。

色分けされた美しいまとめノート。教科書の内容を自分なりに整理した表。手作りの単語カード。これらを作り上げたとき、人は大きな達成感を覚える。何時間もかけて手を動かし、目の前に形のある成果が残っている。これほど「勉強した」と実感できるものはない。

しかし、ここで第1節の基準を思い出してほしい。学力とは、教材を閉じた後に何ができるかである。まとめノートの完成度は、ノートを閉じた後の実力を直接は示さない。

もちろん、ノートを作る過程で頭を使っていれば、学習は起きる。どの情報が重要かを判断し、情報同士の関係を考え、自分の言葉で言い換える。こうした作業は、第5章で見るように学習を深める。ところが、ノート作りが「教科書の文章を、色を変えて書き写す作業」になっているとき、頭はほとんど働いていない。手は疲れるが、それは頭が働いた証拠にはならない。前出のダンロスキーらの評価でも、要約を書くことの有用性は「低い」とされた。要約がうまく書けるかどうかで効果が大きく変わり、訓練なしでは効果が出にくいためである。

### 成果物と頭の変化は別物

ここで、本書全体を通じて使う大切な区別を導入しておきたい。**成果物**と**頭の変化**の区別である。

勉強をすると、二種類のものが生まれる。一つは、ノート、解いた問題集、書いたレポート、提出した宿題といった、目に見える成果物である。もう一つは、学習者の頭の中で起きた変化、つまり、新しく思い出せるようになったこと、できるようになったことだ。

勉強の本当の目的は、言うまでもなく後者である。成果物は、頭の変化を起こすための手段、あるいは頭の変化が起きたかどうかを確かめるための証拠でしかない。ところが、成果物は目に見え、頭の変化は目に見えない。だから人は、見えるほうを目的と取り違えやすい。

宿題を「終わらせる」ことが目的化したとき、この取り違えは最も分かりやすい形で現れる。宿題の答えを友人に見せてもらって写した生徒は、成果物（提出された宿題）を手にしたが、頭の変化はほとんど得ていない。本人もそれを分かっている。

### AIは、この錯覚を最大化しうる

生成AIが学習に持ち込んだ最大の変化は、この「成果物」と「頭の変化」を、かつてないほど簡単に切り離せるようになったことだ。

AIに頼めば、数学の解答も、英作文も、読書感想文も、レポートも、数十秒で完成する。しかもその成果物は、多くの場合、本人が自力で作るものより整っている。友人の宿題を写すのとは違い、AIは頼めば何度でも、どの教科でも、どんな形式でも作ってくれる。

さらに重要なのは、AIが作った成果物は、自分が作ったような感覚を与えやすいことだ。自分で質問を打ち込み、返ってきた答えを読み、「なるほど」と納得する。この一連のやりとりは、友人のノートを写すのとは違って、自分で考えたかのような手ごたえを残す。はじめにで紹介したバスタニらの実験で、汎用AIを使った生徒たちが、成績が下がっていることに気づかなかったのは、この手ごたえのせいだと考えられる。

AIは、ここまでに見た三つの錯覚すべてを強化しうる。AIの説明はとても流暢に読める（錯覚その一）。AIの解答を読んで「あ、そうか」と納得できる（錯覚その二）。そしてAIは、整った成果物を瞬時に作ってくれる（錯覚その三）。AIが悪いのではない。人間の脳がもともと持っている錯覚のくせに、AIがぴったりはまってしまうのである。

## 5　三つの錯覚に共通する構造

### 「学習中の出来」と「学習後の実力」

三つの錯覚を並べると、共通の構造が見えてくる。

どの錯覚でも、学習している最中の出来ばえ（すらすら読める、問題が解ける、ノートが完成する）が、学習後に残る実力を表していると誤解されている。心理学者のロバート・ビョークらは、この二つを「遂行（パフォーマンス）」と「学習（ラーニング）」として区別してきた。遂行とは、学習している最中や直後に観察できる出来ばえのこと。学習とは、時間がたっても残り、別の場面でも使える、比較的長続きする変化のことである。

この区別の要点は、遂行と学習がしばしば食い違うことにある。読み返しや、まとめての練習は、遂行を高めるが、学習はそれほど高めない。逆に、思い出す練習や、混ぜての練習は、その場の遂行を下げる（間違いが増え、もどかしい）が、学習を高める。

### 望ましい困難

ビョークは、学習中にあえて負荷をかけることで長期的な学習が促される条件を、「望ましい困難」と名づけた。思い出す練習、間隔をあけた復習、混ぜての練習などがその代表である。

ここで注意したいのは、「困難なら何でもよい」わけではないという点だ。「望ましい」という形容詞に意味がある。学習者が持っている知識で何とか乗り越えられる困難であれば、学習は深まる。しかし、まったく歯が立たない困難は、ただの挫折に終わる。基礎の知識がない状態で難問に取り組んでも、得られるものは少ない。困難の程度を調整することが、学習設計の要になる。この点は第5章で詳しく扱う。

### 反論——楽しく学べるほうがよいのでは？

ここで、当然の反論が浮かぶだろう。「わざわざ苦労する勉強法より、楽しく、すらすら進む勉強法のほうが続けやすい。続けられなければ意味がないのでは」。

この反論には正しい部分がある。学習は継続して初めて意味を持つし、苦痛ばかりの勉強は長続きしない。やる気の問題は現実に存在する。

ただし、ここで区別しておきたいのは、「楽しい」ことと「楽な」ことの違いである。自分の力で問題が解けたときの喜びや、ばらばらだった知識がつながったときの面白さは、むしろ望ましい困難を乗り越えた先にある。一方、すらすら読める快適さや、ノートが完成していく満足感は、楽ではあっても、学力の伸びをあまり伴わない。前者の楽しさを目指すべきで、後者の楽さを「楽しさ」と取り違えないことが肝心なのだ。

もう一つ、実際的な答えもある。望ましい困難を取り入れた勉強は、慣れないうちはもどかしいが、同じ時間でより多くが身につく。結果として、長い目で見れば勉強時間は短くて済む。「伸びている」という実感が得られれば、それ自体が続ける力になる。

### 例外——錯覚だけが原因ではない

公平を期すために、付け加えておきたいことがある。「やったのに伸びない」原因が、すべて本章の三つの錯覚で説明できるわけではない。

一つは、**前提となる知識の欠落**である。高校の数学で二次関数につまずいている生徒の原因が、実は中学で学ぶ一次関数や平方根の計算にあることは珍しくない。英語の長文が読めない原因が、読解の方法ではなく、中学レベルの文法の理解にあることもある。この場合、目の前の単元をどれほど工夫して学んでも、土台がなければ積み上がらない。学習の順序をさかのぼることが、遠回りに見えて最短の道になる。第3章では、英語をほとんどゼロの状態から立て直した生徒の例を紹介する。

二つ目は、**学習の量そのものが、目標に対して不足している**場合である。本章は「量より質」を説く章ではない。質を上げても、必要な量に届いていなければ結果は出ない。質の改善は、同じ量から得られるものを増やすための手段であって、量の代わりにはならない。

三つ目は、**生活の条件**である。睡眠が極端に不足していたり、強い不安を抱えていたりすれば、どんな学習法も十分に働かない。記憶の定着に睡眠が関わっていることは、多くの研究が示唆している。学習法の議論は、学習者が学べる状態にあることを前提にしている。

これらの原因が疑われるときには、学習法を変える前に、土台・量・生活のどこに問題があるのかを確かめる必要がある。そのうえで、なお「やったのに伸びない」のであれば、本章の三つの錯覚を疑ってみてほしい。

## 6　今日からできること——「手ごたえ」を「証拠」に置き換える

本章の内容を、明日から使える形にまとめておこう。原則は一つである。**学習中の手ごたえを信じるのをやめ、学習後の証拠で判断する。**そのための習慣を三つ挙げる。

一つ目は、**閉じて書く**こと。教科書やノートを一通り読んだら、それを閉じ、白紙に覚えている内容を書き出す。何も見ずに書けたことだけが、自分の頭に入っていることだ。書けなかった部分を確認してから、もう一度閉じて書く。これだけで、読み返しの時間の一部が、思い出す練習に置き換わる。

二つ目は、**混ぜて解く**こと。問題集を章の順に解いたら、次は複数の章の問題を混ぜて解く。問題番号をランダムに選んでもいいし、複数の単元の問題をまとめて一枚のリストにしてもいい。一問ごとに「これは何の問題か」を自分で判断する練習になる。

三つ目は、**翌日に試す**こと。今日「分かった」問題を、翌日か数日後に、解答を見ずにもう一度解く。解答を見て納得した問題は、この再挑戦で初めて「解ける」問題に変わる。解けなければ、それは「分かったつもり」だったということだ。その発見こそが、いちばん価値のある情報である。

これらの習慣には共通点がある。どれも、勉強中の手ごたえを少し下げ、そのかわりに自分の実力についての正確な情報を手に入れる方法だということだ。

---

ここまで、「身についた」と思っているのに身についていない、という錯覚を見てきた。では、「身についた」とは、具体的にはどのような状態なのだろうか。「分かった」と「できる」は何が違うのか。次章では、学力を三つの状態に分け、それぞれの間にある「距離」を測ってみたい。そうすれば、自分の勉強のどこが空回りしているのかを、もっと正確に診断できるようになる。

# 第2章　「分かる」「思い出せる」「使える」——学力の三つの距離

## 1　「解説を読めば分かるのに、初見では解けない」

受験生からよく聞く悩みに、次のようなものがある。

「数学の解説を読むと、全部分かるんです。一行一行、ちゃんと納得できる。でも、模試で初めての問題を見ると、何から手をつけていいか分からない」

この悩みを抱える生徒は、たいてい真面目で、理解力もある。解説を読んで分からないのなら、理解力に問題があると考えられる。しかし彼らは分かっている。分かっているのに、できない。この「分かるのにできない」という状態は、いったい何が起きているのだろうか。

前章で、学習中の手ごたえと学習後の実力が食い違うことを見た。本章ではさらに一歩進んで、「実力」そのものを分解する。本書では、学力を三つの状態に分けて考える。**分かる**、**思い出せる**、**使える**、の三つだ。そして、この三つの間には、それぞれ埋めなければならない「距離」がある。「分かるのにできない」とは、この距離を埋めないまま、最初の状態で止まっていることを意味する。

## 2　三つの状態と二つの距離

### 分かる——説明を追える状態

一つ目の状態は「**分かる**」、すなわち理解である。ここでの「分かる」は、目の前に示された説明を、筋道を追って納得できる状態を指す。解説を読んで一行ずつ「なるほど」と思える。先生の説明を聞いて、論理の流れに納得できる。これが「分かる」状態だ。

この状態は学習の出発点として欠かせない。理解できないことは、覚えても応用がきかないし、そもそも覚えにくい。しかし、「分かる」には一つの決定的な特徴がある。それは、**説明が目の前にあること**を前提にしている、という点である。説明が消えた瞬間に何が残るかは、「分かる」状態からは判断できない。

### 思い出せる——手がかりなしで取り出せる状態

二つ目は「**思い出せる**」、すなわち想起である。説明や手がかりが目の前になくても、頭の中から必要な知識を自分で取り出せる状態だ。英単語を見て意味が分かるのではなく、日本語から英単語が出てくる。公式を見て使い方が分かるのではなく、白紙に公式を書き出せる。歴史の流れを読んで納得するのではなく、何も見ずにその流れを説明できる。

「分かる」と「思い出せる」の間には、心理学でいう**再認**と**再生**の違いがある。再認とは、示されたものが「知っているものかどうか」を判断すること。選択式の問題で正解を選ぶのは再認である。再生とは、手がかりなしに自分で記憶から取り出すこと。記述式の問題で答えを書くのは再生である。一般に、再認は再生よりずっとやさしい。多くの人は、正解の選択肢を見れば「これだ」と分かるのに、選択肢がないと思い出せない、という経験をしているはずだ。

「分かる」から「思い出せる」までの隔たりを、本書では**第一の距離**と呼ぶ。前章で見た読み返しや、解説を読んでの納得は、この距離を埋めない。第一の距離を埋めるのは、思い出そうとする練習、つまり自分の頭から知識を取り出す経験の積み重ねである。

### 使える——初めての状況で、選んで適用できる状態

三つ目は「**使える**」、すなわち運用である。初めて見る状況で、自分が持っている知識のうち、どれがその状況に関係するかを判断し、選び出し、適用できる状態だ。

「思い出せる」と「使える」の違いは微妙だが、決定的である。「二次方程式の解の公式を書きなさい」と言われて書けるのは「思い出せる」状態だ。しかし、文章で書かれた問題を読んで、「ここで二次方程式を立てればよい」と気づき、適切に式を立て、解の公式を使って解き、答えが問題の条件に合うかを確かめる。これが「使える」状態である。前者では何を思い出すべきかが指定されているが、後者では何を思い出すべきかを、自分で判断しなければならない。

「思い出せる」から「使える」までの隔たりを、本書では**第二の距離**と呼ぶ。心理学ではこの「使える」を、学んだことを別の場面に適用するという意味で「転移」という言葉で研究してきた。第二の距離を埋めるのは、前章で見た混ぜての練習や、第4章で見る「見抜く」「選ぶ」練習である。

### 学力は一本の直線ではない

三つの状態を順番に並べると、「分かる→思い出せる→使える」という階段のように見えるかもしれない。確かに、理解していないことを思い出すのは難しいし、思い出せないことを使うこともできない。その意味では、ある程度の順序はある。

しかし、この三つは一方通行の階段ではなく、互いに支え合う関係にある。使おうとしてうまくいかなかった経験が、理解を深めることは多い。何度も思い出すうちに、最初は分からなかった意味が見えてくる場合もあるだろう。大切なのは、三つが別の状態であり、それぞれに別の練習が必要だと知ることだ。「分かった」で学習を止めてしまうのは、階段の一段目で立ち止まったまま、頂上にいるつもりになるようなものである。

## 3　数学で分解する——初見の問題を前にした頭の中

### 解説を読むとき、何が省略されているか

「解説を読めば分かるのに、初見で解けない」という現象を、具体的な問題で分解してみよう。たとえば、高校数学でよく出題される次のような問題を考える。

「aを定数とする。0≦x≦2の範囲で、関数 f(x)=x²−2ax+3 の最小値を求めよ」

解説は、おおむね次のように進む。まず f(x)=(x−a)²−a²+3 と平方完成する。グラフは下に凸の放物線で、軸は x=a である。軸が範囲の左外（a<0）なら x=0 で最小、軸が範囲の中（0≦a≦2）なら頂点で最小、軸が範囲の右外（2<a）なら x=2 で最小。それぞれを計算して、答えが得られる。

この解説は論理的で、一行ずつ読めば誰でも納得できる。しかし、この解説を「読む」ことと、この問題を「解く」ことの間には、大きな違いがある。解説の最初の一行「平方完成する」を、解説を読む人は受け取るだけでよい。しかし問題を解く人は、白紙の状態で、「この問題では平方完成をすべきだ」と自分で判断しなければならない。そして、その判断こそが、この問題でいちばん難しい部分なのだ。

### 初見問題を解くときの五つの工程

初めての問題を自力で解くとき、頭の中では少なくとも次のような工程が進んでいる。

一つ目は**特徴の抽出**である。問題文を読み、「文字aを含む二次関数」「範囲が限定されている」「最小値を求める」といった、解法を決めるうえで重要な特徴を拾い上げる。二つ目は**解法の想起**である。拾った特徴を手がかりに、「範囲つきの二次関数の最大・最小は、軸と範囲の位置関係で決まる」という知識を記憶から取り出す。三つ目は**方針の決定**である。取り出した知識を使って、「まず平方完成して軸を求め、軸の位置で場合分けする」という道筋を決める。四つ目は**実行**である。実際に計算し、場合分けを進める。五つ目は**検証**である。場合分けに漏れや重なりがないか、答えが条件に合っているかを確かめる。

さて、解説を読むとき、読者はこのうちどの工程を自分で行っているだろうか。答えは、四つ目の実行の一部と、五つ目の検証の一部だけである。特徴の抽出も、解法の想起も、方針の決定も、解説者がすでに済ませている。読者は解説者が選んだ道を、後ろからついていけばよい。

だから、解説を読んで「分かる」ことは、この問題を「解ける」ことをほとんど保証しない。問題の核心である前半の三つの工程を、一度も自分でやっていないのだから。これが「分かるのにできない」の正体の一つである。

### 解答を「読む」から、解法を「選ぶ」へ

このように分解すると、何を練習すべきかが見えてくる。初見の問題が解けるようになるには、特徴の抽出、解法の想起、方針の決定を、自分の頭で行う経験を積む必要がある。

具体的には、解説を読む前に、少なくとも「この問題は何の問題で、どの方針で解くか」を自分で決める時間をとることだ。たとえ最後まで解けなくても、方針を自分で立て、その後で解説と照らし合わせる。自分の方針が正しかったか、間違っていたなら、問題文のどの特徴を見落としたのか。この比較こそが、第二の距離を埋める練習になる。

### 医学部を目指す生徒との授業から

この考え方は、私自身が指導の中で試行錯誤してきたことでもある。

医学部を目指す生徒の受験に、数学と英語の指導で並走したことがある。その生徒は、問題集の解説を読む力は十分にあった。解説のどの行について「なぜここでこうするのか」と尋ねても、きちんと説明できた。ところが、初めて見る問題を前にすると、手が止まる時間が長い。何から手をつけてよいか分からないまま、計算を始めては途中でやめる、ということを繰り返していた。

本章の言葉でいえば、この生徒は「分かる」の段階では何の問題もなかった。止まっていたのは、特徴の抽出と方針の決定、つまり解説者がいつも先に済ませてくれていた工程だった。

そこで授業のやり方を変えた。問題を渡したら、計算を始める前に、まず「これは何の問題で、どの方針で行くか、そう判断した理由は問題文のどこにあるか」を口に出してもらう。方針が間違っていても、その場では訂正しない。最後まで解いてもらい、その後で、方針のどこがずれていたのか、問題文のどの言葉に気づけばよかったのかを一緒に振り返る。そして、その振り返りを、次に同じ種類の問題が出たときに使える一行の「教訓」として残してもらった。第5章で詳しく述べる誤答の分析の原型である。

最初のうち、この授業は生徒にとって明らかに居心地が悪かった。解説を読んで納得する授業に比べて、正解にたどり着くまでの時間は長く、間違いも多い。第1章で述べた「望ましい困難」そのものである。しかし、解説を読んで「分かる」ことを何十回繰り返しても埋まらなかった第二の距離は、方針を自分で決め、外し、直すという経験を重ねることでしか埋まらない。この生徒との授業は、私にそのことを確信させた。

医学部の入試は、数学でも英語でも、初めて見る問題を限られた時間で解くことを求める。どれだけ多くの解説を理解していても、その場で方針を選べなければ得点にはならない。英語の長文でも同じ構造があった。和訳を読めば内容は分かるのに、初見の長文では段落の役割がつかめない。ここでも、読み進める前に「この段落は前の段落に対して何をしているか」を先に言葉にする練習を続けた。

## 4　教科ごとに見る「三つの距離」

数学以外の教科でも、三つの状態と二つの距離は、それぞれ違う形で現れる。

### 英語——読める単語と書ける単語

英語の語彙には、**受容語彙**と**発表語彙**という区別がある。受容語彙とは、読んだり聞いたりしたときに意味が分かる語彙のこと。発表語彙とは、自分で話したり書いたりするときに使える語彙のことである。一般に、受容語彙は発表語彙よりずっと多い。

受験生の多くは、英単語帳で「英語→日本語」の方向の練習をする。これは主に再認、つまり「分かる」側の練習だ。長文読解にはこれで一定の効果がある。しかし英作文になると、「日本語→英語」の方向で単語を思い出す必要がある。これは再生であり、第一の距離を越えなければできない。

さらに、英作文で求められるのは単語の再生だけではない。「彼はその問題を避けて通ることはできないと分かっていた」を英語にするとき、inevitable を使うか、could not avoid とするか、文の構造をどう組み立てるか。状況に応じて自分の語彙の中から選び出し、組み合わせる必要がある。これが第二の距離、つまり「使える」の段階である。

### 国語——解説を読めば納得する記述問題

国語の読解、とくに記述問題では、「分かる」と「使える」の距離が特に見えにくい。

評論文の記述問題の解説を読むと、「傍線部の直前の『しかし』に注目すると、筆者の主張はこちらにあることが分かる」といった説明がある。読めば納得できる。ところが自分で解くと、どこに注目すればよいのか分からない。本文の中から根拠を見つけることが、解説を読むことよりはるかに難しいのである。

教育心理学者の西林克彦は『わかったつもり』で、文章を読んで「分かった」と感じた時点で読み手は探索をやめてしまい、それ以上深く読まなくなることを指摘した。いったん何となく意味がつかめると、細部の矛盾や、読み落としている関係に目が向かなくなる。国語の記述問題が解けない生徒の多くは、文章が分からないのではなく、「分かったつもり」の段階で読むのをやめてしまっている。解説はその先を見せてくれるが、自分で先へ進む練習にはならない。

### 社会——用語は言えるのに論述が書けない

社会、とくに歴史では、用語の暗記と論述の間に大きな距離がある。

「大化の改新」「班田収授法」「墾田永年私財法」といった用語を、年号とともに言える生徒は多い。これは「思い出せる」状態である。しかし、「律令国家の土地制度が、八世紀にどのように変化したかを説明せよ」という論述問題になると、手が止まる。個々の用語は思い出せても、それらをつなぎ、因果関係の中に位置づけて説明することができないのだ。

ここでの第二の距離は、知識を「点」として持つか、「つながり」として持つかの違いだと言える。論述が書ける生徒の頭の中では、用語が因果の網目の中に配置されている。班田収授がなぜ行き詰まったのか、その結果どんな政策がとられたのか、その政策が何を生んだのか。この網目があって初めて、問いに応じて知識を取り出し、並べることができる。

### 理科——公式は言えるのに、現象が説明できない

理科では、第二の距離は「公式」と「現象」の間に現れる。

物理の電気の単元で、オームの法則 V=RI を知らない高校生はまずいない。公式を書けと言われれば書ける。計算問題も、数値が与えられていれば解ける。ところが、「豆電球を二個直列につないだ回路と並列につないだ回路では、どちらの豆電球が明るいか。理由とともに説明せよ」と問われると、答えに詰まる生徒が少なくない。

この問題を解くには、V=RI という式を思い出すだけでは足りない。回路のどこで電圧が分かれ、どこで電流が分かれるかという構造を見抜き、明るさが電力で決まることを思い出し、それらを組み合わせて説明を組み立てる必要がある。公式が「思い出せる」状態から、現象の説明に「使える」状態へ。ここにも第二の距離がある。

### 大学での学習——講義は分かったのに、レポートが書けない

大学に入ると、第二の距離はさらに大きくなる。講義を聞いて「分かった」と感じ、試験前にノートを見直して重要な概念を「思い出せる」ようにしても、レポートの課題で「講義で扱った理論を使って、身近な社会現象を分析せよ」と求められると、手が止まる。

この課題では、自分で分析の対象を選び、講義のどの理論がその対象に当てはまるかを判断し、理論と現象を結びつけて論じなければならない。講義の中では、教員が理論と具体例の結びつきを示してくれていた。その結びつけを、今度は自分でやる必要がある。大学の学習が高校までの学習と大きく違うと感じられる理由の一つは、評価の中心が「思い出せる」から「使える」へ移ることにある。

## 5　転移はなぜ難しいのか

### ヒントがないと、類推は起きない

学んだことを別の場面で使う「転移」が難しいことは、心理学の古典的な実験で示されている。

一九八〇年、メアリー・ギックとキース・ホリオークは、次のような実験を行った。参加者に、まず軍事の物語を読ませる。ある将軍が要塞を攻めたいが、要塞に続く道には地雷が埋められていて、大軍が一度に通ると爆発する。そこで将軍は軍を小部隊に分け、多方向の道から同時に要塞に向かわせ、一斉に集結させて攻略した、という話だ。

その後、参加者に別の問題を出す。胃に腫瘍のある患者がいる。強い放射線を当てれば腫瘍を破壊できるが、途中の健康な組織も破壊してしまう。弱い放射線なら健康な組織は無事だが、腫瘍も壊せない。どうすればよいか。

答えは、将軍の物語と同じ構造である。弱い放射線を多方向から当て、腫瘍の位置で集中させればよい。ところが、将軍の物語を読んだ直後であるにもかかわらず、この解法を自発的に思いついた参加者は三割ほどにとどまった（物語を読まなかった場合は一割ほど）。一方、「さっきの物語がヒントになるかもしれない」と告げられると、合わせて八割ほどの参加者が解けた。

この実験が示すのは、知識を持っていることと、それを新しい場面で使えることの間には、大きな溝があるということだ。人は、表面が違って見える問題の間に、同じ構造を見出すのが苦手なのである。

### 初心者は表面を見て、熟達者は原理を見る

では、転移ができる人は何が違うのだろうか。

一九八一年、ミシュリン・チーらは、物理学の初心者（大学で物理を学び始めた学生）と熟達者（大学院生や研究者）に、物理の問題をいくつも見せ、「似ている問題同士をグループに分けてください」と頼んだ。

初心者は、問題の表面的な特徴で分類した。「斜面が出てくる問題」「ばねが出てくる問題」「滑車が出てくる問題」といった具合である。一方、熟達者は、解くのに使う物理の原理で分類した。「エネルギー保存則で解く問題」「ニュートンの第二法則で解く問題」というように。見た目がまったく違う問題でも、同じ原理で解けるなら同じグループに入れたのである。

この研究は、転移の鍵がどこにあるかを示している。熟達者は、問題の表面の奥にある構造を見抜いている。だから、初めて見る問題でも、「これはあの原理の問題だ」と気づき、知識を適用できる。初心者は表面に目を奪われるので、表面が違う問題には、学んだ知識を結びつけられない。

### 不活性な観念

哲学者アルフレッド・ノース・ホワイトヘッドは、一九二九年の講演録『教育の目的』で、使われないまま頭の中にただ置かれている知識を「不活性な観念」と呼び、教育の最大の敵だと述べた。受け取られはするが、使われず、試されず、他の考えと新しい組み合わせを作ることもない観念。ホワイトヘッドはそれが、精神を錆びつかせると言った。

約百年前のこの指摘は、本章の枠組みにそのまま当てはまる。「分かる」だけで止まった知識、「思い出せる」けれど使われない知識は、不活性な観念である。知識は、使われて初めて生きる。そして、使う練習をしなければ、使えるようにはならない。

## 6　誤解されやすい点——「理解か暗記か」ではない

### 二つの極端な主張

学力の三つの状態について、よく見かける誤解が二つある。

一つ目は、「理解さえすれば、自然に覚えられるし、使えるようになる」という考え方だ。「丸暗記ではなく理解が大切」という教育論は、しばしばこの方向に傾く。しかし、本章で見てきたように、理解したことが思い出せるとは限らないし、思い出せることが使えるとも限らない。ギックとホリオークの実験では、参加者は将軍の物語を完全に理解していた。それでも、別の問題には使えなかった。理解は必要条件だが、十分条件ではない。

二つ目は、その逆で、「とにかく覚えれば、そのうち理解できるし、使えるようになる」という考え方だ。こちらは詰め込み型の勉強法に多い。確かに、覚えているうちに意味が分かってくることはある。しかし、意味を理解せずに覚えた知識は、覚えにくく、忘れやすく、応用もききにくい。第3章で見るように、知識は他の知識とつながることで、思い出しやすく、使いやすくなる。

三つの状態は、どれか一つを優先すればよいというものではない。理解・想起・運用のそれぞれに、別の練習が必要である。「理解か暗記か」という二者択一の問いの立て方自体が、問題を見えにくくしている。

### 反論——分かっていれば使えるのでは？

「本当に深く理解していれば、使えるはずだ。使えないのは、理解が浅いからではないか」という反論もあるだろう。

この反論にも一理ある。深い理解、たとえば「なぜその解法でうまくいくのか」まで分かっていれば、転移は起きやすくなる。チーらの研究で熟達者が原理で問題を分類できたのは、原理を深く理解していたからでもある。

しかし、深い理解は、説明を読むだけでは得られない。熟達者の理解は、多くの問題を自分で解き、失敗し、同じ原理が違う姿で現れることに何度も気づく中で、作られてきたものだ。つまり、深い理解は「使う」経験の結果として生まれる部分が大きい。「深く理解すれば使える」は、順序を逆に見ている面がある。使う練習をする中で、理解は深まっていくのである。

## 7　自分の学力を、三つの距離で診断する

本章の枠組みを使えば、自分の学力を具体的に診断できる。ある単元や分野について、次の三つの問いを順に試してほしい。

**「分かる」の確認**：教科書や解説を読んで、筋道に納得できるか。納得できないなら、まず理解から始める必要がある。ここで無理に先へ進まないこと。

**「思い出せる」の確認**：教科書を閉じて、白紙に要点を書き出せるか。公式、定義、用語、流れを、手がかりなしで再現できるか。英単語なら、日本語から英語が出てくるか。できないなら、第一の距離が残っている。

**「使える」の確認**：その単元の問題を、他の単元の問題と混ぜた状態で解けるか。初めて見る問題を前に、「これはあの知識で解ける」と気づけるか。論述なら、問いに合わせて知識を選び、つないで書けるか。できないなら、第二の距離が残っている。

多くの学習者は、一つ目の確認だけで「この単元は終わった」と判断している。二つ目と三つ目を確かめることで、本当に残っている課題が見えてくる。そして、第一の距離が残っているのか、第二の距離が残っているのかによって、次にすべき練習は変わる。第一の距離には思い出す練習が、第二の距離には混ぜて選ぶ練習が効く。この具体的な方法は第5章で詳しく述べる。

ここで、一つの疑問が浮かぶかもしれない。第一の距離、つまり「思い出せる」ようになることは、本当に必要なのだろうか。AIがあれば、公式も用語も英単語も、いつでも数秒で調べられる。わざわざ頭の中に入れておく意味はどこにあるのか。この疑問は、AI時代の学習を考えるうえで避けて通れない。次章では、この「暗記はもう要らないのか」という問いに、正面から取り組む。

# 第3章　検索できる知識を、なぜ覚えるのか——作業台と引き出しと倉庫

## 1　「暗記はもう要らない」は半分正しい

### 外部化の歴史

「これからの時代、暗記は必要ない。調べれば分かることを覚えるのは時間の無駄だ」。こうした意見は、検索エンジンが普及した二〇〇〇年代から繰り返し語られてきた。生成AIの登場で、その声はさらに大きくなっている。

この意見を頭ごなしに否定するつもりはない。実際、人類は知識を頭の外に出すことで、思考の範囲を広げてきた。はじめにで触れた文字の発明がそうだったし、印刷術、辞書、百科事典、電卓、検索エンジンもそうだ。友人の電話番号を覚えている人は、いまではほとんどいない。それで困ることはまずない。三角関数の値を小数点以下何桁まで暗記している技術者もいないだろう。必要なら計算機が教えてくれる。

外部化してよい知識を外部化することで、人間は限られた記憶力を、もっと重要なことに振り向けられるようになった。「暗記は要らない」という主張の正しい部分はここにある。すべてを覚える必要はないし、覚えるべきでないものもある。

### 「グーグル効果」とその後

検索と記憶の関係については、よく引用される研究がある。二〇一一年にベッツィ・スパロウらが科学誌『サイエンス』に発表した研究で、人は後で調べられると思っている情報を、覚えにくくなるという結果を報告した。いわゆる「グーグル効果」である。人間は、記憶の一部をインターネットに預け、「何を知っているか」よりも「どこに行けば分かるか」を覚えるようになっている、という主張だった。

この研究は大きな話題を呼んだが、その後の検証には注意が必要だ。二〇一八年、社会科学の研究の再現性を検証する大規模なプロジェクト（カメラーらによる）が、『ネイチャー』誌と『サイエンス』誌に掲載された社会科学の実験二十一本を追試したところ、スパロウらの研究の主要な実験の一つは、元の研究と同じ結果を再現できなかった。

だからといって、検索が記憶に影響しないと結論できるわけではない。一つの実験が再現されなかったことは、効果がないことの証明ではない。ただ、「検索のせいで人間の記憶力が落ちている」という話は、よく語られるほど確かな根拠に支えられているわけではない。本書では、こうした話題性の高い主張に頼らずに、もっと確かな土台から考えていきたい。その土台とは、人間の記憶と思考の基本的な仕組みである。

## 2　頭の中の仕組み——作業台と引き出し

### 考えるための作業台は小さい

人間が何かを考えるとき、頭の中では何が起きているのか。認知心理学は、考えることを支える記憶を、大きく二つに分けてきた。

一つは**ワーキングメモリ**（作業記憶）である。いま考えていることを一時的に保持し、操作するための記憶だ。暗算をするとき、途中の数字を覚えておく。文章を読むとき、前の文の内容を覚えたまま次の文を読む。こうした「頭の中で手元に置いておく」働きが、ワーキングメモリである。

もう一つは**長期記憶**である。これまでに学んだこと、経験したことが蓄えられている、ほぼ容量無制限の記憶だ。母語の単語、九九、自転車の乗り方、歴史の知識などは、長期記憶に保存されている。

本書では、この二つを、**作業台**と**引き出し**にたとえたい。ワーキングメモリは、考える作業をするための作業台である。長期記憶は、作業台のすぐ横にある、大量の道具や材料が入った引き出しだ。

この作業台には、決定的な特徴がある。**とても小さい**のだ。一九五六年、心理学者ジョージ・ミラーは、人間が一度に保持できる情報のまとまりは「七つ前後」だと論じた。その後の研究では、条件を厳密にすると、実際の容量はもっと少なく、四つ前後ではないかとする見方も有力になっている（ネルソン・コーワン、二〇〇一年）。いずれにせよ、作業台に一度に載せられるものは、ごくわずかなのである。

### 引き出しの中身が、作業台を広くする

作業台がこれほど小さいなら、人間はどうやって複雑なことを考えられるのだろうか。答えは、引き出し、つまり長期記憶にある。

たとえば、「はんせきほうかんはいはんちけんちそかいせい」という文字列を一度読んだだけで覚えてほしいと言われたら、多くの人は苦労するだろう。ひらがな二十文字を一つずつ作業台に載せようとすると、容量を大きく超えてしまうからだ。しかし、日本史を学んだ人なら、これを「版籍奉還」「廃藩置県」「地租改正」という三つのまとまりとして読み取れる。二十個の文字は、三つの品物になる。しかも、明治初期の改革が起きた順に並んでいると気づけば、三つは一本の流れとして、ほとんど一つの品物のように扱える。

ある程度の知識が引き出しにあると、ばらばらの情報を意味のあるまとまりとして扱える。このまとまりを、心理学では**チャンク**と呼ぶ。チャンクは、作業台の上では一つの品物として扱われる。つまり、引き出しの中身が豊かであればあるほど、同じ大きさの作業台に、多くの情報を実質的に載せられるのである。

これを見事に示したのが、チェスの研究だ。一九四〇年代にオランダの心理学者アドリアン・デ・フロートが、そして一九七三年にウィリアム・チェイスとハーバート・サイモンが、チェスの名人と初心者に盤面を数秒だけ見せ、駒の配置を再現させる実験を行った。実際の対局で現れる盤面なら、名人は驚くほど正確に再現できた。初心者はわずかな駒しか再現できなかった。

ところが、駒をでたらめに置いた、実際の対局ではありえない盤面を見せると、名人と初心者の差はほとんど消えた。名人の記憶力が、一般的に優れていたわけではなかったのである。名人は、長年の経験で蓄えた膨大な「盤面のパターン」を引き出しに持っていた。だから、実際の盤面は、いくつかの見慣れたパターンの組み合わせとして、少ないチャンクで記憶できた。でたらめな盤面にはそのパターンがないので、名人の強みは生きなかった。

### 考えることは、作業台の上でしか起きない

ここから、本章の中心的な主張が導かれる。

**考えるという作業は、作業台の上で起きる。そして、作業台に素早く載せられるのは、引き出しの中にあるものだけである。**

外部の情報、たとえば教科書やインターネットやAIの出力は、いわば作業場から離れた場所にある**倉庫**のようなものだ。倉庫の中身も作業台に載せることはできる。しかし、倉庫から取ってくるには時間と手間がかかるし、何より、取ってきたものを作業台に載せると、それだけで小さな作業台が埋まってしまう。

たとえば、英語の長文を読んでいて、知らない単語が一文に三つあったとしよう。一つずつ辞書やAIで調べれば、意味は分かる。しかし、三つの単語の意味を作業台に載せた時点で、作業台はかなり埋まっている。文の構造を把握し、前の文とのつながりを考え、筆者の主張を追う余裕は、ほとんど残らない。一方、三つの単語が引き出しに入っている人は、単語の意味を意識せずに処理できるので、作業台をまるごと、文の内容を考えることに使える。

AIや検索は、倉庫を途方もなく大きくした。しかし、作業台の大きさは変わっていない。そして、倉庫の中身を効率よく使うためにも、引き出しの中身が必要になる。この点を、次に見ていこう。

## 3　知識がなければ、読めず、調べられず、疑えない

### 野球の文章を読む実験

引き出しの中身がどれほど理解を左右するかを示した研究として、一九八八年にドナ・レクトとローレン・レスリーが行った、いわゆる「野球実験」がある。

米国の中学生を、読解力の高低と、野球についての知識の多少で、四つのグループに分けた。そして、野球の試合の一場面を描いた文章を読ませ、その内容を、模型の野球場で人形を動かしながら再現させた。結果、野球についての知識が多い生徒は、読解力が低くても、よく内容を理解し再現できた。読解力が高くても野球の知識が少ない生徒は、それほどうまく再現できなかった。この研究は、読解力と呼ばれるものの多くが、実は文章のテーマについての知識に支えられていることを示す例として、広く引用されてきた。

ただし、この研究にも限界はある。参加者は六十四人と少なく、一つのテーマ（野球）だけを扱っている。二〇二五年には、この研究の結果がどこまで一般化できるかを検討し直す論文も出ている。読解において知識が重要であることを否定する研究者はほとんどいないが、「知識さえあれば読解力はいらない」と言えるほど単純ではない。読解の技能と知識は、両方が組み合わさって働く、と理解しておくのが妥当だろう。

### 英語を「ゼロ」から立て直したとき

私がこの仕組みを最も切実に実感したのは、英語をほとんどゼロの状態から学び直した生徒を指導したときだった。

その生徒は不登校の時期があり、英語は中学の基礎から抜け落ちていた。それでも、関西の外国語大学に進みたいという目標を持っていた。外国語大学を目指す以上、最終的には大学入試レベルの英文を読めなければならない。時間は限られている。焦りから、いきなり入試の長文問題に取り組みたくなる気持ちはよく分かったし、分からない単語は翻訳ツールで調べれば、長文の意味を追うこと自体はできる。

しかし、本章で見た作業台の仕組みを考えれば、それは遠回りになる。一文に知らない単語が三つも四つもあれば、その意味を調べて作業台に載せた時点で、作業台はいっぱいになる。文の構造をつかみ、前後の文とのつながりを考え、筆者の言いたいことを追う余裕は残らない。調べながら読んで意味が分かったとしても、それは第2章でいう「分かる」にすぎず、次に同じ単語が出てきたときに引き出しから取り出せるわけではない。

そこで、最初の時期は、長文から離れることにした。中学レベルの基本単語と、英文の骨組みを作る基本的な文法に絞り、それを毎回の授業の冒頭で、見ずに思い出す小テストで確かめた。前回できなかったものは次回にもう一度出し、できたものは間隔をあけて出す。第5章で述べる原則を、ほとんどそのまま使った形である。英文を読む練習も、最初は短い文から始め、一文の中で主語と動詞がどれかを見抜くことを繰り返した。

地味な作業が続いた。しかし、引き出しに基本の単語と文の型が入っていくにつれ、同じ長さの英文を読むときに、作業台に余裕が生まれていくのが、生徒の読み方から見て取れた。単語の意味を一つずつ思い出すことに作業台を使わなくて済むようになると、ようやく段落の流れや筆者の主張に注意を向けられるようになる。長文読解の練習が本当の意味で役に立ち始めたのは、そこからだった。この生徒は、関西の外国語大学に合格した。

もちろん、これは一人の生徒の事例であり、同じやり方が誰にでも同じ期間で通用すると言うつもりはない。ただ、「知らない単語は調べればいい」という考え方が、学び始めの段階ではかえって学習を遅らせることがある、という点は、多くの学習者に共通すると考えている。

### 何を検索すべきかは、知識が教えてくれる

「知らないことは調べればいい」という主張には、見落とされている前提がある。**自分が何を知らないかを知っている**、という前提だ。

たとえば、歴史の史料を読んでいて、ある出来事の意味がよく分からなかったとする。背景知識がある人は、「これは当時の土地制度と関係があるのではないか」と見当をつけ、それを調べる。背景知識がない人は、何を調べればよいかさえ分からない。「分からない」ということは分かるが、どこが分からないのかが分からないのである。

AIへの質問でも同じことが起きる。AIは、質問されたことには答えてくれる。しかし、何を質問すべきかは教えてくれない。いや、正確には「何を質問すればいいですか」と聞けば答えてくれるが、その答えが自分の状況に合っているかを判断するのは、やはり自分の知識である。検索もAIも、良い問いを立てられる人ほど役に立つ。そして良い問いは、引き出しの中身から生まれる。

### AIの誤りに気づくのは、頭の中の知識

もう一つ、AI時代に特有の理由がある。生成AIは、もっともらしい誤りを出力することがあるからだ。

生成AIは、存在しない論文を引用したり、微妙に間違った数値を答えたり、論理が途中でずれた説明をしたりすることがある。しかも、その誤りは、正しい情報と同じ自信に満ちた文体で示される。

この誤りに気づけるのは、誰だろうか。答えは、その分野の知識を自分の頭に持っている人である。数学の解答で、途中の式変形がおかしいと気づくには、自分で式変形ができなければならない。歴史の説明で、年代の前後関係がおかしいと気づくには、おおまかな年代の流れが頭に入っていなければならない。倉庫から取り出した品物が不良品かどうかは、良い品物がどんなものかを引き出しの中の知識で知っている人にしか、見分けられないのだ。

「AIが答えを出してくれるなら、知識は要らない」という主張は、AIが常に正しいことを前提にしている。しかし、その前提は成り立たない。AIの出力を鵜呑みにせず、検証し、判断するためには、むしろ知識が必要なのである。

## 4　それでも外部化してよい知識の基準

### すべてを覚える必要はない

ここまで、頭の中の知識が必要な理由を述べてきた。しかし、冒頭で認めたとおり、すべてを覚える必要はない。問題は、何を覚え、何を倉庫に預けるかである。本書では、その判断のために四つの基準を提案したい。

**基準一：使用頻度**。その知識は、自分が考える場面で、どれくらい頻繁に使われるか。英語を読むとき、頻出する数千語の単語は、ほぼすべての文章で使われる。これを毎回調べていては、読むことができない。一方、専門分野でしか使わない単語は、出てきたときに調べれば十分だ。

**基準二：判断の土台になるか**。その知識は、他の多くの知識を理解したり、判断したりするための土台になっているか。歴史でいえば、各時代のおおまかな流れや、主要な出来事の因果関係は、他のあらゆる知識を位置づける骨組みになる。これに対し、個々の人物の細かな生没年は、骨組みにぶら下がる枝葉であることが多い。本書では、他の多くの知識をつなぐ中心的な知識を「**ハブ知識**」と呼びたい。ハブ知識は、倉庫に預けてはいけない。

**基準三：調べる余裕があるか**。その知識が必要になる場面で、調べる時間や手段があるか。試験の最中、会議での議論、顧客との会話、手術中の判断などでは、調べる余裕がない。こうした場面で使う知識は、頭に入れておくしかない。

**基準四：誤りに気づく必要があるか**。その知識について、AIや他人の情報が間違っていたときに、自分で気づけなければ困るか。自分の専門分野や、重大な判断に関わる分野では、困る度合いは大きい。

### 知識の四つの区分

四つの基準のうち、特に重要な一つ目と二つ目を組み合わせると、知識を四つに区分できる。

**使用頻度が高く、判断の土台にもなる知識**は、最優先で覚えるべき知識である。英語の基本語彙と文法、数学の基本的な公式とその意味、各教科の基本概念、歴史の大きな流れなどがここに入る。これらは、引き出しの手前に、すぐ取り出せる状態で置いておきたい。

**使用頻度は低いが、判断の土台になる知識**は、細部まで覚える必要はないが、「存在と意味」は理解しておくべき知識である。たとえば、数学のある定理の証明の細部は覚えていなくても、なぜその定理が成り立つのかの筋道は理解しておく。必要なときに倉庫から取り出せるように、目印をつけておくイメージだ。

**使用頻度は高いが、判断の土台にはならない知識**は、使っているうちに自然に覚えるものが多い。意識して暗記するより、繰り返し使う中で身につけるのが効率的だ。よく使うパソコンの操作手順などが典型である。

**使用頻度が低く、判断の土台にもならない知識**は、外部化してよい知識である。細かな数値、珍しい固有名詞、めったに使わない手順などは、必要なときに調べればよい。

ただし注意したいのは、この区分は、学ぶ目的によって変わるということだ。大学入試を受ける高校生にとって、ある年号は試験で問われる可能性がある以上、覚える必要がある（基準三）。同じ年号も、社会人が教養として歴史を学ぶ場合には、外部化してよいかもしれない。何を覚えるかは、自分が何のために学んでいるかと切り離しては決められないのである。

## 5　「覚える」の質を変える

### 丸暗記と、つながりの中での記憶

「知識を覚える必要がある」と言うと、無味乾燥な丸暗記を思い浮かべる人がいるかもしれない。しかし、本書が勧めているのは、丸暗記ではない。

同じ知識でも、覚え方によって、その後の使いやすさが大きく変わる。孤立した点として覚えた知識は、思い出すための手がかりが少なく、忘れやすい。一方、他の知識とのつながりの中で覚えた知識は、さまざまな手がかりから思い出せるし、使うべき場面で自然に浮かんでくる。

たとえば、「一九二九年、世界恐慌」という知識を、年号と出来事の組み合わせとして丸暗記することもできる。しかし、「第一次世界大戦後のアメリカの好景気と、過剰な投機」「株価の暴落」「銀行の連鎖倒産と国際的な資金の引き揚げ」「各国の保護主義とブロック経済」「ドイツでのナチス台頭」という因果の流れの中に位置づけて覚えれば、この知識は、ブロック経済についての問題を考えるときにも、ナチスの台頭についての問題を考えるときにも、呼び出されるようになる。

心理学では、新しい情報を既存の知識と結びつけ、意味づけながら覚えることを**精緻化**と呼ぶ。「なぜそうなるのか」「これは何と似ているか」「これは何の例か」を考えながら覚えることで、記憶は深く、使いやすくなる。

### 記憶は思考の残りかす

認知心理学者のダニエル・ウィリンガムは、「記憶は思考の残りかすである」という趣旨の言葉を残している。私たちが覚えているのは、そのとき考えたことだ、という意味である。

歴史の教科書を読んでも、年号の数字に注意を向けていれば年号が残り、出来事の意味について考えていれば意味が残る。英文を読んでも、単語の訳を考えていれば訳が残り、筆者の主張について考えていれば主張が残る。何を覚えるかは、何を考えたかによって決まる。

この原則は、AIの利用を考えるうえでも重要になる。AIに答えを聞いたとき、あなたが考えたのが「この答えを写せば宿題が終わる」ということだけなら、頭に残るのはそれだけだ。答えの中身について考えなければ、答えの中身は残らない。第6章で詳しく論じるが、AI時代の学習の要点の一つは、AIを使っていても、考えるべきことを自分で考え続けることにある。

## 6　反論に答える——認知負荷を下げることの利点

### AIで負担を減らせば、本質に集中できる

ここまでの議論に対して、強力な反論がありうる。「作業台が小さいのなら、AIを使って作業台の負担を減らせばいい。そのほうが、本質的な思考に集中できるはずだ」。

この反論は、実は教育心理学の重要な理論と一致している。オーストラリアの心理学者ジョン・スウェラーらが発展させた**認知負荷理論**は、学習中の作業台の負担を、大きく三種類に分けて考える。学ぶ内容そのものの難しさから来る負荷（内在的負荷）、教材の分かりにくさなど学習に関係のない原因から来る負荷（外在的負荷）、そして学習を深めるために使われる負荷である。この理論に従えば、学習に関係のない負荷は、できるだけ減らすべきだということになる。

たとえば、大学生が英語で書かれた専門書を読んで、その分野の概念を学ぼうとしているとしよう。この学生の学習目標が「専門分野の概念を理解すること」であれば、知らない英単語を一つずつ辞書で引く負担は、目標にとっては外在的な負荷である。AIに難しい単語の意味を示してもらうことで、作業台を内容の理解に使えるなら、それは合理的な選択だ。同様に、物理の問題で、物理の考え方を学ぶのが目的なら、面倒な数値計算を電卓に任せるのは理にかなっている。

### ただし、その負荷が「学習の本体」なら話は別

しかし、ここには重大な条件がつく。**その負荷が、学習の目標そのものである場合には、減らしてはいけない**ということだ。

さきほどの英語の例で、学習者が英語を学んでいる高校生なら、話はまったく変わる。この生徒の目標は英語を読めるようになることであり、知らない単語の意味を文脈から推測したり、辞書を引いて覚えたりすることは、学習の本体そのものだ。これをAIに任せれば、英語の学習そのものが起きなくなる。同じ作業でも、学習目標によって、減らすべき負荷にもなれば、減らしてはいけない負荷にもなるのである。

この考え方は、第6章で「引き算テスト」という形で具体化する。ここでは、その基本的な考え方だけを確認しておきたい。AIで負荷を減らすことには、確かな利点がある。しかし、どの負荷を減らしてよいかは、自分が何を学ぼうとしているかによって決まる。

### 初心者と熟達者では、同じ支援の効果が逆になる

もう一つ、見落とされやすい点がある。同じ支援でも、学習者の熟達度によって効果が変わるということだ。

認知負荷理論の研究者スラヴァ・カリユガらは、初心者には効果的な丁寧な解説や手順の提示が、ある程度熟達した学習者にはかえって学習を妨げることを示し、これを**熟達化逆転効果**と名づけた。初心者は、引き出しに知識がないので、丁寧な支援で作業台の負担を減らしてもらうと学びやすい。しかし熟達者は、すでに引き出しに知識があるので、丁寧な支援は冗長になり、自分の知識と支援の内容を照らし合わせる余計な負担を生む。

AIの支援にも、同じことが言えるだろう。まったくの初学者が、基本的な概念を理解するためにAIの丁寧な説明を使うのは有効かもしれない。しかし、ある程度知識がある学習者が、自分で考えればできることまでAIに説明させると、自分で考える機会を失うだけでなく、学習の効率も下がりうる。AIの使い方も、自分の熟達度に合わせて変えていくべきだろう。

---

本章では、「検索できる知識をなぜ覚えるのか」という問いに対して、考えることは作業台の上で起き、作業台に素早く載せられるのは引き出しの中身だけだから、と答えた。知識は、考えるための材料であり、AIや検索という巨大な倉庫を使いこなすための鍵でもある。

では、その知識を材料にして「考える」とき、頭の中では具体的に何が起きているのだろうか。「思考力が大切だ」とはよく言われるが、思考力とは何かを具体的に説明できる人は少ない。次章では、この曖昧な言葉を、四つの具体的な頭の動きに分解してみたい。そうすれば、AIが思考のどの部分を代わりにできて、どの部分は人間にしかできないのかも、はっきり見えてくるはずだ。

# 第4章　思考力の正体——見抜く・選ぶ・組み立てる・確かめる

## 1　「思考力を鍛えよう」がうまくいかない理由

### 誰もが言うが、誰も説明しない言葉

「これからの時代に必要なのは、知識ではなく思考力だ」。教育改革の議論でも、企業の採用の場でも、この言葉は繰り返し語られてきた。生成AIの登場で、その声はさらに強くなっている。AIが知識を提供してくれるのだから、人間は考えることに集中すべきだ、というわけだ。

しかし、「思考力とは何ですか」と尋ねられて、具体的に答えられる人は多くない。「自分の頭で考える力」「論理的に考える力」「批判的に考える力」といった言い換えは出てくるが、それは別の言葉に置き換えただけで、中身の説明にはなっていない。中身が分からないものは、鍛えようがない。「思考力を鍛えよう」という掛け声が、しばしば空回りする理由はここにある。

### 思考力は、中身から切り離せない

さらに、前章までの議論から、もう一つの問題が見えてくる。思考力は、知識と切り離して鍛えられるものなのか、という問題だ。

前章のチェスの研究を思い出してほしい。名人が優れていたのは、一般的な記憶力ではなく、チェスの盤面についての知識だった。同じことが、思考力についても言える。数学の問題を解く思考力が高い人が、法律の問題でも同じように優れた思考ができるとは限らない。医師として優れた診断を下す人が、経営判断でも優れているとは限らない。熟達化の研究は、優れた思考の多くが、特定の領域の知識に深く根ざしていることを示してきた。心理学ではこれを、思考の**領域固有性**と呼ぶ。

だから、「知識ではなく思考力を」という対比は、そもそも成り立たない。思考力は、知識を材料にして働く。材料がなければ、どれほど優れた調理法を知っていても、料理はできない。

とはいえ、思考のすべてが領域ごとにばらばらだというわけでもない。どの領域でも共通して見られる「考えるときの頭の動き」はある。本章では、それを四つの動詞として取り出してみたい。**見抜く**、**選ぶ**、**組み立てる**、**確かめる**、の四つである。これは、第2章で数学の問題を分解したときに現れた五つの工程を、教科を問わず使える形にまとめ直したものだ。

## 2　思考の四つの動詞

### 見抜く——表面の奥の構造をつかむ

一つ目の動詞は、**見抜く**である。目の前の問題や状況の、表面の奥にある構造をつかむ働きだ。

第2章で紹介したチーらの研究で、物理の熟達者は、問題を「斜面」「滑車」といった表面ではなく、「エネルギー保存」「運動方程式」といった原理で分類した。これが「見抜く」である。問題文の中から、解決に関わる本質的な特徴を拾い出し、「これは何の問題か」を判断する。

数学の例で考えよう。「nを自然数とするとき、n³−nは6の倍数であることを示せ」という問題がある。初めて見た生徒は、「6の倍数を示すって、どうすればいいんだろう」と戸惑う。ここで見抜くべきことは、n³−n が n(n−1)(n+1) と因数分解でき、「連続する三つの整数の積」になっている、という構造である。これに気づけば、「連続する三つの整数の中には、必ず2の倍数と3の倍数が含まれる」という知識が呼び出され、問題は一気に解決へ向かう。

国語の読解でも、見抜く力は働く。評論文を読むとき、「この文章は、一般的な見方を示してから、それを否定して筆者の主張を述べる構造になっている」と見抜ければ、どこに筆者の主張があるかが分かる。英語の長文でも、「この段落は、前の段落の主張に対する具体例だ」と見抜ければ、細部が分からなくても、段落の役割は理解できる。

見抜く力は、引き出しにどれだけ「型」が入っているかに大きく左右される。「連続する整数の積」という型を知らない生徒は、n(n−1)(n+1) を見ても、それが何を意味するか気づかない。見抜く力は、知識と経験の蓄積の上に成り立つのである。

### 選ぶ——複数の候補から方針を決める

二つ目の動詞は、**選ぶ**である。見抜いた構造をもとに、考えられる複数の方針の中から、どれを採用するかを決める働きだ。

多くの問題には、複数の解き方がありうる。さきほどの整数問題でも、「連続する三つの整数の積」を使う方法のほかに、nを6で割った余りで場合分けする方法や、数学的帰納法を使う方法がある。熟達した解き手は、それぞれの方法を頭の中で素早く比較し、最も見通しのよい方法を選ぶ。

選ぶ力は、日常の判断でも重要になる。大学のレポートで、ある社会問題を論じるとき、経済の観点から論じるか、歴史の観点から論じるか、倫理の観点から論じるか。資料の量、自分の知識、レポートの字数、読み手の関心などを考え合わせて、方針を選ぶ必要がある。

選ぶ力の中心にあるのは、**比較と見通し**である。複数の選択肢を思い浮かべ、それぞれを選んだら先にどうなるかを予測し、比較する。そのためには、選択肢を思い浮かべるための知識と、先を予測するための経験が必要だ。一つの方法しか知らない人は、そもそも選ぶことができない。

### 組み立てる——手順と論理を実行する

三つ目の動詞は、**組み立てる**である。選んだ方針に沿って、実際に手順を実行し、論理をつなぎ、答えや文章を作り上げる働きだ。

数学なら、式を変形し、計算を進め、証明を書く。国語の記述問題なら、本文から根拠となる箇所を拾い、つなぎ合わせて、指定された字数で答えを書く。英作文なら、文の構造を決め、単語を選び、文法的に正しい文を作る。レポートなら、序論・本論・結論の構成を決め、段落ごとに論を展開する。

組み立てる力は、四つの動詞の中で最も目に見えやすい。答案や文章として、形に残るからだ。だから、多くの人が「思考力」と聞いて思い浮かべるのは、この組み立てる力かもしれない。しかし、組み立てる作業は、見抜くことと選ぶことが済んだ後に来る。方針が間違っていれば、どれほど正確に組み立てても、正しい答えにはたどり着かない。

### 確かめる——結果と過程を検証する

四つ目の動詞は、**確かめる**である。組み立てた結果が正しいか、過程に誤りがないか、問いに対して適切に答えているかを検証する働きだ。

数学なら、計算の見直しに加えて、答えが問題の条件を満たしているか、場合分けに漏れがないか、具体的な数値を代入して確かめる。第2章の二次関数の問題なら、たとえば a=1 のときの最小値を直接計算して、場合分けの答えと一致するか確認する。国語の記述なら、書いた答えが設問の要求（「理由を説明せよ」なのか「内容を説明せよ」なのか）に合っているか、本文の内容と矛盾していないかを確認する。

確かめる力は、四つの動詞の中で最も軽視されやすい。答えが出た時点で、多くの学習者は満足してしまう。しかし、優れた解き手ほど、確かめることに時間を使う。数学者ジョージ・ポリアは、問題解決の古典『いかにして問題をとくか』で、問題解決の最終段階として「振り返り」を挙げ、結果を検討し、別の方法で導けないか、他の問題に使えないかを考えることの重要性を説いた。

そして、次節以降で見るように、AI時代には、この確かめる力の重要性が一段と高まる。

## 3　五つ目の動詞——問う

### 問いがなければ、思考は始まらない

四つの動詞は、問題が与えられたときの頭の動きだった。しかし、現実の世界では、問題はいつも与えられるとは限らない。自分で問題を見つけ、問いを立てることから、思考が始まる場面も多い。そこで、四つの動詞の前に、もう一つ、五つ目の動詞を置きたい。**問う**である。

学校の勉強では、問いは先生や教科書や試験が用意してくれる。しかし、大学の研究でも、仕事でも、日々の生活でも、「何が問題なのか」を自分で見つけることが、最初の、そしてしばしば最も難しい一歩になる。

歴史の学習で考えてみよう。「江戸幕府は、なぜ鎖国をしたのか」という問いは、教科書にもよく載っている。しかし、ここから一歩進んで、「鎖国と言われるが、実際にはオランダや中国、朝鮮、琉球、アイヌとの交流は続いていた。では、何が閉ざされ、何が開かれていたのか」と問うことができれば、学習はぐっと深まる。さらに、「なぜ幕府は、キリスト教の布教を伴わないオランダとだけヨーロッパの中で交易を続けたのか」と問えば、宗教と貿易と権力の関係という、より大きな構造が見えてくる。

### 良い問いの条件

では、良い問いとはどのような問いか。学習の場面に限って言えば、少なくとも三つの条件が挙げられる。

一つ目は、**具体的であること**。「歴史について知りたい」ではなく、「十七世紀の日本が、なぜオランダとは交易を続けたのか」。具体的な問いは、答えの手がかりがどこにあるかを示してくれる。

二つ目は、**答えを確かめられること**。「なぜ人は学ぶのか」のような問いも大切だが、学習の場面では、資料や論理によって答えを検証できる問いのほうが、理解を深めるのに役立つ。

三つ目は、**自分の理解の穴を突いていること**。すでに知っていることを確認する問いより、「自分はここが分かっていない」という部分に向けられた問いのほうが、学習の効果は大きい。「この公式はどう使うのか」より、「この公式は、なぜこの形になるのか」「この公式が使えない場合はあるのか」という問いのほうが、理解の穴を埋める。

### AI時代、問いの価値は上がる

生成AIの時代に、「問う」力の価値はさらに高まる。AIは、問われたことに答える道具だからだ。AIから得られる答えの質は、問いの質に大きく左右される。

「光合成について教えて」と問えば、教科書的な一般論が返ってくる。「光合成で、光が当たらないときにも進む反応があると聞いた。それはどの段階で、なぜ光が要らないのか」と問えば、自分の理解の穴に合わせた答えが返ってくる。後者の問いを立てられるのは、光合成についてある程度の知識を持ち、自分がどこを分かっていないかを把握している人だ。

ここで、前章の議論とつながる。良い問いを立てるには、知識が必要なのである。まったく知らない分野では、何を問えばよいかも分からない。知識が問いを生み、問いがさらに知識を広げる。この循環を回すことが、AIを学習の味方にする鍵になる。

## 4　メタ認知——自分の頭を外から見る力

### メタ認知とは何か

五つの動詞のすべてを、裏側から支えている力がある。**メタ認知**である。

メタ認知とは、自分自身の認知、つまり、自分が何を知っていて何を知らないか、いま何を考えているか、自分の考え方はうまく働いているか、を一段上から把握し、調整する働きのことだ。一九七〇年代に心理学者ジョン・フラベルが提唱した概念で、「認知についての認知」とも説明される。

メタ認知には、大きく二つの側面がある。一つは**モニタリング**、つまり自分の状態を観察することだ。「この問題は、自分にはまだ難しい」「この章の内容は、半分くらいしか理解できていない」「いまの方針では、うまくいきそうにない」と気づく働きである。もう一つは**コントロール**、つまり観察した結果をもとに、自分の行動を調整することだ。「この問題は後回しにしよう」「この章はもう一度最初から読もう」「方針を変えよう」と判断する働きである。

### 受験勉強での現れ方

メタ認知は、受験勉強のあらゆる場面に現れる。

第1章で見た三つの錯覚は、すべてメタ認知の失敗として説明できる。読み返しで「覚えた」と感じるのは、自分の記憶の状態を正しくモニタリングできていないからだ。章末問題が解けて「できるようになった」と感じるのも、解答を見て「分かった」と感じるのも、同じである。

試験の場面でも、メタ認知は働く。試験時間の配分を考えるとき、ある問題に時間をかけるべきか、飛ばして次に進むべきかを判断するとき、見直しの時間にどの問題を重点的に確認すべきかを決めるとき。これらはすべて、自分の状態をモニタリングし、行動をコントロールするメタ認知の働きである。

### メタ認知が弱い人の典型的な失敗

メタ認知が弱い学習者には、よく見られる失敗のパターンがある。

一つ目は、**「どこが分からないか分からない」**状態である。質問を促しても、「全部分からない」か「特に質問はない」かのどちらかになる。自分の理解の状態を細かくモニタリングできていないので、どこでつまずいたのかを特定できない。

二つ目は、**できることばかり繰り返す**ことである。すでに解ける問題を何度も解いて安心し、解けない問題を避ける。自分の弱点を正確に把握できていないか、把握していても、それに向き合うようにコントロールできていない。

三つ目は、**方針を変えられない**ことである。試験で、最初に選んだ方針がうまくいかないのに、同じ方法に固執し続け、時間を使い果たしてしまう。「この方針では無理そうだ」と気づくモニタリングか、方針を切り替えるコントロールのどちらかが働いていない。

### メタ認知を鍛える方法

メタ認知は、生まれつきの能力ではなく、練習によって鍛えられる。具体的な方法をいくつか挙げよう。

一つ目は、**解く前に予測する**ことである。問題を解く前に、「この問題は解けそうか」「自信は何割くらいか」を予測し、書き留めておく。解き終わった後、予測と結果を比べる。自信があったのに間違えた問題、自信がなかったのに正解した問題は、自分のモニタリングがずれている場所を教えてくれる。この練習を続けると、自分の実力についての見積もりが、だんだん正確になっていく。

二つ目は、**解いた後に自分に説明する**ことである。正解した問題でも、「なぜこの方針を選んだのか」「どこで迷ったか」「次に似た問題が出たら、どこに注目するか」を、言葉にしてみる。これは、自分の思考の過程を外から眺める練習になる。

三つ目は、**分からないところを言葉にする**ことである。「分からない」で止まらず、「この式からこの式への変形が分からない」「この段落が前の段落とどうつながるのかが分からない」と、できるだけ具体的に言葉にする。この練習は、第6章で扱う「AIへの質問」の質を上げることにも直結する。

## 5　AIは思考のどこを代替できるか

### 最も代替されやすいのは「組み立てる」

五つの動詞とメタ認知という枠組みを手に入れたので、ここで生成AIとの関係を考えてみよう。AIは、思考のどの部分を代わりにできるのだろうか。

最も代替されやすいのは、**組み立てる**働きである。方針が決まっていれば、AIは計算を進め、文章を整え、コードを書くことに非常に長けている。レポートの構成案を示せば、それに沿った文章を書いてくれる。英作文の内容を日本語で伝えれば、文法的に正しい英語にしてくれる。

**見抜く**と**選ぶ**も、ある程度はAIが代わりにできる。問題を丸ごと渡せば、AIは問題の構造を分析し、方針を立てて解いてくれる。ただし、その分析や方針が適切かどうかは、問題によって大きく異なる。

### 要約を例に考える

AIと人間の役割分担を、要約という具体的な作業で考えてみよう。

AIは、長い文章を数秒で要約できる。その結果、「文章を短くまとめる」という作業そのものの希少性は大きく下がった。しかし、要約という作業を五つの動詞で分解すると、別の姿が見えてくる。

まず、何のために要約するのかという目的を決める（問う）。同じ文章でも、試験の準備のための要約と、上司への報告のための要約では、残すべき情報が違う。次に、文章の構造を把握する（見抜く）。どこが主張で、どこが根拠で、どこが具体例か。そして、目的に照らして、どの情報を残し、どの情報を捨てるかを判断する（選ぶ）。それを短い文章にまとめる（組み立てる）。最後に、要約が元の文章の趣旨を正しく反映しているか、重要な情報が抜けていないか、誤った情報が紛れ込んでいないかを検証する（確かめる）。

AIが得意なのは、主に「組み立てる」の部分である。目的の設定も、情報の取捨選択の判断も、AIに指示すればある程度はできる。しかし、その判断が自分の目的に合っているか、要約が妥当かを検証する仕事は、人間側に残る。しかも、その検証は、元の文章を自分で理解していなければできない。

### でこぼこの境界線

AIの能力には、もう一つ厄介な特徴がある。得意なことと苦手なことの境界が、人間の直感とずれていることだ。

二〇二三年、ハーバード・ビジネス・スクールのファブリツィオ・デラクアらは、大手コンサルティング会社ボストン・コンサルティング・グループのコンサルタント七百人あまりを対象に、GPT-4を使って実際の業務に近い課題に取り組ませる実験を行った。AIの能力の範囲内にある課題では、AIを使ったコンサルタントは、より多くの課題を、より速く、より高い品質でこなした。ところが、AIが苦手とする種類の課題では、AIを使ったコンサルタントは、使わなかったコンサルタントに比べて、正しい答えにたどり着く確率が大きく下がった。AIのもっともらしい誤った答えを、そのまま受け入れてしまったのである。

研究チームは、AIの能力の境界を「でこぼこの境界線」と表現した。AIは、人間には難しく見える課題を簡単にこなす一方で、人間には簡単に見える課題で思わぬ誤りを犯す。しかも、どこに境界線があるのかは、外から見ても分かりにくい。

この研究が示しているのは、**確かめる**力の重要性である。AIの出力が境界線の内側のものか外側のものかを判断するには、自分でその内容を検証できなければならない。そして、検証する力は、その分野の知識と、自分で見抜き、選び、組み立てた経験から生まれる。AIに思考を任せれば任せるほど、確かめる力は育ちにくくなる。しかし、AIの時代にこそ、確かめる力が最も必要になる。この逆説が、第6章の議論の出発点になる。

## 6　反論——思考力は生まれつきではないのか

### 熟達化の研究から

ここまで、思考力を五つの動詞とメタ認知に分解し、それぞれが知識と経験に支えられていることを述べてきた。しかし、「結局、頭のいい人はもともと頭がいいのではないか」という疑問を持つ読者もいるだろう。

この疑問に対しては、熟達化の研究が一つの見方を提供している。心理学者アンダース・エリクソンらは、一九九三年、音楽学校のバイオリン専攻の学生を調べ、最も優れた演奏家たちが、それまでに積み重ねてきた「意図的な練習」の時間が長かったことを報告した。意図的な練習とは、ただ漫然と繰り返すのではなく、自分の弱点に焦点を当て、明確な目標を持ち、フィードバックを受けながら行う練習のことだ。この研究は、優れた能力の多くが、生まれつきの才能よりも、練習の質と量によって形作られることを示唆するものとして、大きな影響を与えた。

### ただし、練習がすべてではない

ただし、この研究にも限界がある。二〇一四年、ブルック・マクナマラらは、意図的な練習と能力の関係を調べた多くの研究を統合して分析するメタ分析を行った。その結果、意図的な練習の量で説明できる能力の差（分散）は、全体で約一二％にとどまった。分野によって差があり、ゲームや音楽では比較的大きく、教育の分野では約四％と小さかった。さらに二〇一九年には、マクナマラとメガ・マイトラが、エリクソンらのバイオリン研究を、評価者に生徒の群分けを知らせないなど方法を改良して追試した。すると、最も優れた演奏家と、それに次ぐ水準の演奏家の間に、練習時間の明確な差は見られなかった。

つまり、練習は重要だが、能力の差のすべてを説明するわけではない。練習を始めた年齢、既に持っている知識、ワーキングメモリの個人差、練習の質の違い、動機づけなど、さまざまな要因が関わっている。「誰でも一万時間練習すれば天才になれる」という言い方は、研究の結論を単純化しすぎている。

では、本書の立場はどうなるのか。こう考えたい。**思考力の個人差は確かに存在する。しかし、思考力の多くの部分、特に本章で述べた五つの動詞とメタ認知は、知識と練習によって確実に伸ばせる。**生まれつきの差を嘆くよりも、自分が伸ばせる部分に集中するほうが、はるかに生産的だ。そして、どれほど生まれつきの能力が高い人でも、知識と練習なしに特定の分野で優れた思考をすることはできない。

---

本章では、思考力を、見抜く・選ぶ・組み立てる・確かめる・問うという五つの動詞と、それらを裏から支えるメタ認知に分解した。そして、AIが最も代替しやすいのは組み立てる働きであり、見抜く・選ぶ・確かめる・問うは、人間の側に強く残ることを見た。

では、これらの力を実際に伸ばすには、どのように学習を組み立てればよいのだろうか。次章では、ここまでの章で見てきた原理を、具体的な学習の設計図にまとめる。思い出す練習、間隔をあけた復習、混ぜての練習、説明すること、そして間違いの分析。それぞれを、明日から使える形で示していきたい。

# 第5章　伸びる学習の設計図——想起・間隔・交互・説明・誤答分析

## 1　学習を「設計」するという発想

### 量から構造へ

ここまでの四つの章で、学習についての原理を見てきた。学習中の手ごたえは当てにならないこと（第1章）。学力には、分かる・思い出せる・使えるという三つの状態があること（第2章）。考えることは頭の中の知識を材料にして起きること（第3章）。思考は五つの動詞とメタ認知に分解できること（第4章）。

本章では、これらの原理を、具体的な学習の方法にまとめる。キーワードは「設計」である。

多くの学習者は、学習を「量」で考えている。何時間勉強したか、何ページ進んだか、問題集を何周したか。量はもちろん大切だ。しかし、同じ時間でも、どのような構造で学習するかによって、身につくものは大きく変わる。建物にたとえれば、同じ量の材料を使っても、設計次第で、頑丈な家にも、すぐに崩れる家にもなる。

本章で示す設計の原則は五つある。**思い出す**、**間隔をあける**、**混ぜる**、**説明する**、そして**間違いを資源にする**。最初の四つは、学習科学の研究で効果が繰り返し確認されてきた方法を、第2章の三つの距離に対応させたものだ。五つ目は、日本の教育心理学の知見も取り入れた、本書独自の誤答分析の枠組みである。

## 2　原則一　思い出す——想起の練習

### 最も確かな方法

第1章で、ローディガーとカーピキーの実験を紹介した。読み返すよりも、思い出す練習をしたほうが、時間がたってからの記憶が残る。この効果は、心理学では**テスト効果**、あるいは**検索練習**の効果と呼ばれ、学習科学の中でも最も確かな知見の一つとされている。前述のダンロスキーらの評価でも、練習テストは「有用性が高い」と判定された二つの方法の一つだった。

思い出す練習がなぜ効くのか、そのメカニズムについてはいくつかの説明がある。一つの有力な説明は、記憶は取り出すたびに強化され、取り出すための経路が増える、というものだ。本を読み返すとき、情報は外から入ってくる。しかし思い出すとき、脳は自分の力で情報を再構成しなければならない。この再構成の努力が、記憶を強くする。

### さまざまな「思い出し方」

思い出す練習というと、問題集を解くことを思い浮かべるかもしれない。もちろんそれも有効だが、方法はほかにもある。

**白紙再現**は、最も手軽で強力な方法だ。教科書の一節や授業の内容を学んだ後、何も見ずに、覚えていることをすべて白紙に書き出す。箇条書きでも図でもよい。書き終えたら教科書と照らし合わせ、書けなかった部分、間違っていた部分を確認する。そして、もう一度白紙に書く。

**問いと答えのカード**は、英単語や用語の暗記に向いている。ポイントは、表を見て裏を思い出す、その「思い出す」段階を必ず踏むことだ。裏をすぐにめくってしまえば、それは再認の練習になってしまう。思い出せなくても、数秒は頑張って思い出そうとする。

**説明の再現**は、理科や社会の理解を深めるのに向いている。「光合成の仕組みを、何も見ずに説明する」「明治維新の流れを、何も見ずに説明する」。声に出してもいいし、紙に書いてもいい。

二〇一一年、カーピキーとジャネル・ブラントは、科学的な文章を学ぶ際に、思い出す練習をしたグループと、コンセプトマップ（概念同士の関係を図にしたもの）を作ったグループを比較した。コンセプトマップは、概念同士のつながりを考えるので、理解を深める方法として教育現場で広く使われてきた。ところが、一週間後のテストでは、思い出す練習をしたグループのほうが成績がよかった。しかも、そのテストには、単純な記憶を問う問題だけでなく、推論を必要とする問題も含まれていた。思い出す練習は、単なる暗記だけでなく、理解の深まりにもつながりうるのである。

### 条件と限界

ただし、思い出す練習にも条件がある。

一つ目は、**正しい答えを確認すること**。思い出そうとしたが、思い出せなかったり、間違って思い出したりした場合、正しい答えを確認しなければ、誤った記憶が残ることがある。思い出す練習とフィードバックは、セットで行うのが原則だ。

二つ目は、**難しすぎないこと**。まったく学んでいないことを思い出そうとしても、何も出てこない。何も出てこない練習を続けても、得られるものは少ない。ある程度学んだ後に、少し努力すれば思い出せる状態で練習するのが効果的だ。ただし、後で述べるように、学ぶ前に問題に挑戦すること自体には、別の効果がありうる。

三つ目は、**思い出す内容と、使う場面が合っていること**。英単語を「英語→日本語」の方向でしか練習しなければ、「日本語→英語」の方向では思い出せないかもしれない。使う場面を想定して、思い出す方向を決める必要がある。

## 3　原則二　間隔をあける——分散の練習

### 忘れかけた頃に思い出す

二つ目の原則は、**間隔をあける**ことである。同じ内容を、一度にまとめて学ぶより、時間をあけて何度かに分けて学ぶほうが、長く記憶に残る。これを**分散学習**、あるいは**間隔効果**と呼ぶ。十九世紀の心理学者ヘルマン・エビングハウスの研究以来、百年以上にわたって確認されてきた現象である。

間隔をあけると効果が高まる理由の一つは、忘れかけた頃に思い出そうとすると、思い出すための努力が大きくなり、その努力が記憶を強くするからだと考えられている。前節の思い出す練習と、この間隔の効果は、組み合わせることでさらに力を発揮する。

### 最適な間隔はどれくらいか

では、どれくらいの間隔をあければよいのか。

二〇〇八年、ニコラス・セペダらは、千三百人を超える参加者を対象に、学習と復習の間隔、そして復習から最終テストまでの期間をさまざまに変えた大規模な実験を行った。その結果、最適な復習の間隔は、最終テストまでの期間によって変わることが分かった。おおまかに言えば、テストまでの期間が数週間なら、その二割前後の間隔で復習するのが最もよく、テストまでの期間が一年になると、その比率は五％程度まで下がった。

この結果を、受験勉強に当てはめてみよう。一週間後の小テストに備えるなら、学んだ翌日か翌々日に一度復習するのがよい。一か月後の定期試験に備えるなら、一週間ほどあけて復習する。一年後の入試に備えるなら、数週間の間隔で復習を繰り返す。もちろん、この数字は実験室の条件で得られたもので、そのまま機械的に当てはめるべきものではない。しかし、「試験が先であるほど、復習の間隔も長くしてよい」という原則は、覚えておく価値がある。

### 復習スケジュールの例

具体的なスケジュールの例を示そう。たとえば、ある日に英単語を五十語学んだとする。

**一回目の復習**は、翌日に行う。思い出せなかった単語に印をつける。**二回目の復習**は、その三日後から一週間後に行う。前回印をつけた単語を中心に確認する。**三回目の復習**は、さらに二週間から一か月後に行う。ここで思い出せた単語は、しばらく放っておいてもよい。思い出せなかった単語は、また短い間隔の復習に戻す。

このように、思い出せた項目は間隔を広げ、思い出せなかった項目は間隔を縮める。この原理は、多くの暗記アプリにも組み込まれている。アプリを使ってもよいし、手帳やノートに復習の予定を書き込んでもよい。大切なのは、復習を「気が向いたとき」ではなく、「予定された日」に行うことだ。

### 詰め込みはなぜ効くように感じるのか

試験の前夜に詰め込んだ経験がある人は多いだろう。そして、詰め込みで試験を乗り切った経験がある人も多いはずだ。詰め込みは、本当に効果がないのだろうか。

詰め込みは、直後のテストでは一定の効果がある。第1章で見たように、読み返したグループは五分後のテストでは成績がよかった。しかし、詰め込んだ内容は、試験が終わると急速に忘れられる。定期試験を詰め込みで乗り切っても、数か月後の模試や入試では、その内容はほとんど残っていない。受験のように、学んだことを長期間にわたって積み上げる必要がある学習では、詰め込みは、同じ内容を何度も学び直すことになる、効率の悪い方法なのである。

## 4　原則三　混ぜる——交互の練習

### 「何の問題か」を判断する練習

三つ目の原則は、**混ぜる**ことである。第1章で紹介したローラーとテイラーの研究のように、異なる種類の問題を混ぜて練習すると、同じ種類をまとめて練習するより、長期的な成績がよくなる。これを**交互練習**、あるいは**インターリービング**と呼ぶ。

混ぜる練習が効くのは、第2章で見た第二の距離、つまり「思い出せる」から「使える」への距離を埋めるからだ。問題が混ざっていると、一問ごとに「これは何の問題か」「どの解法を使うべきか」を判断しなければならない。これは、第4章の「見抜く」と「選ぶ」の練習そのものである。

### 教科ごとの混ぜ方

数学なら、単元別の問題集を一通り終えた後、複数の単元の問題を混ぜて解く。入試の過去問や模試は、もともと単元が混ざっているので、良い練習材料になる。問題集を使う場合は、問題番号をシャッフルして解く、複数の章からランダムに問題を選ぶ、といった工夫ができる。

英語の文法問題なら、「関係代名詞の章」「分詞の章」と章ごとに解いた後、章を混ぜた問題集で練習する。関係代名詞の章の問題なら、答えが関係代名詞だと分かっている。しかし混ざっていれば、「ここは関係代名詞か、分詞か、それとも接続詞か」を自分で判断する必要がある。

社会なら、時代ごとに学んだ後、時代を横断するテーマで知識を整理する。たとえば、「日本の土地制度の変遷」「対外関係の変化」といったテーマで、異なる時代の知識を並べて比較する。これは、第2章で述べた「つながりとしての知識」を作る練習にもなる。

### 注意——学び始めはまとめてよい

ただし、混ぜる練習にも適切な時期がある。

まったく新しい単元を学び始めたばかりの段階では、まとめて練習するほうがよいことが多い。まず、その単元の解法の基本を理解し、ある程度使えるようにならなければ、他の単元と混ぜても、判断の練習にならないからだ。まとめての練習で基本を身につけ、その後に混ぜての練習で判断力を鍛える。この二段階で考えるのがよいだろう。

## 5　原則四　説明する——精緻化・自己説明・教える準備

### 「なぜ」を問う

四つ目の原則は、**説明する**ことである。学んだ内容について、「なぜそうなるのか」「これは何とつながっているのか」を自分で説明する。

第3章で見たように、新しい情報を既存の知識と結びつけながら覚えることを精緻化と呼ぶ。その代表的な方法が、「なぜ」を問うことだ。「光合成には光が必要である」という知識を学んだら、「なぜ光が必要なのか」「光のエネルギーは、何に使われるのか」と自分に問う。答えを考える過程で、新しい知識は、既存の知識のネットワークの中に位置づけられる。

### 自己説明の効果

説明することの効果を示した研究として、ミシュリン・チーらが一九八九年に行った研究がある。物理の例題を学ぶ学生たちの様子を調べたところ、成績のよい学生は、例題の解答の各ステップについて、「なぜこのステップが必要なのか」「この式はどこから来たのか」を自分に説明しながら読んでいた。成績の振るわない学生は、解答をただ読み進めるだけだった。

この**自己説明**は、第2章で問題にした「解説を読めば分かるのに、初見では解けない」という状態を改善する方法でもある。解説を読むとき、ただ一行ずつ納得するのではなく、「なぜここでこの方法を選んだのか」「自分なら、問題文のどこからこの方針に気づけたか」を説明しながら読む。そうすることで、解説者が済ませていた「見抜く」と「選ぶ」の工程を、自分の頭で追体験できる。

### 教えるつもりで学ぶ

説明の効果は、他人に教える場面でさらに強くなりうる。二〇一四年、ジョン・ネストイコらは、文章を学ぶ前に「後でこの内容をテストします」と伝えたグループと、「後でこの内容を他の人に教えてもらいます」と伝えたグループを比較した。実際には、どちらのグループも同じテストを受け、誰かに教えることはなかった。それでも、教えるつもりで学んだグループのほうが、内容をよく覚えており、特に重要なポイントをよく思い出せた。

教えるつもりで学ぶと、学習者は、情報を整理し、重要なポイントを見極め、分かりやすい説明の仕方を考えながら学ぶ。これが学習を深めると考えられている。友人と教え合う、家族に今日学んだことを説明する、あるいは、誰かに教えるつもりでノートを作る。これらは、どれも説明の原則を生かした方法である。

## 6　先に考えるか、先に教わるか——原則どうしの緊張

### 「まず自分で考えよ」は本当に正しいか

ここまでの原則と、第6章で述べるAIの使い方には、「答えを見る前に、まず自分で考える」という考え方が繰り返し出てくる。しかし、この考え方には、学習科学の中にも有力な反論がある。公平のために、ここで検討しておきたい。

二〇〇六年、ポール・カーシュナー、ジョン・スウェラー、リチャード・クラークは、「最小限の指導しか与えずに、学習者に自分で発見させる」タイプの教育方法は、初学者にとっては効果が低いと主張する論文を発表し、大きな論争を呼んだ。第3章の認知負荷理論に基づけば、知識のない初学者が自力で問題を解こうとすると、小さな作業台が試行錯誤でいっぱいになり、肝心の解法を学ぶ余裕がなくなる。初学者には、まず解き方の手本（例題とその解説）を示すほうが効率的だ、というのである。実際、例題の解説を学んでから類題を解くほうが、最初から自力で解くより学習が進むという「例題効果」は、多くの研究で確認されている。

一方、シンガポールの研究者マヌ・カプールは、先に教わるより、先に問題に挑戦して失敗し、その後で正しい解き方を教わるほうが、概念の深い理解や転移が促される場合があることを示し、これを「生産的失敗」と名づけた。その後、五十三の研究を統合した分析（シンハとカプール、二〇二一年）でも、先に問題に挑戦してから教わるほうが、先に教わってから問題を解くより、全体として中程度の効果で有利だった。ただし、小学二年生から五年生にあたる児童では逆に、先に教わるほうが有利な傾向が見られている。また、第6章で触れるように、学ぶ前にテスト問題に挑戦し、解けなかったとしても、その後の学習が深まることを示した研究もある（コーネルら、二〇〇九年）。

### 二つの立場をどう折り合わせるか

この二つの立場は、一見すると正反対だが、実は両立させることができる。鍵は、「学習者がいまどの段階にいるか」と「何のための挑戦か」である。

まったく新しい単元の最初の段階では、例題と解説から学ぶほうがよい。前提となる知識がない状態で長時間悩んでも、得られるものは少ない。本章の原則三で「学び始めはまとめてよい」と述べたのと同じ理屈である。

一方、基本的な知識をある程度身につけた後で、初めての問題に取り組む段階では、まず自分で考える時間をとるほうがよい。この段階での「先に考える」は、解法をゼロから発見するためではない。すでに引き出しに入っている知識の中から、どれが使えるかを探す練習、つまり第4章の「見抜く」と「選ぶ」の練習である。たとえ解けなくても、自分がどこで行き詰まったのかが分かっていれば、その後に解説を読んだとき、何を学ぶべきかがはっきりする。

そして、どちらの段階でも、考える時間には上限を設ける。本書で「十五分」といった目安を示しているのはそのためだ。手がかりがまったく見えないまま何十分も悩み続けるのは、望ましい困難ではなく、ただの停滞である。一定時間考えて方針が立たなければ、解説やヒントに進んでよい。ただし、そのときも「自分はどこまで考え、どこで止まったか」を言葉にしてから進むこと。それが、解説を読む学習の質を大きく変える。

## 7　原則五　間違いを資源にする——誤答の四分類

### 間違いは、最も価値のある情報

五つ目の原則は、**間違いを資源にする**ことである。

多くの学習者は、間違いを「失敗」として扱う。丸つけをして、バツがついた問題の正しい答えを赤ペンで書き写し、次に進む。しかし、これでは間違いが持つ情報を、ほとんど捨ててしまっている。間違いは、自分の学力のどこに穴があるかを正確に教えてくれる、最も価値のある情報である。

日本の教育心理学者、市川伸一は、学習者が問題を解いた後に、「なぜ間違えたのか」「次に同じような問題に出会ったとき、何に気をつければよいのか」を自分で引き出すことを**教訓帰納**と名づけ、その重要性を説いてきた。一つの問題の正解を知ることより、その問題から、次の問題にも使える教訓を引き出すことのほうが、学習の効果は大きい。

### 誤答の四分類

では、間違いからどのように教訓を引き出せばよいか。本書では、間違いの原因を、第2章と第4章の枠組みに沿って、四つに分類することを提案したい。

**一つ目は、知識の欠落**である。解くのに必要な知識を、そもそも学んでいなかった、あるいは理解していなかった場合だ。英単語の意味を知らなかった。公式を習っていなかった。この場合の処方は、その知識を学ぶことである。ただし、知識の欠落は、実は四つの中で最も対処しやすい。

**二つ目は、想起の失敗**である。必要な知識は学んでいて、見れば分かるが、試験の場面では思い出せなかった場合だ。「答えを見たら、あ、知ってた、と思った」という間違いはこれにあたる。第2章の第一の距離が埋まっていない状態である。処方は、思い出す練習と間隔をあけた復習だ。

**三つ目は、方針の誤り**である。必要な知識は思い出せたが、問題のどこに注目すべきかを見抜けなかった、あるいは誤った方針を選んでしまった場合だ。「解説を読んだら、なるほどそうやるのか、と思った」という間違いはこれにあたる。第2章の第二の距離、第4章の「見抜く」と「選ぶ」の問題である。処方は、混ぜての練習と、解説を読むときに「問題文のどこからこの方針に気づけたか」を言葉にすることだ。

**四つ目は、実行のミス**である。方針は正しかったが、計算を間違えた、問題文を読み違えた、答えの書き方を誤った、という場合だ。「ケアレスミス」と呼ばれるものの多くがこれにあたる。処方は、自分がどんな種類の実行ミスをしやすいかを把握し、それを重点的に「確かめる」習慣をつけることだ。

### 「ケアレスミス」で片づけない

四つ目の実行のミスについて、一言付け加えておきたい。多くの学習者は、実行のミスを「ケアレスミス」と呼び、「次は気をつけよう」で済ませてしまう。しかし、「気をつけよう」という教訓は、ほとんど役に立たない。何に、どう気をつけるのかが、具体的でないからだ。

実行のミスは、実は、人によって決まったパターンを持っていることが多い。符号を落としやすい、分数の計算で約分を忘れやすい、問題文の「正しくないものを選べ」を読み飛ばしやすい、など。自分のミスを記録していくと、そのパターンが見えてくる。パターンが分かれば、「マイナスの符号が出てきたら丸で囲む」「設問の否定語には下線を引く」といった、具体的な対策が立てられる。

また、実行のミスの背後に、別の原因が隠れていることもある。計算ミスが多いのは、実は計算の基本的な手順が身についておらず（想起の失敗）、作業台の多くを計算に取られているからかもしれない。何度も同じ種類の「ケアレスミス」をするなら、それは不注意ではなく、別の分類の問題である可能性を疑うべきだ。

### 自信のある間違いは、よく直る

間違いについて、心理学には興味深い知見がある。自信を持って答えた間違いほど、正しい答えを知らされた後に、よく修正されるというのだ。ブレア・バターフィールドとジャネット・メトカーフが二〇〇一年に報告したこの現象は、**過修正効果**と呼ばれている。

自信を持っていた答えが間違っていたと知ったとき、人は驚く。その驚きが、正しい答えへの注意を強め、記憶を強化すると考えられている。これは、第4章で述べた「解く前に自信を予測する」練習と組み合わせると、さらに生きてくる。自信があったのに間違えた問題は、最も大きな学習の機会なのである。

### 誤答ノートの作り方

誤答の分析を習慣にするために、「誤答ノート」を作ることを勧めたい。ただし、よくある誤答ノートの作り方には、問題がある。間違えた問題と正しい解答を丁寧に書き写すノートだ。これは、第1章で見た「成果物の錯覚」に陥りやすい。書き写す作業に時間を取られ、肝心の分析がおろそかになる。

本書が勧める誤答ノートは、書くことを最小限にする。書くのは次の三つだけでよい。問題の出典（問題集の何ページの何番か）、間違いの分類（四分類のどれか）、そして教訓（次に同じような問題が出たら、何に気をつけるか）である。教訓は、できるだけ具体的に書く。「平方完成を忘れない」ではなく、「文字を含む二次関数の最大・最小は、まず軸の位置を求めて、範囲との関係で場合分けする」というように。

そして、このノートは、書いて終わりではなく、前節までの原則に沿って使う。数日後に、ノートに記録した問題を、解答を見ずに解き直す（思い出す、間隔をあける）。いくつかの単元の誤答をまとめて、混ぜて解き直す（混ぜる）。教訓を、自分の言葉で説明し直す（説明する）。

### 中学受験に並走して

誤答の分析は、年齢の低い学習者にも使える。ただし、そのままの形では難しい。

関西の中学受験で、ある生徒の受験に並走し、志望していた有名中学への合格まで指導したことがある。中学受験の算数は、塾から出される宿題の量が非常に多い。小学生が毎週の宿題をすべて一度解くだけで、手一杯になる。解いて丸をつけ、バツの問題は解説を読んで直す。それで一週間が終わり、次の週にはまた新しい単元の宿題が来る。第1章で述べた「解けた」と「解ける」の取り違えが、構造的に起こりやすい環境である。

この生徒との学習で最初に変えたのは、「全部を一度解く」から「解けなかった問題を、日をあけてもう一度解く」への重心の移動だった。宿題の一問一問に、自力で解けたら○、解説を読んで分かったら△、解説を読んでも分からなかったら×をつける。△と×の問題だけを、数日後に何も見ずに解き直す。二度目に解けたものは、さらに間隔をあけてもう一度。宿題を全部二度解く時間はないが、△と×だけなら何とかなる。

誤答の四分類も、小学生向けに言い換えた。「知らなかった」（知識の欠落）、「思い出せなかった」（想起の失敗）、「気づかなかった」（方針の誤り）、「うっかり」（実行のミス）の四つである。たとえば算数の比の問題で間違えたとき、比の性質そのものを知らなかったのか、知っていたのにその場で思い出せなかったのか、問題文のどこが比の問題だと気づくべきだったのか、それとも計算の途中でうっかり間違えたのか。これを小学生が自分で選ぶだけでも、「次は気をつける」よりずっと具体的な教訓が出てくる。

保護者との役割分担も大切だった。保護者に算数を教えてもらう必要はない。お願いしたのは、解き直しの予定を一緒に確認することと、ときどき「その問題、どうやって解いたの？」と子どもに説明を求めることだった。第7章で改めて述べるが、説明を求められることは、子どもにとって自分の理解を確かめる最良の機会になる。

年齢が低いほど、本章の前節で述べたように、先に解き方を教わってから練習するほうが効果的な場面が多い。それでも、「解けなかった問題を、日をあけて、何も見ずに解き直す」という一点だけは、小学生にも十分に実行できるし、効果も大きいと私は考えている。

## 8　一週間を設計する

五つの原則を、具体的な一週間の学習計画に落とし込んでみよう。ここでは、三つの典型的な学習者の例を示す。これは一つのモデルであり、自分の状況に合わせて調整してほしい。

### 受験生の場合

高校二年生で、数学と英語を中心に大学受験の準備をしている生徒を想定する。平日は一日二時間、週末は一日四時間程度の学習時間があるとしよう。

平日の二時間は、前半を新しい内容の学習、後半を復習にあてる。新しい内容の学習では、例題を読んだら、解説を閉じて自分で解き直す（思い出す）。解説を読むときは、「なぜこの方針か」を説明しながら読む（説明する）。後半の復習では、前日に学んだ内容を白紙に再現し（思い出す、間隔をあける）、数日前から一週間前に学んだ内容の問題を、単元を混ぜて解く（混ぜる）。

週末の四時間は、一週間の総まとめにあてる。一週間分の誤答ノートを見直し、記録した問題を解答を見ずに解き直す。さらに、過去に学んだ単元も含めた混合問題や、模試の過去問に取り組む。

### 社会人の資格試験の場合

仕事をしながら、半年後の資格試験を目指す社会人を想定する。平日は通勤時間の三十分と夜の一時間、週末は一日三時間程度としよう。

通勤時間は、暗記アプリやカードを使った思い出す練習にあてる。スマートフォンでも、読むのではなく、問いを見て答えを思い出す形式にする。夜の一時間は、新しい内容の学習と、その日の内容の白紙再現にあてる。社会人の学習では、仕事の経験と結びつけて「これは自分の仕事のどの場面に関係するか」を考えることが、精緻化として特に有効である。週末は、一週間分の復習と、過去問を使った混合練習にあてる。

### 大学生の場合

講義を受けて、期末試験やレポートに取り組む大学生を想定する。大学の学習では、講義の内容を受け身で聞くだけになりやすい。

講義の後、その日のうちに十五分でよいので、ノートを見ずに講義の要点を書き出す（思い出す）。一週間後の次の講義の前に、前回の講義の要点をもう一度書き出す（間隔をあける）。レポートを書く前には、講義で扱ったいくつかのテーマを横断して、比較や関連づけを考える（混ぜる、説明する）。友人と勉強会を開き、互いに講義の内容を説明し合うのも効果的だ（説明する）。

## 9　誤解——「自分に合った勉強法」とは何か

### 学習スタイルの神話

最後に、学習法についてよく聞かれる誤解を一つ取り上げておきたい。「人にはそれぞれ合った学習スタイルがある。視覚型の人は図で、聴覚型の人は音声で学ぶのがよい」という考え方だ。

この考え方は、教育現場でも広く信じられてきた。しかし、二〇〇八年、ハロルド・パシュラーらは、学習スタイルについての研究を検討し、学習者を好みのスタイルに分けて、それに合わせた方法で教えると学習効果が高まる、という主張を支持する十分な証拠は見当たらないと結論した。その後の研究でも、この結論はおおむね支持されている。

### 個人差はどこにあるのか

では、学習に個人差はないのかといえば、もちろんそうではない。ただし、その個人差は、「視覚型」「聴覚型」といったスタイルの違いよりも、**すでに持っている知識の量と質**、そして**学習の目的**の違いによるところが大きい。

第3章で見た熟達化逆転効果を思い出してほしい。初心者には丁寧な解説が有効で、熟達者には自分で考える機会が有効だった。同じ人でも、ある分野では初心者で、別の分野では熟達者でありうる。また、一週間後の小テストに備える学習と、一年後の入試に備える学習では、最適な復習の間隔が違う。

「自分に合った勉強法」を探すときには、「自分はどんなタイプか」ではなく、「自分はこの分野について、いまどの段階にいるか」「何のために、いつまでに学ぶのか」を考えるほうが、はるかに役に立つ。本章の五つの原則は、どの段階の、どの目的の学習者にも当てはまる土台であり、その上で、段階と目的に応じて、困難の程度や復習の間隔を調整していけばよい。

---

本章では、学習の設計図として五つの原則を示した。思い出す、間隔をあける、混ぜる、説明する、間違いを資源にする。これらは、AIがなかった時代から有効だった方法である。そして、AIの時代にも、その有効性は変わらない。

では、この設計図の中に、AIをどう組み込めばよいのだろうか。AIは、思い出す練習の相手にも、説明の聞き手にも、間違いの分析の助手にもなりうる。一方で、使い方を誤れば、本章の五つの原則を、すべて台無しにしてしまう。次章では、いよいよAIを正面から扱い、AIに任せてよい苦労と、任せてはいけない苦労を見分ける方法を示す。

# 第6章　AIを使う学習、AIに奪われる学習——「引き算テスト」と六つの使い方

## 1　同じAIが、学力を上げもし、下げもする

### 四つの研究を並べる

はじめにで、二つの対照的な研究を紹介した。トルコの高校で汎用のAIを使って演習した生徒たちは、AIを外した試験で成績を落とした（バスタニら）。ハーバード大学で、学習科学に基づいて設計されたAIチューターを使った学生たちは、能動的な授業を上回る学習の伸びを示した（ケスティンら）。ここに、さらに二つの研究を加えてみよう。

一つは、世界銀行がナイジェリアのエド州で行った研究である（デ・シモーネら、二〇二五年）。公立の中等学校の生徒を対象に、六週間にわたる放課後のプログラムで、GPT-4を使った英語学習を行った。生徒たちは、教師の支援のもとで、AIを家庭教師のように使い、英語の学習内容について質問したり、説明や助言を受けたりした。その結果、プログラムに参加した生徒は、参加しなかった生徒に比べて、英語などを問うテストで標準偏差にして〇・三一の成績向上を示した。研究チームは、これを通常の学校教育の一・五年から二年分に相当する伸びだと推計している。

もう一つは、北京大学やオーストラリアのモナシュ大学などの研究者からなる国際チーム（ファンら、二〇二五年）が、百十七人の大学生を対象に行った実験である。学生たちは、資料を読んで小論文を書き、それを改善する課題に取り組んだ。学生は、ChatGPTの助けを受けるグループ、人間の専門家の助けを受けるグループ、文章分析ツール（チェックリストなど）を使うグループ、何の支援も受けないグループに無作為に分けられた。ChatGPTの助けを受けたグループは、小論文の点数を最も大きく改善した。ところが、課題を通じて学んだ知識の量や、それを別の場面に応用する力については、他のグループとの間に明確な差は見られなかった。さらに、ChatGPTを使った学生は、自分の文章を振り返ったり、評価したりする行動が少なかった。研究チームはこれを「メタ認知的な怠惰」と呼んだ。

### 分かれ目は「誰が考えたか」

四つの研究を並べると、一つの共通点が浮かび上がる。

学力が伸びた研究では、AIは学習者に考えさせるように使われていた。ハーバードのAIチューターは、答えを先に教えず、学生に一歩ずつ考えさせるように設計されていた。ナイジェリアのプログラムでは、教師の支援のもとで、生徒自身がAIに問いかけながら学習を進めた。研究チームも、効果が出たのは教師の支援とともに丁寧に実施されたからだと強調している。トルコの研究でも、答えを直接教えないヒント型のAIを使ったグループは、成績を落とさなかった。

一方、学力が伸びなかった、あるいは下がった研究では、AIが学習者の代わりに考えていた。トルコの汎用AIのグループでは、生徒の多くが答えを写していた。ファンらの研究では、ChatGPTが文章の改善を代わりに行い、学生は自分で振り返る工程を省いた。成果物（演習の正答、小論文の点数）は向上したが、頭の変化は起きなかった、あるいは少なかったのである。

第1章で導入した「成果物」と「頭の変化」の区別が、ここでそのまま当てはまる。AIは、成果物を改善するのが非常にうまい。しかし、頭の変化は、学習者自身の頭が働いたときにしか起きない。AIが成果物を改善する過程で、学習者の頭が働く工程を奪ってしまえば、成果物は良くなっても、学力は伸びない。

### AIが学習を効率化するのは、どんなときか

ただし、この結論を「AIは使わないほうが安全だ」と読むのは誤りである。学力が伸びた研究を見直すと、AIが学習を効率化する仕組みが、少なくとも五つ見えてくる。

一つ目は、**フィードバックの速さ**である。学習では、答えが合っていたか、どこを間違えたかを早く知るほど、修正がしやすい。人間の教師が一人ひとりの答案にすぐ応じるのは難しいが、AIなら、書いた直後に反応を返せる。

二つ目は、**難しさの個別調整**である。第1章で述べた「望ましい困難」は、学習者ごとに適切な水準が違う。集団授業では、一つの説明や課題を全員に合わせることになる。AIなら、「もう少し易しく」「もう一段難しく」と、一人ひとりの段階に合わせて調整できる。

三つ目は、**練習材料の無限の供給**である。思い出す練習にも、混ぜる練習にも、問題が必要だ。市販の問題集の量には限りがあるが、AIは、自分の学習内容に合わせた問題をいくらでも作れる。

四つ目は、**質問のしやすさ**である。授業中に手を挙げて質問するのは、多くの生徒にとって心理的なハードルが高い。「こんなことを聞いたら恥ずかしい」と思って質問を飲み込み、分からないまま進んでしまう。AIには、何度同じことを聞いても、どれほど初歩的なことを聞いても、気後れせずに済む。

五つ目は、**周辺作業の削減**である。第3章で見たように、学習の目標に関係のない負荷を減らせば、作業台を学習の本体に使える。

これら五つの利点は、どれも学習者が自分で考えることを前提にしている。速いフィードバックは、自分で答えを出したからこそ意味がある。練習問題は、自分で解くからこそ役に立つ。AIが学習を効率化するのは、学習者の頭が働く工程を支えるときであって、その工程を肩代わりするときではない。

では、AIを使うとき、どの工程を自分に残し、どの工程をAIに任せればよいのか。本章では、その判断のための基準として「引き算テスト」を提案する。

## 2　引き算テスト——その苦労を消すと、身につけたい力も消えるか

### 一つの問い

引き算テストは、次の一つの問いからなる。

**「この苦労をAIに任せて消したとき、自分が身につけたい力も一緒に消えてしまうか」**

答えが「消える」なら、その苦労は学習の本体であり、自分でやらなければならない。答えが「消えない」なら、その苦労は学習の周辺であり、AIに任せてかまわない。

これは、第3章で紹介した認知負荷理論の考え方を、日常的に使える形にしたものだ。学習の目標に直接関わる負荷は減らしてはいけない。学習の目標に関係のない負荷は、減らしたほうがよい。引き算テストは、目の前の苦労がどちらにあたるかを判断するための問いである。

### 前提——身につけたい力を言葉にする

引き算テストを使うための前提がある。**自分が身につけたい力を、言葉にしておく**ことだ。

同じ作業でも、身につけたい力によって、判断が変わる。第3章の英語の例を思い出してほしい。英語を学んでいる高校生にとって、知らない英単語の意味を調べて覚える苦労は、学習の本体である。しかし、英語で書かれた専門書から専門知識を学ぼうとしている大学生にとっては、同じ苦労が学習の周辺になりうる。

だから、AIを使う前に、「いま自分は、何の力を身につけようとしているのか」を一言で言えるようにしておく。「数学の二次関数の最大・最小の問題を、初見で解けるようになる」「英語の論説文を、辞書なしで読めるようになる」「このテーマについて、自分の意見を論理的に書けるようになる」。こうして目標がはっきりすれば、引き算テストの答えも自然に出てくる。

### 具体例で試す

いくつかの具体例で、引き算テストを試してみよう。

**例一：英作文**。英作文の力をつけたい高校生が、自分で書いた英文の文法の誤りを、AIに指摘してもらう。この場合、英文を書く苦労は自分で担っている。AIが担うのは、誤りを見つける部分である。誤りの発見をAIに任せると、「自分で誤りを見つける力」は育ちにくいが、「英文を書く力」は消えない。そして、指摘された誤りを自分で理解し、書き直すなら、学習は起きる。条件付きで、使ってよい。

一方、同じ高校生が、日本語で書いた内容をAIに英訳してもらい、それを提出したとする。この場合、英文を組み立てる苦労そのものをAIに任せている。英作文の力を身につけるという目標は、この苦労と一緒に消える。使ってはいけない使い方である。

**例二：レポート**。大学の授業で、あるテーマについてレポートを書く課題が出た。身につけたい力は、「資料を読み、自分の論点を立て、論理的に論じる力」だとする。

この場合、関連する文献を探す手がかりをAIに尋ねることは、条件付きで使ってよい。文献探しの手間は学習の周辺である場合が多い（ただし、提示された文献が実在するかは、必ず自分で確認する必要がある。AIは存在しない文献を作り出すことがあるからだ）。文献の内容を要約してもらうことは、慎重に考える必要がある。要約を読むだけでは、文献を自分で読み、重要な部分を見抜く苦労が消えるからだ。そして、レポートの論点そのものをAIに決めてもらうこと、レポートの本文をAIに書いてもらうことは、使ってはいけない。「自分の論点を立て、論じる力」という目標の中心が、そのまま消えてしまうからである。

**例三：数学の問題**。数学の問題を初見で解けるようになりたい受験生が、分からない問題をAIに解いてもらう。この場合、問題を解く苦労、つまり第4章の見抜く・選ぶ・組み立てる・確かめるのすべてを、AIに任せている。目標は完全に消える。

しかし、同じ受験生が、まず自分で十五分考え、方針を立てようとした後で、「この問題で、最初に注目すべき点だけヒントをください。答えや解き方は言わないでください」とAIに頼んだとする。この場合、見抜く苦労の一部はAIに助けられるが、選ぶ・組み立てる・確かめるの苦労は自分に残る。トルコの研究でいえば、ヒント型AIの使い方にあたる。

## 3　AI利用の六つの型

### 使い方を区別する

「AIを勉強に使う」と一口に言っても、その使い方はさまざまだ。そして、使い方によって、学習への効果は大きく異なる。本書では、学習におけるAIの使い方を、六つの型に分けて整理したい。

**型一：答えを得る**。問題の答えや、事実についての情報をAIに尋ねる。

**型二：説明させる**。概念や解法について、AIに説明を求める。

**型三：問題を作らせる**。自分の学習内容に合わせた練習問題を、AIに作ってもらう。

**型四：添削させる**。自分が書いた答案や文章を、AIに評価・修正してもらう。

**型五：問い返させる**。AIに、自分の理解を確かめる質問をしてもらう。AIを試験官や、議論の相手として使う。

**型六：書かせる**。レポートや作文、答案そのものを、AIに書いてもらう。

これらの型のうち、どれが学習に役立ち、どれが学習を妨げるのか。以下では、各型について、効果が出る条件と、失敗しやすいパターンを見ていこう。

### 型一：答えを得る

答えを得る使い方は、最も手軽で、最も危険な使い方である。

知りたい事実を調べる場合、たとえば、歴史の出来事の年号を確認する、単語の意味を確認する、といった場合は、辞書や教科書を引くのと本質的には変わらない。ただし、AIは誤った事実を答えることがあるので、重要な情報は教科書や信頼できる資料で確認する必要がある。

問題を解いて答えを得る場合は、引き算テストに照らして慎重に判断すべきだ。自分で解くべき問題の答えをAIに求めれば、学習は起きない。一方、自分で解いた後に、答え合わせのためにAIを使うなら、学習を妨げない。問題は、答えを得る「タイミング」にある。

### 型二：説明させる

説明させる使い方は、うまく使えば非常に強力だ。教科書の説明が分かりにくいとき、自分の理解の段階に合わせて、何度でも、別の角度から説明してもらえる。「中学生にも分かるように」「具体例を三つ挙げて」「図にするとどうなるか」と注文をつけることもできる。

ただし、説明させる使い方には、第1章の「流暢性の錯覚」の危険がつきまとう。AIの説明は、とても分かりやすく、流暢に読める。読んでいるうちに「分かった」と感じる。しかし、それは第2章でいう「分かる」の段階にすぎない。AIの説明を読んだ後、画面を閉じて、同じ内容を自分の言葉で説明できるかを確かめる必要がある。確かめなければ、AIの説明は、読み返しと同じ効果しか持たない。

### 型三：問題を作らせる

問題を作らせる使い方は、学習に最も役立つ使い方の一つである。第5章の原則一「思い出す」を、AIが強力に支援してくれるからだ。

「この文章の内容について、理解を確かめる問題を五問作ってください。答えは最後にまとめて示してください」「今日学んだ英単語二十語を使って、穴埋め問題を作ってください」「関係代名詞と分詞と接続詞の問題を、混ぜて十問作ってください」。このように頼めば、AIは自分の学習内容に合わせた問題を、いくらでも作ってくれる。混ぜての練習（原則三）の材料も、簡単に手に入る。

注意点は、AIが作った問題や答えが、必ずしも正確ではないことだ。問題の設定に誤りがあったり、答えが間違っていたりすることがある。教科書の内容と照らし合わせて確認する習慣が必要である。また、答えを問題のすぐ下に表示させると、つい見てしまう。答えは最後にまとめるか、別に尋ねるようにするとよい。

### 型四：添削させる

添削させる使い方も、条件付きで学習に役立つ。自分で書いた英作文や小論文、数学の答案をAIに見せて、誤りや改善点を指摘してもらう。

この型の効果を左右するのは、**添削を受けた後に何をするか**である。AIが修正した文章を、そのまま自分の成果物として使えば、ファンらの研究が示した「メタ認知的な怠惰」の状態になる。成果物は良くなるが、自分の書く力は伸びない。

効果的な使い方は、修正後の文章ではなく、**誤りの指摘だけ**を求めることだ。「この英文の文法の誤りを指摘してください。ただし、正しい英文は示さず、どこがどう間違っているかだけを教えてください」。そして、指摘を受けて、自分で書き直す。書き直した文章を、もう一度AIに見てもらう。このやりとりを繰り返すことで、自分で誤りを直す経験が積み重なる。

### 型五：問い返させる

問い返させる使い方は、本書が最も強く勧める使い方である。

多くの人は、AIを「答えてくれる相手」として使う。しかし、AIは「問いかけてくれる相手」としても使える。「私は光合成の仕組みを理解したつもりです。私の理解が正しいかを確かめるために、質問を一つずつしてください。私が答えたら、その答えを評価して、次の質問をしてください」。こう頼むと、AIは試験官や家庭教師のように、自分の理解を試す質問を投げかけてくれる。

この使い方の利点は、思い出す練習（原則一）と説明する練習（原則四）を、同時に行えることだ。AIの質問に答えるには、自分の頭から知識を取り出し、自分の言葉で説明しなければならない。そして、答えがあいまいなとき、AIは「その理由は何ですか」「具体例を挙げられますか」と、さらに問いを重ねてくれる。第4章のメタ認知でいえば、自分では気づけなかった理解の穴を、AIが外から照らしてくれるのである。

同じ考え方で、AIを議論の相手として使うこともできる。「私は、〇〇という意見を持っています。あえて反対の立場から、私の意見の弱点を指摘してください」。自分の考えに対する反論を受けて、それに答えようとすることで、考えは深まる。

### 型六：書かせる

書かせる使い方は、学習の場面では、原則として使うべきではない。レポート、作文、答案をAIに書かせることは、書くことを通じて身につけるべき力を、そのまま手放すことになるからだ。

ここで、「書くこと」の意味について、少し考えておきたい。書くことは、考えたことを文字にする作業だと思われがちだ。しかし実際には、書くことは考えることそのものである。何を書くかを決め、どの順番で書くかを考え、言葉を選び、書いたものを読み返して論理の飛躍に気づき、書き直す。この過程で、頭の中のぼんやりした考えは、はっきりした形を持つようになる。書く前には気づいていなかった自分の考えの矛盾や、足りない部分にも、書くことで初めて気づく。

マサチューセッツ工科大学（MIT）メディアラボのナタリヤ・コスミナらは、二〇二五年、小論文を書く課題に、ChatGPTを使って書くグループ、検索エンジンを使って書くグループ、何も使わずに書くグループの三つに分かれて取り組んでもらい、書いている最中の脳の活動を脳波で測定する研究を発表した。その結果、何も使わずに書いたグループの脳の神経的なつながりが最も強く広範で、ChatGPTを使ったグループは最も弱かったと報告されている。さらに、ChatGPTを使ったグループは、自分が書いた小論文の内容を思い出して引用することが苦手で、自分の文章だという感覚も弱かったという。

ただし、この研究を読むときには注意が必要だ。発表の時点では査読（専門家による審査）を経ていない論文であり、参加者は五十四人と少なく、最後の段階まで参加したのはさらに少人数だった。脳波の測定結果の解釈についても、研究者の間で議論がある。この研究だけで「AIを使うと脳が衰える」と結論するのは、明らかに行き過ぎである。

それでも、この研究の結果は、本書の議論の方向と矛盾しない。自分で書かなかった文章の内容は、自分の頭に残りにくい。第3章でウィリンガムの言葉として紹介したように、記憶は思考の残りかすである。書く過程で考えなかったことは、残らない。

## 4　教科別・AIの使い方

六つの型と引き算テストをもとに、教科ごとの具体的な使い方を示そう。ここに挙げるのは例であり、自分の目標に合わせて調整してほしい。

### 英語

英語では、型三（問題を作らせる）と型五（問い返させる）が特に有効だ。学んだ英単語や文法事項を使った問題を作らせ、思い出す練習に使う。英語で短い会話の相手をしてもらい、自分で英文を組み立てる練習をする。英作文では、型四（添削させる）を、誤りの指摘だけを求める形で使う。長文読解では、まず自分で読み、要旨を自分でまとめた後で、AIの要約と比較する。自分が見落としていた点が、第4章の「見抜く」の改善点になる。

避けるべきは、英文和訳や和文英訳をAIに丸ごと任せること、長文を自分で読む前にAIの要約を読むことである。

### 数学

数学では、第2章で見たように、問題を解く工程の前半（見抜く・選ぶ）が学習の中心になる。AIに解答を求める前に、少なくとも方針を自分で立てる時間をとる。それでも分からない場合は、「最初に注目すべき点だけ」をヒントとして求める。解答を見た後は、自己説明（第5章の原則四）の形で、「問題文のどこから、この方針に気づけばよかったか」をAIに説明してみせ、評価してもらうのもよい。

また、型三を使って、ある解法が使える問題と使えない問題を混ぜて作らせるのも有効だ。「判別式を使う問題と、使わない問題を混ぜて五問作ってください」。見抜く練習の材料になる。

### 国語

国語、特に現代文の読解では、まず自分で読み、自分で答えを書くことが大前提である。そのうえで、型五を使って、「私はこの文章の筆者の主張を〇〇だと読みました。根拠は△△です。この読みに対する反論や、見落としている点を指摘してください」と頼む。自分の読みを、外から検証してもらう使い方だ。

記述問題の添削にAIを使う場合は、採点基準がAIによって揺れることに注意が必要である。AIの添削は参考意見の一つとして受け取り、最終的には模範解答や先生の添削と照らし合わせるのが安全だ。

### 社会

社会、特に歴史では、型五が力を発揮する。「江戸時代の対外関係について、私に質問してください。一問ずつ答えますので、答えが不十分なら追加の質問をしてください」。因果関係を説明させる質問を重ねてもらうことで、第2章で述べた「点」の知識を「つながり」に変えていく練習になる。

注意すべきは、AIの歴史についての説明には、年号や人名の誤りが混ざることがある点だ。教科書や資料集で確認する習慣を持つこと。

### 理科

理科では、型二（説明させる）が役立つ場面が多い。教科書の説明で分からない現象について、別の角度からの説明や、身近な具体例を求める。ただし、説明を読んだら、必ず画面を閉じて自分で説明し直す。計算問題では、数学と同じく、方針を自分で立てる時間をとってからAIに頼る。

### 資格試験

社会人の資格試験では、時間が限られている分、AIによる効率化の誘惑が強い。しかし、資格試験の本番では、AIは使えない。型三で大量の練習問題を作らせる、型五で理解を確かめる質問をしてもらう、といった、思い出す練習を支援する使い方が中心になる。過去問の解説が分かりにくいときに型二を使うのもよいが、その後で自分で解き直すことを忘れないこと。

### 大学のレポートと研究

大学の学習では、AIの使い方についての大学ごとのルールを、まず確認する必要がある。そのうえで、引き算テストを使う。文献の探索の手がかりを得る、自分が書いた文章の論理の飛躍を指摘してもらう、反論を想定してもらう、といった使い方は、多くの場合、学習の周辺を支援するものだ。論点の決定、論証の構成、本文の執筆は、自分で担うべき学習の本体である。

## 5　AIに任せてはいけない学習

ここまでの議論を、「AIに任せてはいけない学習」としてまとめておこう。

一つ目は、**初めて学ぶことを思い出す練習**である。学んだばかりの内容を、AIに答えさせてしまえば、第一の距離は永遠に埋まらない。思い出す練習の「思い出す」部分は、自分の頭でしかできない。

二つ目は、**方針を決めること**である。問題の構造を見抜き、方針を選ぶ工程は、第二の距離を埋める練習の中心だ。ここをAIに任せると、初見の問題に対応する力が育たない。

三つ目は、**自分の意見や論点を決めること**である。レポートでも、小論文でも、議論でも、何を主張するかを決めることは、考えることの核心である。

四つ目は、**最終的な確認と判断**である。AIの出力が正しいか、自分の目的に合っているかを確かめる工程は、どれほどAIが進歩しても、使う人間の責任として残る。そして、第4章で見たデラクアらの研究が示すように、この確認を怠ったとき、AIはかえって判断を誤らせる。

米マイクロソフト研究所のハオピン・リーらが、知識労働者三百十九人を対象に二〇二五年に発表した調査では、生成AIへの信頼が高い人ほど、AIを使う際に批判的に考えることが少ないと自己報告し、一方で、自分自身の能力に自信がある人ほど、批判的に考える傾向があった。この研究は、アンケートによる自己報告に基づくもので、因果関係までは示していない。しかし、AIを信頼しすぎると、確かめる工程が省かれやすいという傾向は、本書の議論と一致している。

## 6　AIの誤りとどう付き合うか

### もっともらしい誤り

生成AIは、もっともらしい誤りを出力することがある。存在しない書籍や論文を挙げる。計算の途中で誤る。歴史の年号を取り違える。しかも、その誤りは、正しい情報と同じ自信に満ちた文体で示される。

AIの誤りの頻度は、AIの性能の向上とともに下がってきている。しかし、ゼロにはならないし、どこで誤りが出るかを予測するのも難しい。デラクアらの言う「でこぼこの境界線」である。

### 検証の技術

AIの出力を検証するための方法を、いくつか挙げておこう。

一つ目は、**自分で解いて照合する**ことだ。数学の問題なら、AIの答えと自分の答えを比べる。一致しなければ、どちらかが間違っている。どちらが正しいかを考える過程が、それ自体で学習になる。

二つ目は、**一次資料で確認する**ことだ。事実についての情報は、教科書、公的な資料、原典で確認する。AIが挙げた文献は、図書館のデータベースや検索で、実在するかを確かめる。

三つ目は、**AIに根拠を問う**ことだ。「その答えの根拠は何ですか」「その情報はどの資料に基づいていますか」と尋ねる。ただし、AIは根拠そのものを作り出してしまうこともあるので、示された根拠も確認が必要である。

四つ目は、**具体的な数値で試す**ことだ。数学の公式や、理科の法則についての説明なら、具体的な数値を代入して、説明どおりの結果になるかを確かめる。第4章で述べた「確かめる」の技術である。

こうした検証は、面倒に感じるかもしれない。しかし、検証の過程そのものが、第4章で述べた確かめる力を鍛える練習になる。AIの誤りは、見方を変えれば、確かめる力を鍛えるための教材でもあるのだ。

## 7　AIと学ぶための約束ごと

本章の内容を、七つの約束ごとにまとめておきたい。これは、学習者自身が守る約束であると同時に、保護者や教師が、子どもや生徒と話し合う際のたたき台にもなる。

**一、使う前に、身につけたい力を一言で言う。**何のために学んでいるかが分からなければ、引き算テストは使えない。

**二、先に自分で考える。**分からない問題でも、少なくとも方針を立てようとする時間をとってから、AIに頼る。学ぶ前に問題に挑戦すると、たとえ解けなくても、その後の学習が深まることが研究で示されている（コーネルら、二〇〇九年）。

**三、答えではなく、ヒントを求める。**AIに頼るときは、答えを丸ごと求めるのではなく、次の一歩のヒントだけを求める。

**四、AIに問題を出させ、問い返させる。**AIを答えを出す機械ではなく、問いを出す相手として使う。

**五、AIの説明を読んだら、閉じて自分で説明し直す。**読んで分かっただけでは、学習は終わっていない。

**六、AIの出力を、必ず確かめる。**特に、事実、数値、文献は、一次資料で確認する。

**七、提出物は、自分の頭で書く。**書くことは考えることである。成果物を手に入れるために、頭の変化を手放さない。

---

本章では、AIの使い方を、学習者の立場から論じてきた。しかし、AIがもたらす変化は、学習者だけにとどまらない。答えがタダになった時代に、教師は何を教えればよいのか。宿題やレポートは、評価の方法として機能し続けるのか。受験勉強には、これからも意味があるのか。そして、AIは、家庭の経済状況による教育の格差を縮めるのか、それとも広げるのか。次章では、視点を広げて、教える人と、学校と、社会の側の変化を考えたい。

# 第7章　教える人・学校・試験はどう変わるか

## 1　「説明する人」から「考えさせる人」へ

### 説明の希少性が下がった

教師や塾講師の仕事の中心は、長い間、「説明すること」だった。教科書の内容を分かりやすく説明し、問題の解き方を説明し、質問に答えて説明する。分かりやすい説明ができる教師は、「良い先生」として評価されてきた。予備校の人気講師は、その説明の技術で多くの受験生を集めてきた。

生成AIは、この「説明」の希少性を大きく下げた。どんな内容でも、いつでも、学習者の理解の段階に合わせて、何度でも説明してくれる相手が、ほとんど無料で手に入るようになった。説明の分かりやすさだけで勝負するなら、教師がAIと競い合うのは、ますます難しくなっていくだろう。

では、教師は不要になるのだろうか。私はそうは考えない。むしろ、ここまでの章の議論から、教師の役割はこれまで以上に重要になると考える。ただし、その役割の中心は、「説明する人」から「考えさせる人」へと移っていく。

### 個別指導の価値と、AIの接近

この変化を考えるうえで参考になるのが、個別指導の効果についての研究である。

一九八四年、米国の教育心理学者ベンジャミン・ブルームは、一対一の個別指導を受けた生徒の成績が、通常の集団授業を受けた生徒に比べて、標準偏差で二つ分ほど高くなったという研究結果をもとに、「二シグマ問題」を提起した。個別指導はこれほど効果的だが、すべての生徒に個別指導を提供するのは費用の面で不可能だ。では、集団授業でどうやって個別指導に近い効果を上げられるか、という問題である。

ただし、この「二シグマ」という数字は、その後の研究で慎重に扱われるようになった。二〇一一年、カート・ヴァンレーンが個別指導の効果についての多くの研究を検討したところ、人間による個別指導の効果は標準偏差で〇・八程度で、ブルームが示した数字よりかなり小さかった。そして興味深いことに、よく設計されたコンピューターによる指導システムの効果も、それに近い水準に達していた。

生成AIは、この個別指導を、はるかに広い範囲に届ける可能性を持っている。ハーバード大学やナイジェリアの研究は、その可能性の一端を示した。しかし、第6章で見たように、その効果は「どう使うか」に大きく左右される。そして、「どう使うか」を設計し、学習者を導くことこそ、これからの教師の中心的な役割になる。

### 教師に残る四つの仕事

説明の希少性が下がった後、教師に残る、あるいはむしろ重要性が増す仕事は何か。本書の枠組みから、四つを挙げたい。

一つ目は、**診断**である。第2章で見たように、学習者がつまずいている原因は、第一の距離（思い出せない）なのか、第二の距離（使えない）なのかによって、処方が変わる。第5章の誤答の四分類でいえば、知識の欠落なのか、想起の失敗なのか、方針の誤りなのか、実行のミスなのか。学習者自身は、この診断が苦手だ。第4章で見たように、メタ認知には限界があるからである。生徒の答案を見て、どこでつまずいているかを見抜く。これは、教師の専門性が最も発揮される仕事の一つである。

二つ目は、**問いと課題の設計**である。第1章の「望ましい困難」は、困難の程度が適切でなければ機能しない。学習者の現在の力に対して、少し努力すれば乗り越えられる課題を用意する。考えることを促す問いを投げかける。AIに頼れば答えが出てしまう時代だからこそ、AIに頼っても意味のない問い、たとえば「あなたはこの解法をなぜ選んだのか」「この資料から、あなたはどう考えるか」を設計する仕事の価値は上がる。

三つ目は、**フィードバック**である。学習者の答案や考え方に対して、何が良くて何が足りないかを伝える。AIも添削はできるが、学習者がこれまでどのように学んできたか、何に苦手意識を持っているか、どんな言葉なら受け止められるかを知ったうえでのフィードバックは、人間の教師にしかできないことが多い。

四つ目は、**動機づけと学習の環境づくり**である。第1章で見たように、効果的な学習にはもどかしさが伴う。そのもどかしさの中で学び続けるには、励まし、見守り、小さな成長を認めてくれる存在が大きな意味を持つ。また、クラスや塾という場で、互いに教え合い、議論し合う環境を作ることも、AIにはできない仕事である。

### 教師自身がAIを使う

教える側がAIを使うことについても触れておきたい。教材の作成、小テストの問題づくり、授業準備のための下調べ、事務的な文書の下書きなど、教師の仕事にはAIに任せられる周辺の作業が少なくない。引き算テストを教師自身に当てはめれば、教師が身につけ、発揮すべき力が「診断」や「問いの設計」であるなら、それ以外の作業をAIで減らすことは理にかなっている。浮いた時間を、生徒一人ひとりの答案を読み、つまずきを見抜くことに回せるなら、AIは教師の仕事の質を上げる道具になる。

ただし、ここでも「確かめる」責任は教師に残る。AIが作った問題に誤りがないか、AIによる採点や添削の判断が妥当かを確かめずに生徒に渡せば、誤った知識を広めることになりかねない。また、生徒の個人情報や答案をAIに入力する際には、学校や自治体のルールに従う必要がある。文部科学省のガイドラインも、個人情報の保護や著作権への配慮を、利活用の際の重要な確認事項として挙げている。

### 塾講師という仕事の再定義

私自身が携わっている塾講師という仕事についても、少し考えておきたい。

これまで、塾の価値の一部は、学校よりも分かりやすい説明や、入試に特化した解法の知識にあった。しかし、説明と解法の知識の多くは、AIでも手に入るようになった。では、塾講師は何を提供すべきか。

私は、その答えは「学習の設計と診断」にあると考えている。生徒一人ひとりの現在の学力を三つの距離で診断し、誤答の原因を分類し、それに応じた学習の設計図を描く。そして、その設計図に沿って学習が進んでいるかを確かめ、必要に応じて修正する。さらに、生徒がAIを学習に使う場合には、引き算テストの考え方を伝え、AIを「考えさせる」道具として使えるように導く。説明の技術は今後も大切だが、それ以上に、学習者自身が気づけない問題を見つけ、学習の道筋を整える仕事の比重が高まっていくはずだ。

## 2　評価と試験はどう変わるべきか

### 成果物による評価の揺らぎ

AIの登場で最も大きく揺らいでいるのは、成果物による評価である。

宿題、レポート、読書感想文、自由研究。これらはこれまで、学習者が自分で取り組んだ成果物として、その学力や努力を評価する材料になってきた。しかし、AIがこれらの成果物を数十秒で作れるようになった今、提出された成果物が、学習者の頭の変化を反映しているとは限らなくなった。

AIが書いた文章を見分ける検出ツールも開発されているが、その精度には限界があり、人間が書いた文章をAIによるものと誤って判定する危険もある。検出技術と生成技術のいたちごっこに頼る評価は、長くは続かないだろう。

### 評価は「その場で見える思考」へ

では、評価はどう変わるべきか。本書の枠組みから言えば、評価の対象を、成果物から、**その場で見える思考**へ移していくことが一つの方向になる。

具体的には、次のような方法が考えられる。教室の中で、道具を使わずに問題を解いたり、文章を書いたりする。提出されたレポートについて、口頭で説明や質問への応答を求める。完成した成果物だけでなく、下書きや、考えの変化の過程も評価の対象にする。AIの使用を認めたうえで、「AIに何を尋ね、その答えをどう検証し、最終的に自分でどう判断したか」を報告させる。

これらの方法には、共通する考え方がある。第1章で述べた「教材を閉じ、道具から離れた状態で、何ができるか」という学力の基準に、評価を近づけるということだ。そして、AIを使う場合には、AIを使う過程での判断そのものを評価するということである。

### 受験勉強には、これからも意味があるか

大学入試をはじめとする筆記試験は、まさに「道具から離れた状態で何ができるか」を測る仕組みである。その意味で、筆記試験は、AI時代にも学力を測る方法として一定の役割を持ち続けるだろう。

二〇二五年度の大学入学共通テストでは、新たに「情報I」が出題教科に加わり、約二十八万人が受験した。プログラミングやデータの扱いなど、情報社会を生きるための基礎的な力を、入試の場で問う試みである。入試の側も、時代に合わせて変化している。

では、受験勉強そのものには、どのような意味があるのか。ここで、受験勉強への批判にも正面から向き合っておきたい。受験勉強は、細かな知識の暗記に偏りがちで、入試が終われば忘れてしまう内容も多い。入試問題の形式に特化した解法の訓練は、入試以外の場面では役に立たないこともある。こうした批判は、的外れではない。第3章の基準でいえば、使用頻度も低く、判断の土台にもならない知識を、試験のためだけに覚えている部分は確かに存在する。

それでも、受験勉強には別の価値が残る。本書の言葉でいえば、受験勉強は、**何も見ずに、初めての問題に対して、知識を選び、組み立て、確かめる**練習を、大量に、集中的に行う機会である。第3章で見たように、この練習によって、各教科の基本的な知識がハブ知識として引き出しに入り、第4章で見た五つの動詞が鍛えられる。これは、AI時代に最も必要とされる力の土台そのものだ。

受験勉強の価値は、それをどう行うかによって大きく変わる。解法を丸暗記し、問題の形式に慣れるだけの受験勉強は、AI時代にはますます価値を失っていくだろう。一方、本書で述べてきたような、思い出す・間隔をあける・混ぜる・説明する・間違いを資源にする、という原則に沿った受験勉強は、入試の後にも残る力を育てる。

## 3　家庭と教育格差——AIは格差を縮めるか、広げるか

### 縮める可能性

AIが教育の格差に与える影響については、楽観的な見方と悲観的な見方の両方がある。どちらにも根拠があるので、両方を見ておきたい。

まず、格差を縮める可能性について。これまで、質の高い個別指導や、いつでも質問できる環境は、経済的に余裕のある家庭の子どもに偏っていた。塾や家庭教師には費用がかかる。親が勉強を教えられる家庭と、そうでない家庭の差もあった。生成AIは、こうした環境の一部を、インターネットにつながる端末さえあれば、誰にでも提供できる。ナイジェリアの研究は、比較的費用のかからない方法で、公立学校の生徒の学力を大きく伸ばせる可能性を示した。

仕事の場面での研究も、AIが能力の差を縮める可能性を示している。スタンフォード大学のエリック・ブリニョルフソンらは、顧客サポートの担当者五千人あまりの仕事を調べ、生成AIによる支援の導入で、一時間あたりに解決できる問題の数が平均一四％増え、特に経験の浅い、あるいは成績の低い担当者では三四％増えたと報告した。経験豊富な担当者では、ほとんど効果は見られなかった。二〇二三年にシャケド・ノイとホイットニー・チャンが『サイエンス』誌に発表した実験でも、文章を書く仕事でChatGPTを使うと、作業時間が短くなり、品質が上がり、特にもともと成績の低かった人の改善が大きかった。

### 広げる可能性

一方、格差を広げる可能性もある。

教育学には「マタイ効果」という言葉がある。新約聖書のマタイによる福音書の「持っている人はさらに与えられ、持っていない人は持っているものまで取り上げられる」という一節にちなんで、心理学者キース・スタノヴィッチが、読む力の発達について用いた言葉だ。早い段階で読む力を身につけた子どもは、たくさん本を読み、語彙や知識を増やし、さらに読む力を高めていく。読む力が弱い子どもは、読むことを避け、その差はますます広がっていく。

AIについても、同じことが起こりうる。第3章と第4章で見たように、AIを学習に役立てるには、良い問いを立て、AIの出力を検証する力が必要だ。そしてその力は、知識から生まれる。すでに知識を持ち、学び方を身につけている学習者は、AIを「考えさせる」道具として使いこなし、さらに学力を伸ばしていく。知識が乏しく、学び方が身についていない学習者は、AIを「考えなくて済む」道具として使ってしまい、第1章の錯覚の中で学力を伸ばせない。前述のナイジェリアの研究でも、プログラムはあらゆる学力層の生徒に効果があったものの、効果が最も大きかったのは、もともと成績の高かった生徒だった。

さきほどの仕事の研究との違いにも注意が必要だ。顧客サポートや文章作成の研究では、AIが成果物の質を底上げし、その結果として能力の差が縮まった。しかし、学習の場面で問題になるのは、成果物の質ではなく、頭の変化である。AIが成果物を底上げすることで、見かけの差は縮まっても、頭の変化の差は、むしろ広がっているかもしれない。

### 格差を広げないために

AIが格差を縮めるか広げるかは、技術そのものではなく、それをどう使うかによって決まる。格差を広げないためには、二つのことが重要になる。

一つは、**学び方を教えること**である。本書で述べてきたような学習の原理と、AIの使い方の原則を、家庭の環境にかかわらず、すべての学習者が学べるようにする。これは、学校教育が担うべき重要な役割である。

もう一つは、**知識の土台を保障すること**である。AIを使いこなすための知識、つまり各教科のハブ知識を、すべての子どもが身につけられるようにする。「AIがあるから知識は要らない」という考え方は、実は、知識を持つ者と持たない者の格差を広げる方向に働きかねない。

### 家庭でできること——禁止か放任か、ではなく

保護者にとって、子どものAI利用は悩ましい問題だろう。禁止すれば、子どもは隠れて使うか、使い方を学ぶ機会を失う。放任すれば、第1章の錯覚の中で、宿題を「終わらせる」ためだけに使うかもしれない。

本書が勧めるのは、禁止でも放任でもなく、**約束**である。第6章の最後に示した七つの約束ごとを、たたき台として子どもと話し合い、家庭の約束を作る。その際、「なぜその約束が必要なのか」を、本書の言葉を使って説明するとよい。「AIに答えを聞いて宿題を終わらせても、宿題という成果物は手に入るけど、あなたの頭の変化は手に入らない」。理由が分かれば、子どもは約束を自分のものとして受け入れやすくなる。

また、保護者にできる最も効果的なことの一つは、子どもに説明を求めることだ。「今日学校で何を習ったの？」「その問題、どうやって解いたの？」と尋ね、子どもの説明を聞く。これは、第5章の原則四「説明する」を、家庭の中で自然に行う方法である。保護者自身がその内容を理解している必要はない。関心を持って聞き、「それはどうして？」と尋ねるだけで、子どもは自分の理解を言葉にし、確かめる機会を得る。

## 4　AI時代に、学校が教えるべきもの

### 国の方針

文部科学省は、二〇二三年七月に初等中等教育段階における生成AIの利用に関する暫定的なガイドラインを示し、二〇二四年十二月にはその改訂版として「初等中等教育段階における生成AIの利活用に関するガイドライン（Ver.2.0）」を公表した。改訂版では、生成AIに対する基本的な考え方や、学校現場で押さえておくべきポイント、利活用する際のチェック項目などが整理されている。学校現場は、生成AIを使うか使わないかを議論する段階から、どう使うかを考える段階へと移りつつある。さらに二〇二六年六月には、エージェント型AIなどの技術の進展や、学習の「近道」を防ぐ評価のあり方を踏まえて、このガイドラインを速やかに改訂する方針が文部科学省から示されている。

ガイドラインは方向性を示すものであり、具体的に何をどう教えるかは、各学校や教師の判断に委ねられている部分が大きい。ここでは、本書の枠組みから、AI時代に学校が教えるべきものを四つ挙げておきたい。

### 一、知識の骨格

第3章で述べたように、考えることは頭の中の知識を材料にして起きる。AIを使いこなし、その誤りに気づくためにも、各教科のハブ知識は欠かせない。学校は、すべての子どもに、この知識の骨格を保障する役割を担う。これは、AI以前から学校が担ってきた役割だが、AI時代には、その重要性がむしろ増している。

ただし、知識の骨格を教えることは、細かな知識の詰め込みを意味しない。第3章の四つの区分でいえば、使用頻度が高く判断の土台になる知識を確実に身につけさせ、それ以外の知識は、つながりの中で理解させたり、調べ方を教えたりする、というメリハリが必要になる。

### 二、検証の習慣

第4章で述べたように、AI時代に最も重要性が増す思考の動詞は、「確かめる」である。AIの出力、インターネットの情報、他人の主張を、鵜呑みにせずに確かめる習慣。一次資料に当たる方法。自分で計算して確かめる方法。複数の情報源を比べる方法。これらを、教科の学習の中で、繰り返し経験させる必要がある。

### 三、問いを立てる経験

第4章で述べたように、AIは問われたことに答える道具であり、問いを立てるのは人間の仕事である。学校の学習では、問いは教師や教科書が用意することが多い。しかし、探究的な学習の時間などを通じて、自分で問いを見つけ、その問いを具体的で検証可能なものに磨き上げる経験を積ませることが、ますます重要になる。

### 四、他者との協働

最後に、他者と学ぶことの意味について述べておきたい。

AIは、一人で学ぶための強力な道具である。いつでも質問に答え、説明し、問いかけてくれる。では、AIがあれば、他者と学ぶ必要はなくなるのだろうか。

私はそうは考えない。他者と学ぶことには、AIとの対話では得にくい価値がある。それは、**自分とは異なる考え方に出会い、自分の理解が揺さぶられる経験**である。同じ問題について、友人が自分とはまったく違う方針で解いているのを見たとき。自分が当然だと思っていた解釈に、クラスメートが疑問を投げかけたとき。自分の説明が、相手にまったく伝わらなかったとき。こうした経験は、自分の理解の限界に気づかせ、理解を更新するきっかけになる。

AIも反論をしてくれるし、別の視点を示してくれる。しかし、AIは基本的に、利用者の求めに応じて振る舞う。利用者が反論を求めなければ反論はしないし、利用者の考えに合わせた答えを返す傾向もある。これに対して、他者は、こちらの求めとは関係なく、自分の考えをぶつけてくる。その予測できなさこそが、自分の理解を揺さぶる力になる。

そして、社会に出れば、ほとんどの仕事は他者との協働の中で行われる。異なる知識と考え方を持つ人々と議論し、合意を形成し、共に問題を解決する力は、AIがどれほど進歩しても、人間にとって中心的な力であり続けるだろう。学校は、同年代の多様な他者と共に学べる、数少ない場である。その場の価値は、AI時代にむしろ高まっていると私は考える。

## 5　教える人への提案

最後に、教師、塾講師、そして家庭で子どもの学習を支える保護者に向けて、本書の議論をまとめた提案をしておきたい。

一つ目は、**学習者に、学習の原理を教えること**。第1章の三つの錯覚、第2章の三つの距離、第5章の五つの原則を、教える側だけが知っているのではなく、学習者自身が知っている状態を目指す。原理を知っている学習者は、教師の手を離れても、自分で学習を設計できる。

二つ目は、**成果物ではなく、頭の変化を見ること**。提出物の出来ばえだけでなく、その場で何ができるか、どう考えたかを確かめる機会を増やす。

三つ目は、**AIの使い方を、禁止ではなく、設計すること**。引き算テストの考え方を共有し、学習の目標に照らして、AIをどの工程で使い、どの工程では使わないかを、学習者と一緒に決める。

四つ目は、**問いを投げかけること**。説明するだけでなく、「なぜそう考えたのか」「他の方法はないか」「それは本当に正しいか」と問いかけ、学習者自身に考えさせる。

---

本章では、教える人、学校、試験、そして社会の側の変化を考えてきた。説明の希少性が下がった時代に、教師の役割は、診断し、問いを設計し、フィードバックを与え、学びの場を作ることへと移っていく。評価は、成果物から、その場で見える思考へと移っていく。そしてAIが教育の格差を縮めるか広げるかは、学び方と知識の土台を、すべての学習者に保障できるかにかかっている。

最後に、本書全体を振り返り、AI時代に「学ぶ」とはどういうことなのかを、あらためて考えてみたい。

# おわりに　知識を持つ人から、知識で考える人へ

## よく満たされた頭より、よく作られた頭

十六世紀フランスの思想家ミシェル・ド・モンテーニュは、『エセー』の子どもの教育について論じた章で、教師を選ぶなら、頭がよく満たされた人よりも、頭がよく作られた人を選ぶべきだ、という趣旨のことを書いている。知識をたくさん詰め込んだ頭よりも、知識を使って判断できる頭のほうが大切だ、というのである。

四百年以上前のこの言葉は、AI時代の学習を考えるうえで、しばしば引用されるようになった。知識はAIに任せて、人間は判断することに集中すればよい、という文脈で。

しかし、本書をここまで読んできた読者には、この言葉の読み方が、少し変わっているのではないだろうか。「よく作られた頭」は、空っぽの頭ではない。第3章で見たように、考えることは、頭の中の知識を材料にして起きる。第4章で見たように、見抜く力も、選ぶ力も、確かめる力も、知識と経験の上に成り立つ。よく作られた頭とは、知識がたくさん詰まっている頭ではなく、**知識が、考えるために使える形で入っている頭**のことなのだ。

本書のタイトルでいえば、答えがタダになった時代に価値を失うのは、「知識を持っていること」そのものではない。知識を、使える形で持たずに、ただ持っていることである。そして、知識を使える形にするには、自分の頭で思い出し、使い、間違え、確かめるという経験が欠かせない。この経験だけは、AIに代わってもらうことができない。

## 本書のまとめ

本書の議論を、一本の線としてまとめておこう。

第1章では、学習中の手ごたえと学習後の実力は別物であり、読み返し、まとめての練習、きれいな成果物は、手ごたえを高めるが、実力を必ずしも高めないことを見た。学力とは、教材を閉じ、道具から離れた状態で、何ができるかである。

第2章では、学力を「分かる」「思い出せる」「使える」の三つの状態に分け、その間にある二つの距離を示した。解説を読んで分かることと、白紙から思い出せることと、初めての問題に使えることは、それぞれ別の状態であり、別の練習を必要とする。

第3章では、「検索できる知識を、なぜ覚えるのか」という問いに、作業台と引き出しと倉庫のたとえで答えた。考えることは小さな作業台の上で起き、作業台に素早く載せられるのは引き出しの中身だけである。そして、倉庫、つまりAIや検索を使いこなすためにも、引き出しの中身が必要になる。

第4章では、思考力を、見抜く・選ぶ・組み立てる・確かめる・問うの五つの動詞と、それを支えるメタ認知に分解した。AIが最も代替しやすいのは組み立てる働きであり、見抜く・選ぶ・確かめる・問うは、人間の側に強く残る。

第5章では、学習の設計図として、思い出す・間隔をあける・混ぜる・説明する・間違いを資源にする、の五つの原則を示した。

第6章では、AIの使い方を判断する基準として「引き算テスト」を提案した。その苦労をAIに任せて消したとき、身につけたい力も一緒に消えるなら、その苦労は自分で担う。AIを答えを出す機械としてではなく、問題を出し、問い返してくれる相手として使う。

第7章では、教師の役割が「説明する人」から「考えさせる人」へ移り、評価が成果物から「その場で見える思考」へ移っていくこと、そしてAIが格差を縮めるか広げるかは、学び方と知識の土台をすべての学習者に保障できるかにかかっていることを論じた。

## 理解を更新し続けるということ

本書の最初に、中心となる主張の方向を示した。AIによって知識の価値がなくなるのではない。知識を使って考え、問い、判断し、他者と協働し、自分の理解を更新する能力の価値が、かえって高まる、と。

この中の最後の一つ、「自分の理解を更新する」について、最後に少し述べておきたい。

学ぶということは、新しい知識を付け加えることだけではない。すでに持っている理解が間違っていたと気づき、それを修正すること。自分が当然だと思っていた考えが、ある条件のもとでしか成り立たないと知ること。以前は別々だと思っていた二つの知識が、実は同じ原理でつながっていると気づくこと。こうした、自分の理解そのものを組み替える経験こそが、学ぶことの核心にある。

第5章で見た誤答の分析は、この更新の具体的な練習である。自信を持って答えた問題が間違っていたとき、その驚きが、理解を組み替えるきっかけになる。第7章で見た他者との協働も、自分とは異なる考えに出会うことで、理解の更新を促す。

AIは、この更新のための、これまでにない強力な相手になりうる。自分の理解を確かめる質問をしてもらう。自分の考えへの反論を求める。自分の答えの誤りを指摘してもらう。こうした使い方をすれば、AIは、自分の理解の穴を照らし、更新を促す鏡になる。

一方で、AIは、更新を不要にする道具にもなりうる。自分で考えなくても、整った答えが手に入る。自分の理解が間違っていても、AIの答えを写せば、成果物は正しくなる。そうして、自分の理解は更新されないまま、古いまま、穴の空いたまま、残り続ける。

どちらになるかを決めるのは、AIではなく、使う人間である。そして、その判断のための原理を示すことが、本書の目的だった。

## 明日からの最初の一歩

最後に、本書を読み終えたあなたが、明日からできる最初の一歩を、一つだけ提案したい。

**今日学んだことを、何も見ずに、白紙に書き出してみる。**

本を閉じ、ノートを閉じ、画面を閉じて、今日学んだことを、覚えている限り書き出す。書けたことが、今日あなたの頭に残ったことだ。書けなかったことを確認し、もう一度閉じて書く。

これは、本書で述べてきたすべての原理の出発点である。学習中の手ごたえではなく、学習後の証拠で判断する（第1章）。「分かる」から「思い出せる」への距離を埋める（第2章）。引き出しの中身を確かめ、増やす（第3章）。自分の理解を外から見る（第4章）。思い出す練習をする（第5章）。そして、AIには代わってもらえない、自分の頭が働く時間を持つ（第6章）。

答えがタダになった時代に、それでも自分の頭で学ぶことの意味は、この小さな一歩の中にある。白紙を前にして、何も出てこないもどかしさを感じたとき、あなたの頭は、確かに働いている。そのもどかしさこそが、学びが起きている証拠なのだ。

本書が、あなたの学びを、そしてあなたが関わる誰かの学びを、少しでも前に進める助けになれば幸いである。

# 付録　すぐに使える実践ツール

本文で述べた原理を、そのまま使える形にまとめた。AIへの頼み方の例文は、特定のサービスに依存しない書き方にしてある。使うAIの仕様や、学校・大学のルールに合わせて調整してほしい。

## 付録1　AIへの頼み方・実例集

### 使う前のチェック（第6章「引き算テスト」）

AIに頼む前に、次の二つを自分に問う。

- いま身につけたい力は何か。一言で言うと？
- この作業をAIに任せたら、その力も一緒に消えるか？

「消える」と答えたら、その作業は自分でやる。「消えない」と答えたら、AIに任せてよい。

### 型三　問題を作らせる（思い出す練習・混ぜる練習）

> これから貼る文章は、私が今日学んだ教科書の一節です。内容の理解を確かめる問題を五問作ってください。三問は用語を答える問題、二問は理由を説明する問題にしてください。答えは最後にまとめて示し、問題のすぐ下には書かないでください。

> 高校数学の「二次関数の最大・最小」「二次不等式」「判別式」の問題を混ぜて、難易度が基本〜標準の問題を六問作ってください。どの単元の問題かは書かないでください。答えは、私が「答えを見せて」と言うまで示さないでください。

> 次の英単語二十語を使って、日本語の意味から英単語を答える問題を作ってください。順番はランダムにしてください。

### 型五　問い返させる（理解の確認・メタ認知）

> 私は「光合成の仕組み」を理解したつもりです。私の理解を確かめるために、質問を一つずつしてください。私が答えたら、その答えの正しい点と足りない点を短く指摘してから、次の質問をしてください。私の答えがあいまいなときは、「なぜそう言えるのか」をさらに尋ねてください。全部で五問にしてください。

> 江戸時代の対外関係について、私に口頭試問をしてください。出来事の名前を答えさせる質問よりも、「なぜ」「その結果どうなったか」を説明させる質問を中心にしてください。

> 私は次の意見を持っています。〔意見〕。あえて反対の立場から、この意見の最も弱い点を三つ指摘してください。私が反論したら、それに再反論してください。

### 型四　添削させる（指摘だけを求める）

> 次の英文の文法と語法の誤りを指摘してください。ただし、正しい英文は示さないでください。どの部分が、どういう理由で誤っているかだけを教えてください。私が書き直したら、もう一度確認してください。

> 次の小論文を読んで、論理の飛躍がある箇所と、根拠が不足している箇所を指摘してください。書き直した文章は示さないでください。

### 数学のヒントの求め方（型一を安全に使う）

> 次の問題を十五分考えましたが、方針が立ちません。私が考えたことは〔自分の考え〕です。答えや解き方は言わずに、問題文のどこに注目すべきかのヒントだけを一つください。

> 次の問題の解説を読みました。私はこの解法の方針に、問題文の〔箇所〕から気づくべきだったと考えます。この考えが妥当かどうか、評価してください。

### 説明を読んだ後の確認（型二を安全に使う）

> 先ほどの説明を読んだので、画面を見ずに、自分の言葉で説明し直します。〔自分の説明〕。私の説明で、抜けている点や誤っている点を指摘してください。

### 検証のための問いかけ

> いまの答えの根拠となる資料や原典は何ですか。確認できる形で示してください。確かな根拠がない場合は、そう言ってください。

## 付録2　誤答ノートの書き方（第5章）

一つの誤答につき、書くのは三項目だけ。問題や解答を丸写ししない。

| 項目 | 書き方 | 例 |
|---|---|---|
| 出典 | 教材名・ページ・番号 | 問題集A p.42 問5 |
| 分類 | 次の四つから一つ選ぶ：①知識の欠落　②想起の失敗　③方針の誤り　④実行のミス | ③方針の誤り |
| 教訓 | 次に似た問題が出たら、どこに注目し、何をするか。具体的に | 文字を含む二次関数の最大・最小は、まず平方完成して軸を求め、軸と範囲の位置関係で場合分けする |

**使い方**：書いてから三日後と二週間後に、解答を見ずに解き直す。週末に、複数の単元の誤答を混ぜて解き直す。同じ分類の誤りが続いたら、その分類の処方（本文第5章）を重点的に行う。

| 分類 | 処方 |
|---|---|
| ①知識の欠落 | その知識を学ぶ。教科書の該当箇所に戻る |
| ②想起の失敗 | 白紙再現・カードで思い出す練習。間隔をあけて復習 |
| ③方針の誤り | 混ぜて解く練習。解説を読むとき「問題文のどこから方針に気づけたか」を言葉にする |
| ④実行のミス | 自分のミスのパターンを記録し、具体的な確認手順を決める（例：符号に丸をつける） |

## 付録3　学力の三つの距離・自己診断シート（第2章）

単元ごとに、次の三つを確かめる。

| 確認 | 方法 | できなければ |
|---|---|---|
| 分かる | 教科書・解説を読んで、筋道に納得できるか | 理解から始める。先生・AIの説明（型二）を使ってよい |
| 思い出せる | 教科書を閉じて、要点・公式・用語を白紙に書けるか | 第一の距離が残っている。思い出す練習・間隔をあけた復習 |
| 使える | 他の単元と混ぜた問題、初見の問題で、使う知識を自分で選べるか | 第二の距離が残っている。混ぜる練習・方針を自分で立てる練習 |

## 付録4　一週間の学習設計シート（第5章）

次の枠を埋めて、自分の一週間を設計する。

**今週身につけたい力（一言で）**：

**使える時間**：平日　　分／日、週末　　分／日

| 時間帯 | 新しい内容 | 思い出す練習 | 間隔をあけた復習 | 混ぜる練習 | 誤答の解き直し |
|---|---|---|---|---|---|
| 月 | | | | | |
| 火 | | | | | |
| 水 | | | | | |
| 木 | | | | | |
| 金 | | | | | |
| 土 | | | | | |
| 日 | | | | | |

**設計の目安**
- 新しい内容を学んだ日には、必ず閉じて書く時間（十〜十五分）をとる。
- 前日の内容と、数日〜一週間前の内容の復習を、毎日少しずつ入れる。
- 週に一度は、複数の単元を混ぜて解く時間をとる。
- 週末に、一週間分の誤答ノートを見直し、解答を見ずに解き直す。

## 付録5　家庭で話し合うための「AIと学ぶ七つの約束」（第6章）

1. 使う前に、身につけたい力を一言で言う。
2. 先に自分で考える。
3. 答えではなく、ヒントを求める。
4. AIに問題を出させ、問い返させる。
5. AIの説明を読んだら、閉じて自分で説明し直す。
6. AIの出力を、必ず確かめる。
7. 提出物は、自分の頭で書く。

この七つは、そのまま守るための規則ではなく、話し合いのたたき台である。子どもの年齢や、学校のルール、学習の目的に合わせて、家庭ごとの約束を作ってほしい。大切なのは、約束の中身よりも、「なぜその約束が必要なのか」を、子ども自身が説明できることである。
