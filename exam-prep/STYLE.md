# 執筆・品質基準（全教科共通）

このパックの全ファイルが従う約束です。執筆者も検証者もここを基準にします。

## 1. 前提とする入試制度

- **共通テストは2025年度以降の新課程（2022年度施行の学習指導要領）に準拠する。**
  - 数学：「数学Ⅰ，数学A」（70分・100点）、「数学Ⅱ，数学B，数学C」（70分・100点）。
    数学B・Cは「数列」「統計的な推測」「ベクトル」「平面上の曲線と複素数平面」から3項目選択。
  - 国語：90分・200点。現代文（近代以降の文章）110点／古文45点／漢文45点。
    現代文は大問3題（第3問は実用的な文章・資料を含む問題）。
  - 英語：リーディング80分・100点、リスニング30分（解答時間）・100点。
  - 地理歴史・公民：「地理総合，地理探究」「歴史総合，日本史探究」「歴史総合，世界史探究」
    「公共，倫理」「公共，政治・経済」（各60分・100点）。
    「歴史総合」「公共」部分の扱いにも必ず触れる。
  - 理科：物理・化学・生物・地学（各60分・100点）、基礎科目（2科目で60分・各50点）。
  - 情報Ⅰ：60分・100点。
- 配点・時間・大問構成は**確定情報だけ**を断定調で書く。年度で変わりうるもの
  （大問ごとの配点、設問数など）は「例年」「近年は」と明記し、断定しない。
  自信のない数値は書かない。
- **二次試験は旧帝大（東大・京大・阪大・名大・東北大・九大・北大）の出題水準を参考**にする。
  ただし特定大学の過去問を再掲・改変しない。「〜大の出題傾向を踏まえた」程度の言及に留める。
- 数学の二次範囲は理系（数学Ⅰ・A・Ⅱ・B・Ⅲ・C）を基本とし、文系範囲の問題には
  【文理共通】【文系向け】などのタグを付ける。

## 2. 著作権

- **過去問・市販教材・予備校教材の問題文や解説を転載しない。問題はすべてオリジナル。**
- 現代文・英語の本文は**すべて書き下ろし**。実在の評論・小説を引用しない。
- 古文・漢文は**著作権の切れた古典（徒然草・枕草子・源氏物語・今昔物語集・論語・史記・
  唐詩など）の本文を使ってよい**。ただし本文は正確に（うろ覚えで改変しない）。
  正確さに自信がなければ短く切るか、別の有名な一節を選ぶ。
  現代語訳・設問・解説はオリジナルで書く。
- 地図・図版は使えないので、必要なら文章・表・座標で表現する。

## 3. 正確性（最優先）

- **誤った正答・誤った解説は、問題が無いより悪い。** 迷ったら問題を削る。
- 数学・物理・化学・情報の計算問題は、**解答を別の方法で検算してから書く**
  （Python・sympyでの数値確認を推奨。`pip install sympy numpy` 済み）。
- 選択肢問題は、正答が**一つだけ**に定まることを確認する。
  誤答選択肢それぞれに「どこが誤りか」を解説に書く。
- 歴史の年代・人名・事件、地理の統計の傾向、生物・地学の用語は、教科書レベルで
  確立した内容だけを使う。**具体的な統計数値（生産量の順位・割合など）は、
  年によって入れ替わるものを断定しない。** 長期的に安定した傾向として書く。
- 化学：原子量は問題文で与える（H=1.0, C=12, N=14, O=16, Na=23, Cl=35.5 など）。
  有効数字の指示を明記する。
- 物理：重力加速度 g などの定数は文字で置くか、値を問題文で与える。

## 4. ファイル構成（各教科1ファイル）

置き場所：
- 共通テスト → `exam-prep/kyotsu/<slug>.md`
- 二次試験 → `exam-prep/niji/<slug>.md`

各ファイルは次の見出し構成を守る（教科の性質上不要な節は理由を書いて省略可）。

```
# 【共通テスト】数学Ⅰ，数学A 対策パック   ← 二次は【二次・記述】
> 対象：… ／ 試験時間：… ／ 配点：… ／ 目標：…

## 0. このパックの使い方
## 1. 試験の概要と出題傾向
   （構成・時間・配点、近年の傾向、他試験との違い）
## 2. 得点戦略
   （時間配分表、解く順番、目標点別の方針：6割／8割／9割）
## 3. 分野別の要点整理
   （頻出事項を表や箇条書きで。暗記事項と「使い方」をセットで）
## 4. 頻出テーマと解法の型
   （型ごとに「着眼点 → 手順 → よくある失点」）
## 5. 演習問題
   （本番形式のオリジナル問題。難易度 ★〜★★★ を付ける）
## 6. 解答・解説
   （正答、根拠、誤答の理由。二次では「模範解答」「採点基準（部分点）」
     「よくある減点答案」を必ず付ける）
## 7. 直前チェックリスト
   （□ で始まる確認項目 15〜30個）
## 8. 学習スケジュール例
   （高3の4月〜本番までの目安。どの時期に何をするか）
```

## 5. 分量と水準

- 共通テスト科目：演習問題は**本番の大問1〜2題分以上**（小問換算で12問以上が目安）。
  基礎科目は小問8問以上。
- 二次科目：記述・論述の演習問題**6題以上**（数学は8題以上）。
  各題に**模範解答・部分点つき採点基準・減点例**を付ける。
  論述（日本史・世界史・地理）は字数指定つき（例：120字、200字、300字）で、
  模範解答の字数が指定字数の9割〜10割に収まっていることを数えて確認する。
- 目安：1ファイル 日本語で2万〜4万字程度。水増しはしない。
- 難易度：共通テストは本番相当、二次は旧帝大の標準〜やや難レベル。

## 6. 表記

- Markdown（GitHub Flavored）。数式は `$...$`（インライン）と `$$...$$`（ディスプレイ）で
  LaTeXを使う（GitHubで表示できる）。
- 文体は「である」調を基本に、学習者への指示は簡潔に。
- 選択肢は ①②③④⑤⑥ の丸数字。解答番号・マーク式の再現が必要なら「[ア]」のように書く。
- 英語の本文・選択肢は英語、設問指示と解説は日本語。
- 太字は本当に重要な所だけに使う。
