# 『思考の主導権』増補解説版

- 完成PDF：`思考の主導権_増補解説版_黒田清友.pdf`（B5判・271ページ・約16万字）
- 原稿：`src/original.docx`（受け取った原稿）／`src/original.md`（本文を抽出したもの。本文は一字も変えていない）
- 増補解説：`supp/*.md`（章ごと。「=== IN 節番号」「=== AFTER 節番号」で本文への差し込み位置を指定）
- 組版：`build/build.py`（Markdown→HTML、目次ページ番号は2パス）、`build/book.css`（誌面デザイン）、`build/render.js`（Chromium で PDF 化）

再生成：`python3 build/build.py`（BIZ UD明朝／BIZ UDゴシック、Node の playwright が必要）

## 増補した内容
- 前付け：この本の使い方（囲みの読み方・読む順番）、全体地図（枠組みの一覧と関係図）
- 各章：この章で分かること、章の流れの図解、用語、なぜ？（理由を段階的に）、よくある間違い（✕／○／なぜ）、具体例、まとめ、確認問題と解答、次の章へのつながり
- 実践編・ケース・実践ツール・反論Q&A・研究ノート：使い方の手引き、振り返りチェックリスト、比較表、「言えること／言えないこと」表
- 巻末：追加参考文献（Crossref等で書誌確認済み）、数字と研究の早見表、著者紹介、用語集（本文の用語欄から自動生成・五十音順）
