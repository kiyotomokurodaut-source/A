## この本の使い方――読む前の三分間

この本は、黒田清友『思考の主導権――書き殴る、AIに整理させる、そして自分で決める。』の本文をそのまま土台にして、理解を助けるための解説を大幅に書き足した「増補解説版」です。

本文は、著者の主張を一本の流れとして読めるように書かれています。ただ、流れを優先した文章には、どうしても「言わなくても分かるだろう」という省略が入ります。たとえば「メタ分析」「ワーキングメモリ」「転移」といった専門用語や、「なぜその順番でなければならないのか」という理由の一部は、本文では短く触れるだけで先へ進みます。

増補解説版では、その省略をできるかぎりなくしました。専門用語はすべてその場で定義します。「なぜそう言えるのか」は、段階を一つずつ踏んで説明します。多くの人がつまずく場所は「よくある間違い」として、間違い・正しい考え方・その理由の三点セットで書きました。他の本を横に置かなくても、この一冊だけで最後までたどり着けることを目標にしています。

::: guide | 囲みの種類と読み方
本文の途中には、色の違う囲みが入っています。色ごとに役割が決まっているので、慣れてくると「いま自分が何を読んでいるのか」が一目で分かります。
:::

| 囲み | 何が書いてあるか | どう読むとよいか |
|---|---|---|
| この章で分かること（紺） | 章の扉に置いた、章のゴールと問い | 読む前に目を通し、「この問いに答えられるか」を意識して本文へ進む |
| 図解（枠と矢印） | 考え方の流れや手順を、段と矢印で示した図 | 矢印の順番そのものに意味がある。順番を入れ替えると何が起きるかを考える |
| 用語（緑灰） | 専門用語や本書独自の言葉の定義 | 定義を一度読んだら、本文で出てきたときに自分の言葉で言い換えてみる |
| なぜ？（青） | 主張の理由を、段階を踏んで説明したもの | 結論ではなく「理由の鎖」を追う。どの鎖が切れたら結論が崩れるかを見る |
| よくある間違い（赤） | ✕間違い／○正しくは／なぜ、の三点セット | 自分が✕側の考え方をしていないかを点検する |
| 具体例（黄） | 教科や場面を一つに絞った例 | 自分の科目・仕事に置き換えて読む |
| 要点（太枠） | 一文で覚えておくべきこと | ここだけ拾い読みしても本の骨格がつかめる |
| AIへの頼み方（例）（灰） | そのままAIに渡せる依頼文の例 | 丸写しより、なぜその制約が入っているかを読む |
| まとめ（緑） | 章の内容を短く整理したもの | 本を閉じて、まとめを自分で再現できるか試す |
| 確認問題（紫）と解答 | 章の理解を確かめる問題と、その解答・解説 | 解答を手で隠し、先に自分で書いてから答え合わせをする |

::: point
この本は「読んで分かった」で終わらせないように作ってあります。各章の確認問題を、本を見ずに解いてみてください。それ自体が、本書のいちばん大事な主張――「見て分かる」と「自分で出せる」は違う――の実践になります。
:::

### 読む順番のおすすめ

時間がない人と、じっくり読みたい人とで、読む順番を変えてかまいません。

- **全体を早くつかみたい人**：次のページの「全体地図」→各章の扉（この章で分かること）→各章末の「まとめ」→「実践編 30日」の順に読む。これで本の骨格が一通り手に入ります。
- **しっかり身につけたい人**：はじめから順に読み、各章末の確認問題を必ず解く。解けなかった問題は、その問題に対応する節へ戻って読み直す。
- **保護者・教師の人**：はじめに→第1章→第2章→第4章→第7章→実践ツール3→よくある反論、の順がおすすめです。子どもや生徒に説明するときの言葉が、「なぜ？」と「よくある間違い」の欄にまとまっています。
- **いますぐAIの使い方を変えたい人**：第4章（並走六手）→実践ツール1（テンプレート）→実践ツール2（外注境界）を先に読み、あとで第1〜3章に戻って理由を確かめる。

::: caution | 増補部分について
増補した解説は、本文の主張を分かりやすく言い換え、理由を補い、例を足したものです。本文にない新しい研究結果や数字を、根拠なしに付け加えることはしていません。研究に触れる箇所では、本文と巻末の参考文献に挙げた文献の範囲で説明しています。例として出てくる生徒や場面（「ある高校生が」など）は、説明のために作った典型例です。
:::

## 全体地図――この本の考え方を一枚で見る

この本には、いくつもの「枠組み」（考えを整理するための型）が出てきます。並走六手、理解の四段階、誤答の五分類、復習の四工程、外注境界……。数が多いので、ばらばらの道具に見えるかもしれません。

実は、これらはすべて一つの問いから出てきたものです。

::: point
**AIを使っても、自分の中に能力が残るようにするには、どの工程を自分でやり、どの工程をAIに任せればよいか。**
:::

この問いに、「時間の順番」「理解の深さ」「失敗の種類」「任せる基準」という四つの角度から答えたものが、各章の枠組みです。

::: flow | 本書の枠組みは、一つの問いから四方向に広がっている
中心の問い | AIを使っても自分に能力が残るには、どこを自分でやり、どこを任せるか
時間の順番で答える | 並走六手（第4章）：出す→整える→ぶつける→確かめる→選ぶ→戻す。一日の単位では「無支援→並走→再無支援」
理解の深さで答える | 理解の四段階（第2章）：追跡→再生→選択→変形。学習の状態は「接触→想起→運用」（第1章）
失敗の種類で答える | 誤答の五分類（第5章）：知識欠如・認識失敗・方針失敗・実行失敗・検証失敗。復習は「想起→照合→修正→再試行」
任せる基準で答える | 外注境界（実践ツール2）：四つの軸と、赤・黄・緑の三領域。検証の強さ＝起こりやすさ×影響×見抜きにくさ
最終的に守るもの | 知的自立の三条件（第8章）：目的・判断・責任
:::

### 本書の主張を、五つの文で言うと

1. 答えが手に入ることと、自分が考えられるようになることは、同じではない（はじめに・第1章）。
2. 人は「見れば分かる」状態を「自分で出せる」状態だと勘違いしやすく、AIはこの勘違いを強めやすい（第2章）。
3. だから、AIを見る前に、自分の考えを不完全なままノートに書き出す（一次思考・乱筆ノート、第3章）。
4. そのメモをAIに整理させ、反論させ、事実を確かめ、自分で選び、最後にAIを閉じて自分の言葉に戻す（並走六手、第4章）。復習も「見直す」ではなく「もう一度できるか試す」に変える（第5章）。
5. こうして、何を任せ、何を自分に残すかを自分で決められること――それが「思考の主導権」であり、AI時代の知的自立である（第6〜8章）。
