# 3万円という値づけを、数字で検証する

やりたいことは分かるので、まず**そのまま3万円でやった場合の数字**を出します。
そのうえで、どこを変えると事業になるかを書きます。

---

## 1. 相場との位置

5ページ規模の小規模サイトの制作費は、**10万〜50万円**が一般的な目安です
（[アキばれ](https://www.akibare.jp/base/costavg/)、[バリューエージェント](https://valueagent.co.jp/blog/40203) ほか複数の制作会社の公開相場）。
月額保守は**5,000円〜3万円**が相場です。

**3万円は、相場のおよそ1/5〜1/15。** 安さ自体は武器になります。問題は原価です。

---

## 2. 1件あたりに本当にかかる時間

`biz/kit/` の生成キットがあるので、**制作時間は本当に短い**です。
しかし制作は全体の2割しかありません。

| 工程 | 時間 | 備考 |
| --- | --- | --- |
| リスト精査（検索して本当にサイトがないか確認） | 0.3h | 1社5分 × 成約までの母数で按分 |
| 事前生成（`client.json` を書いて生成） | 0.4h | キットのおかげでここは短い |
| **架電（150件 × 3分）** | **7.5h** | `phone-script.md` の目安。**ここが全体の6割** |
| 商談・要望のヒアリング | 1.0h | 電話1〜2回 |
| 文章の書き直し（仮の文章を実物に） | 1.5h | ここは自動化できない |
| ドメイン取得・公開・GBP連携・Search Console | 1.0h | |
| 公開後の手直し・問い合わせ対応 | 1.0h | 初年度の平均 |
| 請求・入金確認 | 0.2h | |
| **合計** | **約12.9h** | |

### 時間あたりの粗利

```
30,000円 ÷ 12.9h ≒ 2,330円/時
```

ここから実費（ドメイン 年1,500円、通信費、Cloudflare Pagesは無料枠）を引きます。
**月20日・1日8時間フルで動いて、月商はおよそ 37万円、手取りはさらに下**です。
そして**この売上は翌月ゼロから積み直し**になります。

**結論：3万円の売り切りは、労働としては成立するが、事業としては積み上がりません。**

---

## 3. どこを変えるか（4つ、効く順）

### ① 月額を足す ← 最優先

売り切りをやめ、**初期3万円＋月額3,000円**にします。

| 契約数 | 月額収入 | 年間 |
| --- | --- | --- |
| 30社 | 9万円 | 108万円 |
| 100社 | 30万円 | 360万円 |
| 200社 | 60万円 | 720万円 |

月額3,000円の中身は、**実際にやること**を入れます（何もしない月額は必ず解約されます）。

- ドメイン・SSL・配信の維持（原価はほぼゼロ）
- **文章の差し替え 月1回まで**
- **Googleビジネスプロフィールの月次レポート**（表示回数・電話数・ルート検索数。
  GBPの管理画面に出ている数字を1枚にまとめるだけ。15分で作れて、
  「効いている」ことが目に見えるので解約されません）

3年LTV：`30,000 + 3,000 × 36 = 138,000円`。売り切りの**4.6倍**です。
相場（初期10万＋月額5,000円＝3年で28万）よりまだ安く、価格の優位は保てます。

### ② 架電をやめる方向に寄せる

7.5時間の架電が原価の6割です。ここを削るのが二番目に効きます。

- **紹介。** 成約した1社に「同業のお知り合いを1社ご紹介いただけたら、
  次の1年分の月額を無料にします」。原価3,000×12=36,000円で1件取れるなら、
  架電7.5時間より安い
- **商工会議所・同業組合。** 墨田区・大田区・足立区は町工場と工務店の組合が機能しています。
  1回の説明会で10社に会えるなら、架電の100倍効率がいい
- **1業種を掘り下げる。** 「工務店専門」と名乗ると、実績が次の営業になります。
  3社作れば、4社目には「〈地名〉の工務店さん3社でお使いいただいています」が言えます

### ③ 単価を業種で変える

3万円は**全業種一律である必要がありません。** 同じ手間で客単価だけが違います。

| 業種 | 妥当な初期費用 | 理由 |
| --- | --- | --- |
| 飲食・小売 | 3万円 | 1件の粗利が小さい。ここは3万円が上限 |
| 整体・美容 | 5万円 | 客単価は低いが回転が高く、広告費の感覚がある |
| 工務店・リフォーム | **10万円** | **1件の受注が数十万〜数百万円。**サイト1本で回収できる |
| 不動産・士業 | **10〜15万円** | 同上。かつ「信用の担保」として必要性を理解してもらいやすい |
| 自動車整備・葬祭 | 8万円 | 検索で探される業種 |

**「工務店に10万円」は、相場（10〜50万円）の下限です。安売りですらありません。**
3万円はあくまで、飲食・小売という**いちばん払えない層に合わせた価格**だと理解してください。

### ④ 制作を本当にゼロ手間にする

すでに `biz/kit/` でかなり詰めてあります。残っているのは**文章**（1.5h）です。

- 業種別の文例集を作り、屋号と地名を差し替えるだけにする
- ヒアリングを**紙1枚の記入式**にして、電話で聞き取る時間を削る
  → `biz/sales/hearing-sheet.md`

## 4. 推奨する値づけ

| プラン | 初期 | 月額 | 対象 |
| --- | --- | --- | --- |
| **おためし** | 30,000円 | なし | 飲食・小売。売り切り。手直しは年2回まで |
| **標準** | 30,000円 | 3,000円 | 上記以外の全業種。**これを基本にする** |
| **工務店・士業向け** | 100,000円 | 5,000円 | 受注単価の高い業種。写真撮影・事例ページ3本込み |

**3万円という看板は下ろさなくていい。**
「3万円から」で電話をかけ、業種を聞いてから上のどれかを出せば、嘘にはなりません。

## 5. 損益分岐（専業で始める場合）

生活費を月25万円とすると、

- **売り切りのみ**：月9件の成約が必要 → 架電 1,350件/月 → **1日68件。ほぼ不可能ではないが、毎月これを続ける**
- **標準プラン**：初年度は同じ。ただし**2年目は月額だけで9万円**入るので、必要な新規は6件に減る
- **3年目**：月額が30万円を超え、**新規ゼロでも生活費が出る**

**この事業の勝ち筋は、初年度の苦しさに耐えて月額を積むこと**です。
売り切りを続けるかぎり、3年目も1年目と同じ働き方になります。
