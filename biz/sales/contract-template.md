# 契約書・注文書のひな形

> 弁護士の作成したものではありません。3万〜10万円の取引で、
> **もめやすいところを先に潰しておく**ための実務用です。
> 金額が大きくなったら、専門家に見てもらってください。

`legal.md` の結論どおり、**特定商取引法の電話勧誘販売の義務を満たす形**にしてあります。
適用除外を当てにしないほうが安全で、そのコストはこの紙一枚だけです。

## ウェブサイト制作 注文書兼契約書

```
─────────────────────────────────────────────
                ウェブサイト制作 注文書兼契約書
─────────────────────────────────────────────

  〈発注者〉                          〈受注者〉
  商号                                 屋号　〈あなたの屋号〉
  所在地                               所在地 〈住所〉
  ご担当者                             氏名　 〈氏名〉
                                       電話　 〈電話〉
                                       メール 〈メール〉

  上記の両者は、次のとおり契約します。

  1. 業務の内容
     受注者は、発注者のウェブサイトを制作し、公開する。
     ・ページ数    5ページ（トップ／サービス／会社概要／
                   よくある質問／お問い合わせ）
                   ＋ サービス個別ページ　　　ページ
     ・含むもの    スマートフォン対応、検索エンジン向けの
                   基本設定（sitemap・構造化データ・canonical）、
                   Googleビジネスプロフィールとの接続、
                   Google Search Console への登録
     ・含まないもの 写真撮影／ロゴ制作／文章の全面的な書き起こし／
                   ネットショップ機能／予約システム／多言語対応
                   （別途お見積もり）

  2. 金額
     制作費　　　　　　　　　　　　　　　　　　　　　　円（税込）
     ドメイン費用（実費・年額）　　　　　　　　　　　　円
     月額費用　　　　　　　　　　　　　　　　　　　　　円／月
     　　　　　　　　　　　　　　　合計　　　　　　　　円

  3. 支払い
     公開の完了後、受注者が請求書を発行し、
     発行日の翌月末日までに指定口座へお振込みください。
     振込手数料は発注者のご負担とします。
     ※ 着手金はいただきません。

  4. 納期
     必要な資料をすべてお預かりした日から　　営業日以内に公開します。
     資料のご提供が遅れた日数は、この期間に加算されます。

  5. 修正
     公開前　　無制限
     公開後　　年2回まで無料（文章の差し替え・営業時間の変更など）
               3回目以降は1回5,000円（税込）
     ※ 構成そのものを変える場合は、別途お見積もりします。

  6. 原稿と素材
     発注者から提供された文章・写真・ロゴについて、
     第三者の権利を侵害していないことは発注者が保証するものとします。
     受注者が公開情報をもとに作成した仮の文章は、
     発注者の確認をもって発注者の責任において公開されるものとします。

  7. 成果物の権利
     制作費の支払い完了をもって、ウェブサイトの内容（文章・画像・
     ページ構成）に関する権利は発注者に移ります。
     受注者が制作に用いた生成の仕組み・共通の雛形については、
     受注者に留保されます。
     発注者は、他社へ移管することを含め、内容を自由に利用できます。

  8. 約束しないこと
     受注者は、検索結果の順位、問い合わせ件数、売上について、
     いかなる保証もいたしません。
     検索エンジンに正しく認識される形で公開するところまでを
     業務の範囲とします。

  9. 解約
     公開前　　着手前であれば無償。着手後は実費のみ申し受けます。
     公開後　　制作費の返金はいたしません。
               月額契約は、前月末までのお申し出で翌月分から終了します。
               解約後もサイトのデータ一式はお渡しします。

 10. ドメイン・サーバー
     ドメインは発注者名義で取得します。
     月額契約を終了された場合も、ドメインは発注者のものです。
     移管に必要な情報は無償でお渡しします。

 11. クーリング・オフ
     本契約が特定商取引法の電話勧誘販売に該当する場合、
     発注者は、本書面を受け取った日から8日間、
     書面または電磁的記録により、無条件で契約を解除できます。
     その場合、受注者は損害賠償や違約金を請求せず、
     既に受け取った金銭があるときは速やかに返金します。

 12. 協議
     本契約に定めのない事項は、両者が誠意をもって協議します。

     　　　　年　　月　　日

     発注者　署名（記名押印）　　　　　　　　　　　　　　
     受注者　署名（記名押印）　　　　　　　　　　　　　　

─────────────────────────────────────────────
```

## 月額保守 覚書（`PRICING.md` の標準プラン用）

```
─────────────────────────────────────────────
                ウェブサイト保守 覚書
─────────────────────────────────────────────

  1. 内容（毎月おこなうこと）
     ・ドメイン・SSL証明書・配信環境の維持
     ・文章の差し替え　月1回まで
     ・Googleビジネスプロフィールの状況レポート
       （表示回数・電話数・ルート検索数）
     ・不具合が起きた場合の復旧

  2. 含まないもの
     ページの新規追加、写真撮影、広告の運用、
     文章の新規書き起こし

  3. 金額　　月額　　　　　　円（税込）
     毎月末締め、翌月末日までのお振込み

  4. 期間　　最低契約期間はありません。
             前月末までのお申し出で、翌月分から終了します。

  5. 終了後　サイトのデータ一式とドメインの管理情報を
             無償でお渡しします。サイトを止めることはしません。

─────────────────────────────────────────────
```

## 実務のメモ

- **着手金を取らない。** 3万円で前受金をもらう手間と、もめたときの損失が釣り合いません。
  公開後に請求すれば、相手はもうサイトを使っているので回収率はほぼ100%です
- **9条「解約後もサイトのデータ一式はお渡しします」と、10条のドメイン名義を必ず守る。**
  この業界で一番嫌われているのが「解約するとサイトが消える」「ドメインを人質に取る」商法です。
  **逆をやると、それだけで選ばれます**
- **8条「約束しないこと」を必ず読み上げる。** 景表法の問題であると同時に、
  半年後に「順位が上がらない」と言われたときに効きます
- **11条のクーリング・オフは、書いてあるほうが信用されます。**
  3万円で8日以内に解除されても損失は知れています
