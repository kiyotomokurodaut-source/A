# ヒアリングシート（電話で15分／これだけ埋まればサイトは作れる）

`biz/kit/clients/<slug>.json` の各項目に1対1で対応しています。
**上から順に聞けば、そのままJSONになります。**

相手は忙しいので、**「わからない」と言われた項目は飛ばして、こちらで決めて後から確認**します。
15分を超えたら、残りはメールで聞いてください。

---

## 1. 基本（Googleマップから先に埋めておく。確認するだけ）

| 項目 | JSONのキー | 聞き方 |
| --- | --- | --- |
| 正式な商号 | `business.name` | 「看板は〇〇ですが、**契約書に書くお名前**は株式会社が付きますか」 |
| 読みがな | `business.kana` | |
| 郵便番号・住所 | `address.*` | **ビル名と階まで。**マップに入っていないことが多い |
| 電話 | `contact.phone` | 「**お客さんに出す番号**はこちらでよろしいですか」（携帯を出したい人もいる） |
| FAX | `contact.fax` | |
| メール | `contact.email` | 無ければ作るところから。`info@ドメイン` を提案 |
| 営業時間・定休日 | `contact.hours_text` / `hours_schema` | 「**年末年始やお盆**はどうされますか」まで |
| 創業年 | `business.founded` | **古いほど売りになります。**必ず聞く |
| 代表者名 | `business.representative` | |
| 従業員数 | `business.employees` | 少なくても書く。「大工3名」は強い |

## 2. 中身（ここが値打ちの分かれ目）

### Q1. 対応エリアはどこまでですか　→ `area_served`

区名で3〜5個。「都内全域」は**弱い**ので、必ず具体名に落とします。
検索は「墨田区 リフォーム」で行われるからです。

### Q2. お仕事の種類を、多い順に3つ教えてください　→ `services[]`

サービスごとに：

- **名前**（`name`）── お客さんが使う言葉で。「住宅改修」より「**リフォーム**」
- **ひとことで言うと**（`summary`）── 40〜60字
- **いくらから**（`price_from`）── 「**いちばん安い工事でいくらですか**」と聞く。
  「場合による」と言われたら「**これまででいちばん小さかった仕事**はいくらでしたか」
- **本文2段落**（`body`）── 下のQ3〜Q5の答えをここに書きます

### Q3. そのお仕事で、お客さんが**いちばん不安に思っていること**は何ですか

> 「追加費用が出ないか」「住みながらできるか」「何日かかるか」

**これがそのまま本文とFAQになります。**この質問1つで、他社のテンプレサイトと差がつきます。

### Q4. 同業の会社と、**はっきり違うところ**を1つだけ　→ `reasons[]`

「丁寧です」「誠実です」は**全社が言うので無意味**です。粘って具体を引き出します。

- ✗ 「対応が早い」 → ○ 「**電話から48時間以内に必ず現地を見に行きます**」
- ✗ 「安い」 → ○ 「**下請けに出さないので中間マージンがありません**」
- ✗ 「経験豊富」 → ○ 「**1978年から同じ石原で営業しています**」

### Q5. **断っている仕事**はありますか

意外と重要です。「新築はやりません」「ビルはやりません」と書いてあると、
**合う客だけが問い合わせてきて、無駄な電話が減ります。**
これは相手にとって分かりやすい利益なので、話が弾みます。

### Q6. よくある質問を3つ　→ `faq[]`

「毎回同じことを聞かれるな、ということはありますか」と聞くと出てきます。

## 3. 業種ごとの追加確認（法令対応。`legal.md` 参照）

| 業種 | 必ず聞くこと |
| --- | --- |
| 建設業 | **建設業許可番号**（500万円以上の工事を請けるなら表示が必要） |
| 不動産 | **宅建業免許番号**、専任取引士名 |
| 医科・歯科 | 標榜科目。**体験談・症例写真は載せられない**ことを先に伝える |
| 整体・接骨 | 施術所の届出。**「治る」「治療」と書けない**ことを先に伝える |
| 士業 | 登録番号、所属会 |
| 飲食 | 食品営業許可、アレルギー表示の方針 |

**「載せられないもの」は、作る前に伝えてください。**
あとから削ると「話が違う」になります。

## 4. 素材

| 欲しいもの | 無い場合 |
| --- | --- |
| 外観写真1枚 | **こちらで撮りに行く**（東京なので行けます。これが訪問の口実にもなる） |
| 施工前後 / 店内 3〜5枚 | スマホで撮ってLINEで送ってもらう |
| ロゴ | 無ければ屋号を文字で組む（`kit` の favicon は自動生成） |
| 許可証・登録証 | 番号だけでよい |

## 5. 公開まわり

| 項目 | 確認 |
| --- | --- |
| ドメイン | 希望があるか。無ければ `屋号ローマ字.com` を2〜3案出す |
| すでに持っているドメイン | **あることが多い。**昔作って放置しているケース。管理会社とIDを確認 |
| Googleビジネスプロフィール | **オーナー確認済みか。**未確認なら、そこから一緒にやる（ここが実は一番の価値） |
| 既存のSNS | Instagram・LINE公式があればリンクする |

## 埋めたあと

```sh
# 1. JSONに書き写す
vi biz/kit/clients/<slug>.json

# 2. 生成して検査
python3 biz/kit/build_site.py biz/kit/clients/<slug>.json --check
python3 biz/kit/check_render.py biz/kit/dist/<slug>

# 3. 両方通ったら公開（Cloudflare Pages に dist/<slug> を上げる）
```

**検査に落ちたまま見せないこと。** 3万円の商品で信用を落とす一番の近道です。
