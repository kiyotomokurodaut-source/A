# 電話営業の台本

## 前提：この台本は「まだ作っていない」状態を想定していない

`biz/kit/` の生成キットがあるので、**1社分のサイトを作る限界費用はほぼゼロ**です。
だから電話の前に作ってしまいます。

「作りませんか」は提案で、断るのにコストがかかりません。
「もう作ってあります、URLをお送りするので見てください」は事実で、
断るには一度見る必要があります。この差が受注率を分けます。

**電話の目的は契約を取ることではありません。URLを見てもらう約束を取ることです。**
契約は、相手が自分の会社のサイトを画面で見たあとに決まります。

---

## 架電前の準備（1社あたり3〜5分）

`biz/data/out/prospects.csv` の1行につき、次を確認します。

1. **「確認用検索」のURLを開く。** 本当にサイトがないか。
   - 公式サイトが出てきた → その行は捨てる（リストの列 `接触状況` に `既存サイトあり` と記入）
   - Googleビジネスプロフィールだけ出る → **最良の見込み客**。次へ
   - 食べログ・エキテン・ホットペッパーだけ出る → 見込み客。「他社の器を借りている」と言える
2. **何を売っているか10秒で言えるようにする。** 「リフォームの会社さん」では弱い。
   「木造の耐震補強もやっている工務店さん」まで具体化する
3. **サイトを生成しておく。** 屋号・住所・電話・業種だけで `clients/<slug>.json` は書けます。
   中身の文章は仮で構いません。相手は「自分の会社の名前が載った画面」を見た瞬間に話を聞きます

### 架電しない相手

- 従業員数が多い、複数拠点がある → 決裁が個人にない。3万円の商談に何回も通うことになる
- チェーン・フランチャイズ → 本部が禁止していることが多い
- 「電話営業お断り」の掲示がある → かけない
- 医療機関・士業 → **広告規制があります**。医療広告ガイドライン、弁護士等の業務広告規程。
  作れないわけではありませんが、書ける内容に制限があります。慣れるまで後回しでいい

## 台本

### 1. 名乗り（ここを早口にしない）

> お忙しいところ恐れ入ります。わたくし、**〈屋号〉の〈氏名〉**と申します。
> ホームページの制作をしております。**1分だけ**お時間いただけますでしょうか。

**「1分だけ」は必ず言い、必ず守ります。** 1分で切り上げた相手は、次に電話したとき出ます。
名乗りで業種を隠すと、そのあと何を言っても信用されません。

### 2. 事実を1つだけ置く（ここが本体）

> 先ほど「**〈屋号〉 〈地名〉**」で検索してみたのですが、
> Googleマップには出てくるのに、**御社の公式のページが出てこない**状態でした。
> これ、もうご存じでしたか。

- 「ご存じでしたか」で終える。売り込みではなく確認になります
- 相手が「知ってる」→ 3へ
- 相手が「え、そうなの」→ 3へ（こちらのほうが話が早い）
- 相手が「うちはいらない」→ 5へ

### 3. 損失を具体化する（業種の言葉で）

工務店・リフォーム：
> リフォームだと、お客さんは**何社か調べてから電話する**のが普通になっていまして。
> そのときに会社の中身が見えないと、候補から外れてしまうんです。
> 紹介でいただいている仕事には影響ないのですが、**新規の分だけ取りこぼしている**形になります。

整体・美容：
> 「〈地名〉 整体」で探している人が、いちばん最後に見るのが公式のページなんです。
> そこがないと、クーポンサイト経由のお客さんしか来なくなって、
> **手数料を払う分だけ利益が薄くなる**、というのがよくある形です。

士業・不動産：
> ご相談される方は、**先生のお名前を必ず検索します**。
> そのときに事務所のページが出ないと、それだけで問い合わせが止まってしまいます。

**やってはいけないこと**：「今のままだと売上が落ちます」のような、確かめていない断定。
根拠のない不安を煽ると、その場では話が進んでも契約後に必ずもめます。

### 4. 次の一歩を小さくする

> それで、**もう作ってあります**。
> 御社の名前と住所と電話番号だけで、5ページ分。
> 見ていただいて「いらない」ということでしたら、それで終わりで構いません。
> **URLをお送りしたいのですが、FAXとメールどちらがよろしいですか。**

- 「送っていいですか」ではなく「**FAXとメールどちら**」と聞く（断る形を作らない）
- 費用は**ここでは言わない**。聞かれたら即答する：
  > **3万円です。**月々の費用はかかりません。ドメインを新しく取る場合だけ、
  > 年1,500円ほど実費でいただきます。
- 「なんでそんなに安いの」と必ず聞かれます。正直に答える：
  > 型が決まっているので、うちの手間が少ないんです。
  > そのかわり、ゼロから絵を描くようなデザインはお請けしていません。

### 5. 断られたときの引き際

> かしこまりました。お忙しいところ失礼いたしました。
> もしあとで気になることがあれば、**〈電話番号〉**までご連絡ください。失礼します。

**食い下がらない。** 3万円の商材で粘って得るものはありません。
断った相手の8割は二度と買いませんが、粘らずに切った相手の2割は半年後に電話してきます。
`接触状況` に `断り／日付／理由` を残します。同じ相手に半年以内にかけ直さないためです。

## よくある切り返し

| 相手の言葉 | 返し |
| --- | --- |
| 「間に合ってます」 | 「失礼しました。いまはSNSでされてる感じですか」→ Instagramだけなら「検索からは出てこないので、そこだけ補う話です」と1回だけ返して、断られたら引く |
| 「忙しい」 | 「承知しました。**夕方の何時ごろ**でしたらお手すきですか」（日時を取る。取れなければ引く） |
| 「高い／安い会社が他にもある」 | 「ございますね。うちは**月額をいただかない**のが違いです。3年で比べると差が出ます」 |
| 「社長に聞かないと」 | 「ありがとうございます。**お名前だけ**うかがってよろしいですか」＋ URLを先に送る |
| 「どこで番号を知った」 | 「**Googleマップ**に公開されているものです」（正直に。ここでごまかすと終わり） |
| 「作ってもどうせ見られない」 | 「そのとおりで、作っただけでは出ません。**Googleビジネスプロフィールと繋ぐ**ところまでやります。そこが本体です」 |
| 「更新できないと困る」 | 「**文章の差し替えは年2回まで無料**です。それ以上は1回5,000円いただきます」 |

## かける時間帯

| 業種 | 良い時間 | 避ける時間 |
| --- | --- | --- |
| 工務店・建設 | 11:30〜12:30、16:30〜18:00 | 朝8〜10時（現場に出ている） |
| 飲食 | 14:00〜16:30 | 11:30〜13:30、17:30〜 |
| 美容・整体 | 火〜木の10:00〜11:00、14:00〜16:00 | 月曜（定休が多い）、土日 |
| 士業・不動産 | 火〜金の10:00〜11:30、14:00〜16:00 | 月曜午前、水曜（不動産の定休） |
| 自動車整備 | 10:00〜11:30、14:00〜16:00 | 月末（車検の締め） |

## 数字の目安（この目安で回らなければ、やり方ではなく商品を疑う）

| 指標 | 目安 |
| --- | --- |
| 1時間あたりの架電数 | 15〜20件 |
| 決裁者につながる率 | 30〜40%（小規模事業者は本人が出る） |
| URLを送る約束が取れる率 | つながったうちの 15〜25% |
| 送付 → 成約 | 10〜20% |
| **1成約あたりの架電数** | **おおむね 120〜250件** |

1成約に150件かけるとして、1件3分（準備込み）で7.5時間。
**3万円の受注に、営業だけで1日かかります。** この数字は `biz/PRICING.md` の前提です。
