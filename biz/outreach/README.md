# メール営業：使える相手と、使えない相手

結論から書きます。

> **「ホームページがない会社」には、メールを送れません。**
> 法律の問題であると同時に、そもそも宛先が存在しません。
> **メールで行くなら、狙う相手を「サイトはあるが古い会社」に変えてください。**
> **「サイトがない会社」を狙うなら、電話です。**

---

## 1. 数字

全国から取れた「電話あり・サイトなし」**20,823件**のうち、
**メールアドレスが取れたのは0.9%**でした。

これは採取の不備ではありません。**定義上そうなります。**

- メールアドレスは、ウェブサイトか、ぐるなびのような掲載サイトに載っているから拾えます
- ウェブサイトを持っていない会社は、どこにも載せていません
- そして特定電子メール法が同意なしの送信を認める例外は、
  **「自己の電子メールアドレスを公表している」**事業者に限られます（`../sales/legal.md` §3）

つまり、**公表していない＝拾えない＝送っても違法**、の三つが同時に成立します。
抜け道はありません。

| 手段 | 「サイトがない会社」に届くか |
| --- | --- |
| 電話 | **届く。20,823件すべてに番号がある**（それが抽出条件なので） |
| FAX | 届く。建設・整備・製造はFAXのほうが読まれる |
| 郵送 | 届く。住所は8割方そろっている |
| **メール** | **届かない。0.9%** |

## 2. だから、メール用のリストは別に作ります

`find_email_targets.py` が狙うのは、**すでにサイトを持っている会社**です。
一見すると見込みが薄そうですが、実際には**こちらのほうが良い相手**です。

| | サイトなし | **サイトはあるが古い** |
| --- | --- | --- |
| メールで届くか | ✗ | **○（公表アドレスあり＝法の例外が成立）** |
| 予算があるか | 未知数 | **○。一度払った実績がある** |
| 話の入り口 | 「作りませんか」＝提案 | **「ここが崩れています」＝事実** |
| 母数 | 全国で20,823件 | 全国で14,745件 |

3行目が肝心です。提案は断るのにコストがかかりませんが、
**自分のサイトについての具体的な指摘は、一度確かめないと断れません。**

## 3. 何を根拠にするか

`find_email_targets.py` は各社のサイトを実際に開いて、
**相手が自分のスマホで10秒で確かめられること**だけを拾います。

| 検出するもの | メールでの言い方 |
| --- | --- |
| viewport がない | 「スマートフォンで開くと、文字が小さいまま横に広がります」 |
| http:// のまま | 「アドレスバーに『保護されていない通信』と出ます」 |
| フレーム／テーブルレイアウト | 「画面幅に合わせて折り返らない、古い組み方です」 |
| Flash が残っている | 「いまはどのブラウザでも再生されません」 |
| 著作権表記が3年以上前 | 「ページ下部の年号が更新されていません」 |
| 構造化データ・canonical・OGPなし | 「検索結果に住所や電話が出る設定が入っていません」 |

**好みの問題は一切入れていません。**「デザインが古い」は反論されますが、
「スマホで崩れる」は反論されません。

## 4. 送らない相手を、機械的に外す

サイトに **営業お断り／セールスお断り／勧誘お断り** の表示がある会社は、
`email_excluded.csv` に落として**絶対に送りません。**

これは礼儀ではなく法律です。特定電子メール法の「公表アドレス」例外は、
**アドレスと並んで送信拒否の表示がある場合には成立しません。**
表示があるのに送れば、例外の外なので違反になります。

`info(at)example.jp` のように書き換えてあるアドレスも**復元しません。**
その書き方自体が「機械で拾うな」という意思表示だからです。

## 5. 実際に下書きにするまで

```sh
# 1. サイトを持っている会社の一覧を作る（harvest_osm.py が両方書き出します）
python3 ../prospecting/harvest_osm.py --preset nationwide

# 2. 各社のサイトを開いて、アドレスと「古さ」を調べる
python3 find_email_targets.py --limit 500

# 3. 送信者情報を埋める（法律上の必須項目。空だと止まります）
vi sender.json

# 4. 下書きを作る
python3 make_drafts.py --limit 50
```

出力は3つです。

| ファイル | 使い方 |
| --- | --- |
| **`gmail-drafts.gs`** | **script.google.com に貼って実行 → Gmailの下書きに入る** |
| `compose-links.md` | クリックすると作成画面が中身入りで開く。数通だけのとき |
| `drafts.csv` | 送る前に全文を読み返すため |

### Gmailの下書きにする手順

1. <https://script.google.com/home> →「新しいプロジェクト」
2. `gmail-drafts.gs` の中身を全部貼って保存
3. 関数 `createDrafts` を選んで実行
4. 初回だけ権限の確認が出ます（自分で書いたスクリプトなので、
   「詳細」→「安全ではないページに移動」で進みます）
5. Gmailの「下書き」に入ります

**送信はしません。下書きを作るだけです。** 1通ずつ読んで、直して、自分で送ってください。
同じ宛先にすでに下書きがあれば飛ばすので、二重に作られることはありません。

Gmailには1日の送信上限があります（無料アカウントでおおむね500通、
実際には**1日20〜30通に抑えるべき**です。新しいアカウントから急に大量送信すると、
迷惑メール判定を受けて以後のメールが全部届かなくなります）。

## 6. 実績の書き方について

`sender.json` の `portfolio_url` は**空のままにしてあります。**

営業文面のなかで、**受け手が確かめられて、こちらが取り消せない唯一の主張**が実績です。
「制作実績50社」と書いて1社も出せなければ、そのメールは開いた瞬間に価値がゼロになり、
景品表示法の優良誤認にも当たります（`../sales/legal.md` §4）。

いま出せるものを整理すると：

| 候補 | 状態 |
| --- | --- |
| `kiyotomokuroda.pages.dev` | **名前解決できません**（`../../SEO.md` 第0章）。載せられない |
| `kiyotomokuroda.netlify.app` | 表示はされますが、中身が古い版です |
| `...workers.dev` | 現行の内容が出ますが、URLが営業文面に向きません |
| **`biz/kit/` で作ったサンプル** | **これを1つ公開するのが最短です** |

**最初の1通を送る前に、Cloudflare Pages に `kit/dist/` のサイトを1つ公開してください。**
「こういうものを作ります」と言える実物が1つあれば足ります。
それができるまでは `portfolio_url` を空にしておけば、その段落ごと出力されません。

黒田塾のサイト自体を実績として出す場合も、先に `pages.dev` を作って
canonical と一致させる必要があります。**いまのままリンクを貼ると、
「この人のサイトも検索に出ていない」ことが相手に分かってしまいます。**

## 7. 実際に走らせた結果（2026-09-22）

全国の `with_site_jp.csv` 14,745件のうち、**スコア上位1,500社のサイトを実際に開いて**
調べた結果です。

| | 件数 |
| --- | --- |
| 調べたサイト | 1,500 |
| **送付可（アドレスあり・必要度2以上）** | **190** |
| 営業お断りの表示あり → 除外 | 3 |
| アドレスが見つからない／サイトが開かない | 1,200 |

**送付可190件の業種内訳**（高単価の業種がきれいに残りました）:

| 件数 | 業種 |
| --- | --- |
| 43 | 一般企業・専門事務所 |
| 30 | 自動車・バイク整備 |
| 26 | 建設・職人（工務店ほか） |
| 22 | 塾・教室・習い事 |
| 20 | 製造・町工場 |
| 9 | 歯科／葬祭 |
| 6 | 士業・コンサル |

上位はいずれも **viewportなし＋常時SSL化なし**、つまり
「スマホで崩れる」「保護されていない通信と出る」の両方が当てはまる会社です。
メールの1行目で書いていることが、相手の画面でそのまま確認できます。

残り13,245社は未調査です。`--limit` を上げれば同じ手順で増やせます
（1,500社でおよそ20分）。
